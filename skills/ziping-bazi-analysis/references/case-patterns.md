# 19个实证可复用模式

## 乾造辛亥案例（偏财格、通关结构、杀藏财库）
**模式1：事业变动触发字归纳法**
从实证归纳触发字：亥卯酉午四字。未来此四字之年事业必动。
**模式2：双动年机制——先试错后到位**
偏财被引动→心动奔向创业→无名之财不立→回归平台翻倍
**模式3：破财两步走**
透财年结盟(2014甲午)→劫透年兑现(2020庚子)。反例：2024甲辰湿土水地→收入十年最佳
**模式4：官非开库放杀**
2014甲午午未合开杀库→酉月引爆→外杀入宫→印化杀保险公司全赔
**模式5：健康土困水脏**
2024甲辰土困亥水→肾结石手术。财吉与身疾并行（分线断法）
**模式6：大器晚成结构**
食神被埋→解封点在用神填实/伏吟之年
**模式7：置业印性窗口**
三次置业全在土月或印年。印是比劫夺不走的资产形态

## 坤造庚午案例（从杀格、六亲缘薄）
**模式8：从格实证锁定法**
土金运大凶→反向锁定从格→喜忌全颠倒
**模式9：从格六亲缘薄机制**
印比皆忌→亲缘星皆为忌神→疏离是结构使然
**模式10：从格转运节奏**
逆局苦→顺势昌→逆局危→晚运安
**模式11：从格婚恋夫星动应期**
冲动官杀之年=婚恋应期。宜夫强，被管反而安心

## 乾造丙戌案例（建禄格、财官俱真）
**模式12：学业官杀线晴雨表**
杀透压制则滑，金生水足则升，平台升级则强
**模式13：财星明绝暗生**
表面辛坐卯绝地→实际两巳庚金长生+戌库辛金余气
**模式14：运抬格局结构**
原局七成、大运三成。先苦后甜、越老越值钱
**模式15：升学应期**
食神透干（发挥）+ 官星得源（名分）
