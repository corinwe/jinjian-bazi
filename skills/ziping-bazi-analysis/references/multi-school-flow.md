# 多流派分析模式
日期：2026-07-27
来源：用户反馈与竞品（heluwenxian.nat100.top）研究

## 为什么多流派？
不同命理流派擅长不同分析维度。同一八字用不同流派看，能够覆盖更多角度，让用户自己选择最准的那个。

| 流派 | 擅长 | 不擅长 |
|:-----|:-----|:-------|
| **子平** | 格局定性、旺衰扶抑、层次判定、大运流年 | 具体事象的精准取象 |
| **盲派** | 做功机制、家里家外、体用关系、具体事象 | 抽象层次的量化 |
| **九龙** | 一位为真、十神吉恶平比例、补益应用 | 大运流年的体系化推演 |

## 玩法
### 入口
免费报告阶段，同时输出三个流派的简版三决断。

### 三流派输出格式
```
【子平视角】
条1：...机制：...
条2：...机制：...
条3：...机制：...

【盲派视角】
条1：...机制：...
条2：...机制：...
条3：...机制：...

【九龙视角】
条1：...机制：...
条2：...机制：...
条3：...机制：...
```

### 用户反馈
用户选择：
- "子平说得准" → 深度以子平为主体
- "盲派说得准" → 深度以盲派为主体
- "九龙说得准" → 深度以九龙为主体
- "都准/各有千秋" → 以子平为主体，融合其他流派

### 三决断选取原则
- 每个流派的三条内容不能相同（不同流派的判断逻辑不同）
- 每条必须明确标注"条1/条2/条3，您可以对照看看"
- 每条必须附带命理依据（机制式分析，非结论式）
- 覆盖三个不同人生阶段或三个不同领域
