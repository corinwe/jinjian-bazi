# 机制式分析方法论

## 为什么需要机制式分析
本技能的前身（2026-07-22之前的版本）曾被用户反复批评为"结论式"——只给结论，不解释为什么。用户原话："我说三行就说完了，文档要写十八行才把机制讲透。我的问题：我说出了"是什么"，文档说清楚了"为什么"、"怎么发生的"、"为什么持续这么久"、"为什么是这个结果"。"

## 结论式 vs 机制式对照

### 事业变动分析
**结论式**（禁止）："2027丁未年防压力加倍"
**机制式**（必须）：
```
① 年柱定性：丁未年，丁火七杀透干
② 坐下地支：未土为燥土，丁杀坐燥土则名分之力被泄
③ 通关检查：未土伏吟月令，土重克癸水，通关链条受损
④ 结论：【官杀线偏凶】名分打折，压力加倍，防名到利不随
```

### 财星分析
**结论式**（禁止）："某年财透主破财"
**机制式**（必须）：
```
① 财在哪：天干透出（暴露在外，易被比劫争夺）
② 通关于否：天干是否有食伤在比劫和财之间通关？
   有 → 比劫生食伤→食伤生财 → 正财能存
   无 → 比劫无食伤可泄 → 回头夺财 → 破财
③ 地支环境：该年地支湿润还是干燥？
   湿润(辰亥子丑寅卯) → 滋养通关链条 → 得财
   干燥(午未戌巳) → 烤断通关链条 → 破财
④ 结论：【财线吉/凶/平】+ 原因
```

### 流年总评
**结论式**（禁止）："2024年收入佳但动手术"
**机制式**（必须）：
```
2024甲辰年分线断：
① 财线 → 【吉】。甲木透干得辰土滋养，通关加粗，收入十年最佳
② 身线 → 【凶】。辰土困亥，土重困水，肾结石手术
③ 官杀线 → 【平】。无官杀透干冲刑，平稳
总评：财吉与身疾并行不悖，不可一言蔽之
```

## 机制式分析的通用五个"为什么"
分析任意流年事件时，必须回答以下五个问题：
1. **为什么是这一年？** → 流年激发了什么机制（填实/冲/合/伏吟/透干/开库）
2. **为什么是这个月？** → 具体流月引爆（冲力到顶点的月份）
3. **为什么是这个类型的事件？** → 十神取象（财线/官杀线/身线/夫妻线）
4. **为什么持续这么久？** → 战冲还是断冲？开库后须等合化？
5. **为什么是这个结果？** → 通关链条完整/断裂？印化杀/比劫夺财？
