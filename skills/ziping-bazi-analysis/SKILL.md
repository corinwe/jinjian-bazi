# 子平八字命理深度分析体系

## 核心原则
本技能以六套理论派系为骨架，以实证校正为方法论，以"有理有据、分析详实"为输出标准。

### 基本原则
1. **机制式分析（禁止结论式）**：每一条判断必须包含"事实→机制→条件→结论"四步，不能直接给结论。
   - 错误的写法（结论式）："2026丙午年事业吉"
   - 正确的写法（机制式）："2026丙午年，丙火合日主（官来就我）→ 午未合开杀库（库中丁火出库）→ 职责扩大但名分未动（透丙非透丁）→ 结论：【官线吉、财线平】"
2. **条件化表达**：每个十神/五行的喜忌需要附加条件（"什么条件下吉、什么条件下凶"），不写静态清单。
3. **明确结论 + 细说条件**：结论明确说【吉】【凶】【平】，但必须同时说清条件。两者都要，不是二选一。
4. **分线断法**：同一年各条线（财/官杀/身/夫妻/比劫）分开判断，不允许用"某年吉/凶"一言蔽之。
5. **不回避矛盾和模糊点**：遇到实证与理论冲突，优先怀疑理论而非用户实证；被推翻的判断必须明确认账。

## 六套理论派系分工
| 派系 | 功能 | 经典依据 |
|------|------|----------|
| **子平格局法** | 定层次（命多高） | 《子平真诠》 |
| **扶抑旺衰法** | 定喜忌（用什么） | 《滴天髓》 |
| **调候法** | 定气候（缺什么） | 《穷通宝鉴》 |
| **从格法** | 定顺逆（顺谁走） | 《滴天髓·从象》 |

| **大运流年应期法** | 定时间（何时发生） | 岁运并临法 |

## 分析流程（产品版）

### Step 0：三决断（先验过去）
任何八字分析的第一步不是全面报告，而是"先验过去，再看当下选择"。
分析任何命盘时，必须先给出3条可验证的过去判断，等用户确认后再深入。

**三决断选取规则：**
- 覆盖三个不同人生阶段（早年/青年/中年）或三个不同领域（家庭/事业/健康）
- 每条必须有明确时间点或时间段
- 每条标注"条1/条2/条3，您可以对照看看"
- 每条必须附命理依据（什么机制导致这个事件）

**示例格式：**
```
条1（约2009-2012丁亥运）：你经历了一次主动选择的职业转型，不是被迫的。
条2（约2014-2015甲午未年）：你同时面对了至少两件大事，一件工作变动一件家庭事务，不是巧合。
条3（约2019己亥年）：你内心有强烈想改变的念头，但外在条件不允许，憋了一年多。
```

**用户确认后** → 进入深度分析。用户不确认 → 结束或调整判断。

### Step 1：基础命盘解析
旺衰判定→格局定性→喜忌推导→关键组合

### Step 2：事项解读
事业/财运/婚恋/子女/六亲/健康

### Step 3：大运流年推演
分线断法，明确每线【吉/凶/平】

### Step 4：格局层次总评
清奇之处与瑕疵，一句话总评

### Step 5：建议与规避
发展方向/人际/风险日历

## 多流派分析模式（可选）
当用户要求多流派分析时，对同一八字同时输出子平/盲派/九龙三个流派的简版三决断。
用户反馈哪个流派说得准 → 以该流派为主体做深度分析。
详见 `references/multi-school-flow.md`

## 完整报告输出格式（三流派版）

当输出完整报告时，每人需包含以下全部板块：

```
【八字排盘】四柱+大运+藏干

【子平视角】
  一、格局层次（类型+成败清浊）
  二、性格特点（日主+十神+调候）
  三、身材长相外貌（肤色/骨架/五官/神态/气质）
  四、学业事业和财富
  五、婚姻子女
  六、健康体质
  七、三决断（3条已发生可验证事件）
  八、重点流年年份（已发生关键流年+三派合参）
  九、未来发展方向（事业/财富/子女/健康）
  十、关键时间事件·流月应期

【盲派视角】
  一、做功方式（制/生/合）
  二、家里家外
  三、体用关系
  四、性格+长相象法
  五、三决断
  六、重点流年年份

【九龙视角】
  一、十神吉恶平比例
  二、一位为真应用
  三、五行体用关系
  四、补益建议（方位/颜色/行业）
  五、三决断
  六、重点流年年份

【流年吉凶总表·分线断法】
  五线分断表（财线/官线/身线/夫妻线/比劫线）
  每条线明确【吉】【凶】【平】
```

⚠️ 未来流年断事及财富事业走向在完整版报告中必须包含，不可省略。
⚠️ 分线断法每条线必须明确说【吉】【凶】【平】，不得模棱两可。

## 定价分层
- **免费层**：完整排盘 + 旺衰/格局一句话 + 三决断 + 后续方向选择
- **付费层**：六体系完整深度分析 + 条件喜忌 + 分线断法 + 大运流年总表 + 风险日历
