# 子平八字命理深度分析体系

## 核心原则
本技能以六套理论派系为骨架，以实证校正为方法论，以"有理有据、分析详实"为输出标准。

### 基本原则
1. **机制式分析（禁止结论式）**：每一条判断必须包含"事实→机制→条件→结论"四步，不能直接给结论。
   - 错误的写法（结论式）："2026丙午年事业吉"
   - 正确的写法（机制式）："2026丙午年，丙火合日主（官来就我）→ 午未合开杀库（库中丁火出库）→ 职责扩大但名分未动（透丙非透丁）→ 结论：【官线吉、财线平】"
2. **条件化表达**：每个十神/五行的喜忌需要附加条件（"什么条件下吉、什么条件下凶"），不写静态清单。
3. **明确结论 + 细说条件**：结论明确说【吉】【凶】【平】，但必须同时说清条件。两者都要，不是二选一。
4. **分线断法**：同一年各条线（财/官杀/身/夫妻/比劫）分开判断，不允许用"某年吉/凶"一言蔽之。
5. **不回避矛盾和模糊点**：遇到实证与理论冲突，优先怀疑理论而非用户实证；被推翻的判断必须明确认账。

## 六套理论派系分工
| 派系 | 功能 | 经典依据 |
|------|------|----------|
| **子平格局法** | 定层次（命多高） | 《子平真诠》 |
| **扶抑旺衰法** | 定喜忌（用什么） | 《滴天髓》 |
| **调候法** | 定气候（缺什么） | 《穷通宝鉴》 |
| **从格法** | 定顺逆（顺谁走） | 《滴天髓·从象》 |
| **刑冲合害开库法** | 定机制（怎么发生） | 子平正法 |
| **大运流年应期法** | 定时间（何时发生） | 岁运并临法 |

## 分析流程
1. **基础命盘解析**：旺衰判定→格局定性→喜忌推导→关键组合
2. **事项解读**：事业/财运/婚恋/子女/六亲/健康
3. **大运流年推演**：分线断法，明确每线【吉/凶/平】
4. **格局层次总评**：清奇之处与瑕疵，一句话总评
5. **建议与规避**：发展方向/人际/风险日历
