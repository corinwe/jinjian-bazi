# 盲派家里家外 · 亥卯未三合木局财富分析
来源：2026-07-22 与老板对谈精要
精读人物：魏启令（庚申 癸未 辛亥 辛卯）

## 核心逻辑

### 家里 vs 家外分法
家外（年柱+月柱）：社会、外部资源、行业人脉
家里（日柱+时柱）：自己能掌控的、私人的财富

### 两份财的逻辑
月柱占一份（家外·未中乙木偏财）
日支+时柱占一份（家里·亥中甲木正财 + 卯中乙木偏财）
这两份财通过亥卯未三合木局连在一起。

## 三合木局的财富价值

未（月支·家外）— 木库 → 外部资源库、人脉库、行业资源
     ↙          ↘
亥（日支·家里）— 木长生 → 技术/产品/平台
卯（时支·家里）— 木旺位 → 财富变现

### 合的方式
不是克（硬抢），是合（合作共赢）。
外部资源（未）通过三合局被拉进家里（亥+卯）。

### 核心结论
- 赚钱方式是合不是克——适合平台化整合资源，不适合硬碰硬竞争
- 外部资源通过合的方式进入家里——适合合作、合伙、平台模式
- 财富路径：技术（亥）→ 对接行业资源（未）→ 合作变现（卯）

## 引化条件
三合局需要天干透木来引化才能真正发力。
- 甲透干 + 寅亥合木 → 双引化 → 三合局正式启动
- 丑未冲 → 开未木库 → 未中乙木释放 → 提前激活
- 庚寅运（寅亥合+三合局双加持）→ 财富顶峰

## 枭神夺食风险
月干癸水食神（名声IP）被偏印克制时需注意：
- 己土大运/流年透干 → 直接克癸水 → 保守为主
- 财不外露、不激进扩张
- 未中己土（地支）不直接克天干癸水 → 威胁较小
