# 起运唯一口径（2026-09-29 老板定标修正版·v2）

## 铁律
**起运/大运年龄/大运年份只有一个实现：`engine/qi_yun.py`。**
禁止另写公式；**验证器也不准用固定日期近似表或钟表时验算**（自欺）。

## 三条致命易错点（2026-09-29 老板定标·静/少爷两个基准）

| # | 错法 | 正法 |
|:--|:--|:--|
| ① | 起运年用「实际起运日 + Q4(10-12月)进位次年」 | **出生年 + int(起运年龄)**（<1岁记1）<br>静 2006+8=**2014** · 少爷 2011+8=**2019** |
| ② | 折算只到「天」就截断 | 必须 **年/月/天/时** 四段：<br>3日=1年 → 1日=4月 → 1月=30命理日 → **1命理日=24命理时** |
| ③ | 真太阳时只修经度（或未知出生地直接返0） | 真太阳时 = 地方平太阳时 + **均时差EoT**<br>用精确式 `4×(太阳平黄经−真赤经)`（`jieqi.equation_of_time`） |

## 敏感度（为什么②③必须较真）
**真太阳时差 1 分钟 = 命理时间差 2 小时。**
静：EoT 近似式 -4.34分 → 起运「9时」；精确式 -4.08分 → **「10时」**（与老板答案完全一致）。
少爷：上海经度修正+5.9、均时差+2.4 → 真太阳时 09:14 → 8年4月24天**7时**（老板给6时，差1命理时=30秒，属分钟级取整噪声）。
