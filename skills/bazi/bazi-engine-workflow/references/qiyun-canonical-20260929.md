# 起运唯一口径（2026-09-29 老板令·全系统强制）

## 铁律
**起运/大运年龄/大运年份 只有一个实现：`engine/qi_yun.py`。**
任何脚本、验证器、报告生成器要算起运，必须 `from qi_yun import compute_qi_yun`，禁止另写公式。
验证器尤其不能自己用「固定日期近似表」验算——用近似表验证精确值 = 自欺。

## 唯一规则 R1~R9
| 规则 | 内容 |
|:--|:--|
| R1 | 阳男阴女顺排、阴男阳女逆排；年干阴阳按**立春精确定界** |
| R2 | 节气一律 `engine/jieqi.py` 精确值（分钟级）；顺排取下一「节」、逆排取上一「节」，**禁用固定日期表** |
| R3 | 天数 = \|节气时刻−出生时刻\| 秒级 ÷ 86400 |
| R4 | 起运年龄 = 天数 / 3.0（3天=1年） |
| R5 | 折算：年=int(d//3)、月=int(余×4)、天=int((余×4−月)×30) |
| R6 | 年龄基准：<1年→1；≥1年→**int() 向下取整**（8.7岁→8岁起运，**禁 ceil**）＝九龙道长标准·2026-06-25 校准 |
| R7 | 起始年 = 起运实际日期年；月份≥10月（Q4）→ 进位次年 |
| R8 | 每步10年，默认 11 步 |
| R9 | 唯一展示格式：`起运8岁8个月19天（8.72岁·约2015年12月起运·阳女逆排）`（经 `format_qi_yun()`） |

## 历史教训（为什么加门禁）
同一命造曾同时存在 5 套算法 / 2 个答案：起运 `8岁8个月19天` vs `8岁10个月0天`，
大运年龄带 `8~17岁` vs `9~18岁`（`math.ceil` 导致差1岁），起始年差1年。
| 位置 | 病灶 |
|:--|:--|
| da_yun.py | 固定日期近似表 + `math.ceil` + `出生年+int(age)` |
| bazi-verify.py | 第三份固定日期表（验证器用近似表） |
| bazi-full-verify.py | 死代码 |
| pipeline_v5.py | `round(qy_age,1)` → 8.72 显示成 8.7 |
