# 分析流程设计（产品版）
日期：2026-07-27

## 核心原则：先验过去，再看当下选择

## 流程

### Step 1：排盘（用户操作）
用户输入出生年月日时+性别 → 系统排盘 → 展示四柱+大运表
（免费，无需登录）

### Step 2：三决断（免费）
系统根据八字给出3条可验证的过去判断。
- 覆盖三个不同人生阶段（早/中/青）或三个不同领域（家/事/健）
- 每条标注"条1/条2/条3，您可以对照看看"
- 可选：同时给出三个后续方向

### Step 3：用户反馈（免费）
用户确认三决断是否准确：
- "都准" → 进入后续方向选择
- "部分准" → 系统记录偏差，调整后继续
- "都不准" → 免费报告结束，建议用户联系支持

### Step 4：方向选择（免费）
用户从2-3个方向中选择一个想深入了解的方向

### Step 5：付费解锁（收费）
用户选择方向后 → 提示支付 → 解锁深度报告

### Step 6：深度分析（收费）
完整六体系分析 + 条件喜忌 + 分线断法 + 大运流年总表 + 风险日历

## 多流派模式（可选流程）
- 排盘 → 三流派同步输出简版三决断
- 用户反馈哪种流派说的准
- 系统选择主流派进行深度分析
