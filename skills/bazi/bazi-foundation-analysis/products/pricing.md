# 产品定价分层设计
日期：2026-07-27
状态：方案阶段

## 定价原则
- 免费层让用户信服（不仅是获客，也是建立信任）
- 付费层提供真正的深度价值
- 不搞一刀切的"不给钱就不给看"

## 免费层内容（基础报告）
### 包含项
1. 🆓 **八字排盘** — 四柱+大运（完整展示藏干）
2. 🆓 **旺衰判定** — 一句话（如"日主偏旺"）
3. 🆓 **格局定性** — 一句话（如"食伤生财格"）
4. 🆓 **三决断** — 3条可验证的过去判断，覆盖三个不同阶段/领域
5. 🆓 **可选方向** — 提供2-3个后续深入方向供用户选择

### 免费报告示例结构
```
【八字排盘】
【旺衰】→ 一句话
【格局】→ 一句话
【三决断】
  条1（早年）：...
  条2（青年）：...
  条3（中年）：...
【可选方向】
  ▶ 方向一：感情模式与婚姻质量
  ▶ 方向二：事业接下来怎么走
  ▶ 方向三：XX年（当前年）状态和注意事项
【付费解锁】：如用户选择方向 → 提示深度报告需要解锁
```

## 付费层内容（深度报告）
### 包含项
1. 六体系完整分析
2. 条件喜忌（每个十神的精确条件）
3. 分线断法（财线/官杀线/身线/夫妻线/比劫线）
4. 大运流年总表（分线标注吉凶）
5. 风险日历
6. 19个模式对照
7. 创业合参/家庭合参（如需求）

## 定价参考
- 基础免费 → 深度报告: ¥9.90/用户/命盘（参考同行）
- 家庭合参（多命盘）: ¥19.90
- 创业合作分析: ¥29.90
