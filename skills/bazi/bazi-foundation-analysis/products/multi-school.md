# 多流派分析模式
日期：2026-07-27

## 为什么多流派？
不同命理流派擅长不同维度：
- **子平法**：格局定性、旺衰扶抑、层次判定
- **盲派**：做功机制、家里家外、体用关系、具体事象
- **九龙特色**：一位为真、十神吉恶平比例、补益应用

针对同一个八字，不同流派可能给出不同侧重的判断。
与其我们猜哪个准，不如让用户自己选。

## 玩法

### 入口
免费报告阶段，同时输出三个流派的简版三决断。

### 三流派输出格式
```
【子平视角】
条1：...
条2：...
条3：...

【盲派视角】
条1：...
条2：...
条3：...

【九龙视角】
条1：...
条2：...
条3：...
```

### 用户反馈
用户勾选认为最准的流派：
- "子平说得准"
- "盲派说得准"
- "九龙说得准"
- "都准/各有千秋"

### 后续处理
- 用户选定流派 → 深度报告以该流派为主体
- 用户选"都准" → 以子平为主体，融合其他流派观点
- 用户没反馈 → 默认以子平为主体（常规流程）
