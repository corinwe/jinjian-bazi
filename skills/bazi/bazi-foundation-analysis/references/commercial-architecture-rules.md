# 商业化架构与输出规则（2026-07-27 老板校准）

## 1. 分析流派声明
每次输出报告时，必须在报告开头明确声明流派依据：
> 本报告以子平法（格局法+旺衰法）为骨架，
> 融合九龙道长特色理论（一位为真、十神吉恶平比例），
> 以盲派做功理论为实证视角。
> 综合之：子平为主、九龙为佐、盲派为验。

铁律：不得隐性使用流派而不声明。流派声明是报告的第一段内容。

## 2. 标准报告格式——21§结构
所有八字分析报告必须采用21§标准格式：
§1总览→§2格局→§3身强弱→§4喜用→§5灾祸→§6性格→§7外貌→§8财富→§9置业→§10事业→§11学历→§12婚姻→§13子女→§14健康→§15六亲→§16大事表→§17大运精析→§18三决断→§19总评→§20补益→§21人生建议

铁律：不得只输出§2和§18就结束。必须覆盖全部21§或明确说明"本节暂无数据"。

## 3. 动态威胁分析规则（关键修正）
威胁不可写死为"比劫线"。必须根据八字喜忌动态判定：

| 八字类型 | 真实威胁 |
|:---------|:---------|
| 身强喜财被泄 | 比劫夺财 |
| 从弱格 | 印比逆势（土金） |
| 身弱不胜财 | 财星损身 |
| 火旺为病 | 水克火（心/眼） |
| 从强格 | 官杀破局 |
| 土旺金埋 | 木克土（消化） |

判断方法：
1. 看引擎输出的身强弱标签
2. 看引擎输出的喜用忌
3. 威胁 = 忌神五行对日主的克制方式
4. §8财富分析的破财风险必须基于此动态判定
