## 二、具体短缺的5项分析方法

### 1. 成中有败、败中有成（子平辨证逻辑）
**文档表述方式**：不说"格成"或"格败"，而说"成中有败、败中有成"。
- 乾1："身旺有通关则格成"——条件式判断，不是绝对化
- 乾2："建禄用财官则格成"——同样条件式
- 坤3："从格从得真则格成"——从得真=格成，从得假=格破

**我的问题**：我直接说"食伤生财格/从杀格"，不加条件。

**通用规则**：任何格局判断都要加条件——"在X条件下格成/在Y条件下格败"。

### 2. 清浊论——格局品质的评估标准
**文档表述**：
- "格局清而不雄"（乾1）= 财不透、官杀不透 → 正派但不霸气
- "财官俱真格正而清"（乾2）= 财透有根、官透有源 → 纯正又通透
- "从格从得真且从得净"（坤3）= 无一处比劫搅局 → 纯粹

**通用规则**：格局不仅要判断类型，还要判断品质——清/浊/雄/弱四个维度。

**清浊判定标准**：
- **清**：用神纯粹、无搅局、通关顺畅
- **浊**：用神被混（如官杀混杂）、通关断裂、比劫搅局
- **雄**：用神有力、势不可挡
- **弱**：用神虚浮、有等于无

### 3. 合化真假甄别——合而化 vs 合而绊
**文档**明确指出：
- 丙辛合财 = 是"绊"不是"化"（乾1的丙辛合）
- 午未合火 = 是"化"不是"绊"（坤3的午未合）
- 卯戌合火 = 是"化火"（乾2的卯戌合）

**通用规则**：凡是合，先判断是真化还是假化（绊住）：
- **真化**：化出的五行是用神且不被破坏 → 吉
- **假化**：化而不纯、被其他五行破坏 → 表面吉但内在受限
- **绊住**：只合不化，只是牵制作用 → 中性，视牵制的是什么而定

### 4. 分线断法——同一年吉凶并行
**文档处理方法**：
2024甲辰年：乾1"甲木透干走财线大吉 → 辰土困亥走身线则疾"
→ 同一年，财线和身线分开判断，财吉+身疾并行不悖。

**通用规则**：分析任何流年，必须把该年的各条线（财线/官杀线/身线/比劫线/夫妻线）分开判断：
- 一条流年可以：财线吉 + 身线凶 + 官杀线平
- 不能用"某年吉/某年凶"一言以蔽之

**分线方法**：
| 流年干支 | 财线(看财/食伤) | 官杀线(看官/杀) | 身线(看印/比) | 夫妻线(看日支) |
|:---------|:---------------|:---------------|:-------------|:--------------|

### 5. "以运证格"——从格判定的标准化操作
**文档流程**：
```
第一步：格局推测 → 怀疑是从格（日主无依+一方成势）
第二步：查过往大运 → 行印比运时人生苦还是顺？
第三步：苦 → 从格锁定（逆运则凶=从格）
        顺 → 非从格（扶身有效）
第四步：喜忌全颠倒 → 从哪个五行，那个五行就是用神
```

**我的问题**：我有从格判定条件但没把它写成"以运证格"的标准流程。

## 三、六体系协同分析框架（吸收后的新SOP）

**分析任何八字时，按以下顺序调用六体系：**

```
第一步：格局法 → 定层次
  用子平格局法取格，评估成/败/清/浊
  输出：格局类型 + 品质评价

第二步：扶抑法 → 定喜忌（初步）
  用旺衰法判断日主强弱
  输出：初步喜用忌

第三步：调候法 → 定气候
  用穷通宝鉴检查调候需求
  输出：调候用神

第四步：从格法 → 检查是否需要反转
  用三步锁判断是否从格
  如从格 → 喜忌全颠倒，跳过第五步
  输出：是否从格 + 最终喜忌

第五步：刑冲合害开库法 → 定机制
  分析原局的冲/合/刑/害/藏干/库
  输出：应期触发机制

第六步：大运流年应期法 → 定时间
  逐流年分析，每条线（财/官杀/身/夫妻）分开判断
  输出：流年吉凶总表 + 分线表
```
