# MingLi-Bench 与 xuzhaomeng.ai 借鉴与沉淀
日期：20260722

## MingLi-Bench
来源：https://github.com/DestinyLinker/MingLi-Bench
核心价值：面向大语言模型的中国传统命理评测基准（八字+紫微斗数）

### 关键设计
1. 160道选择题，来自全球算命师大赛（hkjfma.org）2022-2025真题
2. 评测方式：与标准答案完全一致=得分
3. 支持--astro参数：排盘与推理解耦（预先排好命盘，仅测试推理能力）
4. 支持--cot思维链：让模型逐步推演再给答案
5. 覆盖12大类事件：事业、健康、外貌、婚姻、子女、学业、官非、家庭、性格、灾劫、财运、运势

### 可借鉴之处
① 建立自己的分析质量评估机制：选择题+标准答案+自动评分
② 160道真题可用作训练/验证数据
③ 排盘与推理解耦的架构思路（与我们的引擎设计一致）
④ CoT思维链的设计：先推理后结论

## xuzhaomeng.ai（徐兆猛）
来源：https://xuzhaomeng.ai
定位：一人公司创始人，AI独立架构师
标签：Build in Public / AI产品 / 公开经营数据

### 核心模式
- 三大杠杆：AI（放大生产力）× 投资（放大本金）× 自媒体（放大影响力）
- 一人公司模式：一个人跑通产品→获客→商业化闭环
- 公开构建（Build in Public）：所有经营数据透明公开
- 多产品矩阵：同时跑4款产品

### 可借鉴之处
① 一人公司的经营理念：轻资产、高杠杆、可复制
② Build in Public：透明化建设信任（命理行业信任最重要）
③ 多产品矩阵打法而不是押注单款

## 沉淀到自动化体系

### 分析质量验证（新增步骤）
借鉴MingLi-Bench的评测思路，在我们的报告生成流程中增加后验证环节：

1. 每条报告生成后，从题库中抽取3-5道与命主八字相关的选择题
2. 让模型回答这些题，并与标准答案对比
3. 通过率≥80%则报告质量合格
4. 通过率<80%则回炉重写

### 题库建设
逐步将全球算命师大赛的真题转化为验证题库，
按事件类型（事业/财运/婚姻/子女/健康/学业）分类标注。
