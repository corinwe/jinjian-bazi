## 总纲：子平法核心思想

**一句话纲领：** 以日干为体（自身），以月令为纲（格局来源），以十神为用（吉凶语言）。

**经典原文依据：**
- 《继善篇》：「欲知贵贱，先观月令乃提纲；次断吉凶，专以日干为主本。」〔原文〕
  - 白话：断贵贱先看月令（月支是八字提纲），断吉凶以日干为核心主体。
- 《妖祥赋》：「命理深微，子平可推；先要取其日干，次则详其月令。」〔原文〕
  - 白话：先定日干，再详察月令，这是子平推命的固定顺序。

**操作顺序铁律（每次分析必按此序）：**
1. 排四柱（年月日时）
2. 定日干（日主）五行与旺衰
3. 看月令（月支）→ 定格局（本文档§1）
4. 依格局喜忌取用神（§3）
5. 排大运、看流年（§4、§5）
6. 套断语验证吉凶（§6）

**十神五类总表（《渊海子平》卷首原文）：**
> 「一曰官，分之阴阳，曰官、曰杀，甲乙见庚辛也；二曰财，分之阴阳，曰正财、偏财，甲乙见戊己也；三曰生气之阴阳，曰印绶、曰倒食，甲乙见壬癸是也；四曰窃气之阴阳，曰食神、曰伤官，甲乙见丙丁是也；五曰同类之阴阳，曰劫财、曰阳刃，甲乙见甲乙是也。」〔原文〕

|:----|:--------|:----------|

# §1 论月令定格

## 1.1 为什么以月令定格（提纲之义）

**原文依据：**
- 《继善篇》：「欲知贵贱，先观月令乃提纲。」〔原文〕
- 《五言独步》：「格中如去病，财禄喜相随。」〔原文〕（格中有病，去病即贵）

**原理（〔意〕）：**
1. 月令是五行之气最强旺之处（季节当令），代表一个人「先天禀气最厚」的部分。
2. 月支的十神决定了此人一生最主要的「人生主题」——是求财、求官、求名、还是求艺。
3. 月令之气旺，格局才「立得住」；年时之气散，不足以立格。

**结论：取格一律以月支为主，其余柱干支只作辅助、配合、救应，不作定格主体。**

## 1.2 取格四步法（优先级从高到低）

### 第一步：月令本气透干 → 取本气之十神为格
- 规则：月支藏干中力量最大的本气（占比60%），若透出在年、月、时干（天干四字任一），即以该透干十神定格。
- 例：甲日主，生于酉月，酉中本气辛金=甲木的正官，若辛金透出天干（如时干辛）→ **正官格**。
- 例：丙日主，生于子月，子中本气癸水=丙火的正官，若癸透 → **正官格**。
- 操作口诀：**「月令本气透干者，以透出之十神定格」**。

### 第二步：本气不透，中气/余气透干 → 取透出者为格
- 规则：月支本气未透，看中气（30%）、余气（10%）是否透干，透出哪个取哪个。
- 例：甲日主，生于丑月，丑中藏干：己土（本气60%，甲之正财）、癸水（中气30%，甲之正印）、辛金（余气10%，甲之正官）。己不透而癸透 → **正印格**（取中气）；己癸皆不透而辛透 → 正官格（取余气）。
- 注意：透干取格顺序仍以「本气>中气>余气」为先后，本气透出时即使中气也透出，仍取本气。

### 第三步：本气不透干，但月支与他支会合成局 → 取合化后之五行十神定格
- 规则：月支参与三合局/三会局（如申子辰合水、亥卯未合木、寅卯辰会木），且局成而不破（无冲散、无争合），以合化之五行十神定格。
- 例：壬日主，生于申月，地支申子辰全 → 申子辰合水局，水为壬之比劫 → 取「比劫/专旺类」看，旺极则论从旺或专旺。
- 例：戊日主，生于寅月，地支寅午戌全 → 寅午戌合火局，火=戊之印星 → 印格。
- 操作口诀：**「月支会合局者，以局神之十神定格」**。

### 第四步：本气不透、不合局 → 直接取月令本气十神定格
- 规则：即使本气不透干，仍以月支本气为格（格神在地支，靠岁运引出照样成立）。此为《渊海子平》「以提纲取格」正法。
- 例：甲日主，生于申月，申中庚金（七杀）不透干，仍定 **七杀格**（杀藏于提纲，岁运透出时发用）。
- 操作口诀：**「透者取透，不透取本」**。

### 五、月令无用可取时（月支为日主比劫且无官杀财印可立）
- 规则：月令本气是日主之比肩/劫财（如甲日寅月、乙日卯月），比劫不能立格（比劫非用神十神），此时：
  1. 看月支余气：寅中藏丙戊（食神、偏财）、卯中藏乙（无余气）、辰中藏戊乙癸……取透干或会合者。
  2. 若无，则从其他三柱（年/日/时支）找有力十神取格（称「暗格」「借格」）。
  3. 例：甲日寅月（建禄），寅中丙火（食神）透干 → 取食神格；不透则依本skill建禄格规则处理（§2.9）。
- 操作口诀：**「禄刃之月不立比劫格，另觅财官食伤印」**。

## 1.4 定格四大注意（清浊真假混杂）

### ① 官杀不可混杂
- 原文依据：《论正官》「如时干逢杀，乃官杀混杂。盖四柱有刑冲破害，皆未为贵命看。」〔原文〕
- 规则：正官格中，天干或地支再出现七杀（或反之），为「官杀混杂」，格局降级。去留之法：
  1. 留官去杀：合杀（如七杀被合）或制杀（食神制杀）。
  2. 留杀去官：合官或伤官克官。
  3. 两干并透无法去留 → 官杀混杂，一生是非多、职位多变动。
- 操作：看年/月/时干及地支藏干，凡官与杀同现（透干优先计），即触发混杂检查。

### ② 格重清纯
- 规则：同一十神在天干透出两位以上为「重见」：正官重见则「官多为杀」（《论官星太过》专论），财多则身弱难担，印多则母旺子衰（日主反被泄？印多身旺喜财）。
- 原文依据：《论官星太过》：「正官或多，反不为福。盖人之命，宜得中和之气，太过与不及同。」〔原文〕
- 操作：格局之神透干个数 ≥2 时，进入「太过」检查，按中和原则减分。

### ③ 真假之分（透干为真，藏支为假）
- 透干取格者称「真格」，藏支待透者称「假格」。
- 真格力量显于外，早年即见（年干透）或中年见（月干透）；假格须待大运流年引出。
- 操作：定格时注明「真/假」；断应期时，假格以透出之年为应期。

### ④ 有情无情（格局配合的吉凶倾向）
- 有情：格局之神与日主关系顺畅（如官格配印，印护官且生日主；财格配食神，食神生财）。
- 无情：格局之神互相打架（官格见伤官克官；财格见比劫夺财）。
- 操作：定格后必查「格神→日主」的完整生克链，断格局成色（§2各格成格条件即据此展开）。

## 2.1 正官格

### 取格条件
- 月令本气为正官（日主之正官，异阴阳相克），本气透干或不透按§1规则定格。
- 例：甲日酉月（辛正官）、乙日申月（庚正官）、丙日子月（癸正官）、丁日亥月（壬正官）、戊日卯月（乙正官）、己日寅月（甲正官）、庚日午月（丁正官）、辛日巳月（丙正官）、壬日未月（己正官）、癸日辰月（戊正官）。

### 原文总纲
- 《论正官》：「正官者，乃甲见辛、乙见庚之例。……又曰，于月令得之是也，喜身旺、印绶。如甲用辛官，喜土生官；最怕刑冲破害、阳刃七杀，为贫命；如时干逢杀，乃官杀混杂。盖四柱有刑冲破害，皆未为贵命看。」〔原文〕
- 白话：正官格喜身旺、喜印绶（印护官），最怕刑冲破害、羊刃、七杀；遇之则贫贱之命；时干见杀即官杀混杂；四柱有刑冲破害者不作贵命看。

### 成格条件（逐条可操作）
1. **官星要旺**：月令当令为正官，力量已足；不宜再被合去、被伤克。
2. **身旺能任**：日主有根（得令/得地/得生），印绶透出护官最佳（官印相生）。
3. **官星要纯**：只一位正官最贵（「官星有理会」），不可再见七杀（混杂）。
4. **不可见伤官**：伤官见官为祸百端（见§6断语1），伤官须被合去/被印制方解。
5. **刑冲破害全无**：年月日时支不得冲官星之支（如甲日酉官，卯冲酉、戌害酉、子刑酉〔酉酉自刑除外〕）、不得刑破。
6. **喜财生官**：财星（土）生官（金），「甲用辛官，喜土生官」，财官相生格更高。

### 贵格加分项
- 官印相生（印绶护官）→ 掌权之贵，清贵。
- 财官相生（财滋弱官）→ 富贵双全。
- 官星坐禄/坐库（如甲日辛官坐酉）→ 官位稳固。
- 时上一位官星独透 → 「时上一位贵格」类贵（见§2.12）。

### 破格条件（任一即破）
- 伤官透干克官（无解救）→ 破格，主官非、口舌、丢职。
- 官杀混杂（无去留）→ 降格，主多职多扰。
- 官星被合（如丙日癸官，戊合癸）→ 官被合去，贵气减半；合官者非贵即多情债。
- 日主太弱无印无根 → 官反为压力（「身弱官旺，受制于人」）。

### 吉凶断语
- 吉：官星一位清透，身旺印护 → 仕途显达，为人正直守规矩。
- 凶：见伤官 → 丢官罢职、官非口舌；见冲 → 官职调动频繁、离乡。
- 大运：喜财官印运；忌伤官运（伤官见官）、忌冲刑官星之运。

## 2.2 七杀格（偏官格、月上偏官格）

### 取格条件
- 月令本气为七杀（日主之七杀，同阴阳相克）。
- 例：甲日申月（庚杀）、乙日酉月（辛杀）、丙日亥月（壬杀）、丁日子月（癸杀）、戊日寅月（甲杀）、己日卯月（乙杀）、庚日巳月（丙杀）、辛日午月（丁杀）、壬日辰戌月（戊杀）、癸日丑未月（己杀）。
- 《渊海子平》专设「月上偏官格」：**「月上偏官却怕冲，与阳刃同；时上偏官不怕冲，与阳刃同。又要本身生日自旺，如甲乙日在正二月生是也。」**〔原文〕
  - 白话：月支七杀怕冲（冲则杀动攻身），时支七杀不怕冲；日主要旺（如甲乙木生于寅卯月）。

### 原文总纲
- 《论七杀》：「七杀者，如甲见庚之例。……喜身旺、印绶、食神制伏。忌身弱、财星生杀。」〔意〕
- 七杀诗诀：「偏官妙喜食神遂，印绶身强福禄丰；若见正官并枭用，却见死绝祸重重。」〔原文〕
  - 白话：七杀最喜欢食神制伏，配印绶身强则福禄丰厚；若再见正官（官杀混杂）又逢偏印（枭夺食则杀无制），再行死绝之地则灾祸重重。

### 成格条件（逐条可操作）
1. **七杀有制**：食神制杀（食神透干制月令之杀）→ 大贵（「杀有制化为权」）。制杀要恰当：杀强制强、杀弱制弱；制之太过（食神太旺）则杀无力，反主庸常。
2. **杀印相生**：印绶化杀（杀生印、印生身）→ 贵（「杀印相生，功名显达」）。无制有化亦可，化比制更高一层。
3. **身杀两停**：日主旺而七杀有力，两者势均 → 大贵之命（掌权柄、能任事）。
4. **羊刃合杀/驾杀**：羊刃（劫财）合杀或身强刃旺能抗杀 → 武将、权贵（「阳刃驾杀」）。
5. **日主有根**：「本身生日自旺」是七杀格成立的前提；身弱无印无食则杀攻身。

### 忌神与破格
- 身弱无制无化 → 杀攻身，主灾祸、病伤、官非、压力大。
- 财星生杀（财滋弱杀）→ 破格，财反助纣为虐。
- 官杀混杂无去留 → 降格。
- 杀无制又逢枭神夺食 → 杀复旺攻身，大凶（「若见正官并枭用，却见死绝祸重重」）。

### 吉凶断语
- 吉：食神制杀、杀印相生 → 权威、魄力、能屈能伸、白手起家掌实权。
- 凶：身弱杀旺 → 多灾多难、疾病伤残、牢狱官非；女命婚姻多波折。
- 大运：喜食神运、印绶运、身旺运（比劫禄刃）；忌财乡（生杀）、忌杀旺无制之运。

## 2.3 正财格

### 取格条件
- 月令本气为正财（日主所克、异阴阳）。
- 例：甲日未月（己财）、乙日辰月（戊财）、丙日酉月（辛财）、丁日申月（庚财）、戊日子月（癸财）、己日亥月（壬财）、庚日卯月（乙财）、辛日寅月（甲财）、壬日午月（丁财）、癸日巳月（丙财）。

### 原文总纲
- 《论正财》：「正财者，乃甲见己、乙见戊之例。……财喜身旺，不要刑冲破害。」〔原文〕
  - 白话：正财是日主克而能享用的资源；财格喜身旺，忌刑冲破害（冲财则财散）。

### 成格条件（逐条可操作）
1. **身旺任财**：日主强旺（得令得地得生）方能担财；「身旺财旺，富贵双全」。
2. **财星有根**：财星在地支有强根（长生/禄/旺/库），不透干亦可，透一位清用最喜。
3. **财不受伤**：无羊刃劫财夺财（劫财见财则分夺）、无比肩争财、无冲刑破害财之根。
4. **财官相生**：财旺能生官 → 富贵格局（「财旺生官，因财得贵」）。
5. **食神生财**：食神透干生财 → 财有源头，源源不绝（「食神生财，富贵自天来」）。

### 忌神与破格
- 身弱财旺 → 富屋贫人（「财多身弱，富屋贫人」〔意〕），财反为负担，主为财所累、病从财起。
- 比劫夺财（羊刃见财）→ 破格，主破财、合伙失利、钱财留不住。
- 财星被冲（财库逢冲须辨：冲开库则得财，冲散根则破财）→ 见§6断语。
- 正财偏财混杂且都透 → 财不纯，主多财源亦多耗散。

### 吉凶断语
- 吉：身旺财旺又透食伤 → 大富；财官相生 → 富而有贵。
- 凶：财多身弱 → 一生为财奔波、体弱、妻缘差（正财为妻）。
- 大运：喜食伤运（生财）、财运；忌比劫运（夺财）、忌身弱再行财杀运。

## 2.4 偏财格

### 取格条件
- 月令本气为偏财（日主所克、同阴阳）。
- 例：甲日辰戌月（戊财）、乙日丑未月（己财）、丙日申月（庚财）、丁日酉月（辛财）、戊日亥月（壬财）、己日子月（癸财）、庚日寅月（甲财）、辛日卯月（乙财）、壬日巳月（丙财）、癸日午月（丁财）。
- 《渊海子平》专设「时上偏财格」：**时柱天干偏财一位独透** → 特别贵（「时上偏财，怕比肩分夺」）。

### 原文总纲
- 《论偏财》：「偏财者，乃甲见戊、乙见己之例。……偏财主人慷慨，不甚吝财。」〔原文〕
- 时上偏财诗诀：「时上偏财一位佳，不须透出怕刑冲；运行财地财源旺，再行比劫主贫乏。」〔意〕（版本有异文）

### 成格条件（逐条可操作）
1. **身旺能任**：同正财格，身强才能担偏财。
2. **偏财宜藏**：偏财主人慷慨，透干多则露财招祸；藏支（尤其藏于时支/墓库）反主大财。
3. **时上一位偏财**：时干独透一位偏财，无劫财分夺 → 贵格（「时上偏财格」）。
4. **忌比劫分夺**：比肩劫财旺（尤其羊刃）见偏财 → 财被分夺，主破财、因兄弟朋友破财。
5. **喜食伤生财、财生官**：同正财格。

### 忌神与破格
- 比劫夺财（最忌羊刃见财）→ 破格。
- 偏财被冲合 → 财来财去。
- 身弱财旺无印 → 富屋贫人。

### 吉凶断语
- 吉：偏财旺而有食伤生 → 大富、人慷慨、人缘好、有经营才能；偏财亦主「众人之财」，利投资、横财。
- 凶：比劫夺财 → 因兄弟朋友、合伙、赌博破财。
- 大运：喜食伤运、财运；忌比劫禄刃运（夺财）。

## 2.5 正印格（印绶格）

### 取格条件
- 月令本气为正印（生日主、异阴阳）。
- 例：甲日子月（癸印）、乙日亥月（壬印）、丙日卯月（乙印）、丁日寅月（甲印）、戊日午月（丁印）、己日巳月（丙印）、庚日丑未月（己印）、辛日辰戌月（戊印）、壬日酉月（辛印）、癸日申月（庚印）。

### 原文总纲
- 《论印绶》：「印绶者，乃五行生我之名。……月逢印绶喜官星，运入官乡福必清；死绝运临身不利，后行财运百无成。」〔原文〕
  - 白话：印绶格最喜欢官星（官印相生），行官运则福气清显；行死绝之地则身不利，行财运则破印（财克印）百事不成。

### 成格条件（逐条可操作）
1. **印星当令**：月令本气为正印，力量最足。
2. **官印相生**：官星透出（官生印、印生身）→ 最贵组合（「官印相生」）。
3. **忌财破印**：财星（克印）不得透干、不得过旺；财印同透而印弱 → 财破印，主学业中断、母缘薄、文书官非。
4. **印星不受伤**：印之根不被冲刑；偏财合印/克印须防。
5. **身印相宜**：身弱印旺 → 印为慈母，主学问、靠山；身旺印重（枭印夺食者另论）→ 印多为忌，主孤、懒、依赖。

### 忌神与破格
- 财星破印（财透无救）→ 破格。
- 印星被合（如丙日乙印被庚合）→ 印被合去，靠山失。
- 枭神夺食（偏印夺食神）→ 见§2.6倒食格，主灾。

### 吉凶断语
- 吉：官印相生 → 学业有成、文职贵、有靠山长辈缘；印绶格主人聪明仁慈、重名誉。
- 凶：财破印 → 因财失学、因财失名、母亲健康受损、文凭官司。
- 大运：喜官杀运（生印）、比劫运（帮身）；忌财运（破印）、忌死绝运。

## 2.6 偏印格（倒食格、枭神格）

### 取格条件
- 月令本气为偏印（生日主、同阴阳）。
- 例：甲日亥月（壬枭）、乙日子月（癸枭）、丙日寅月（甲枭）、丁日卯月（乙枭）、戊日巳月（丙枭）、己日午月（丁枭）、庚日辰戌月（戊枭）、辛日丑未月（己枭）、壬日申月（庚枭）、癸日酉月（辛枭）。

### 原文总纲
- 《论倒食》：「倒食者，如甲见壬之类。……倒食者，名虽曰印，实则枭也。……忌见食神，见之则夺。」〔意〕
- 白话：偏印又称倒食，是「夺食之枭」；最忌见食神，见则夺食（枭神夺食）。

### 成格条件与吉凶（偏印为凶星，论其「化凶为吉」的条件）
1. **偏印有制**：偏印逢偏财（克枭）制之 → 凶星受制反为吉（「枭神逢财，反为福」〔意〕）。
2. **偏印化杀**：七杀生偏印、偏印生身 → 杀印相生之贵（偏印化杀比正印化杀更狠辣有力，主非常之才）。
3. **枭食同透须辨**：食神与偏印同透（枭神夺食）→ 主灾：学业受阻、断奶克子（女命）、夺食则财源断。
4. **身旺枭重** → 性格孤僻、多思多疑、学而不精；身弱枭重反得生扶。

### 破格条件
- 枭神夺食（食神格逢偏印）→ 大凶，主灾病、子女缘薄。
- 偏印无制又逢杀旺 → 枭杀攻身。

### 吉凶断语
- 吉：偏印化杀、偏印逢财 → 奇才异禀、偏门技艺成名。
- 凶：枭神夺食 → 破财断源、子女灾、健康受损。
- 大运：喜偏财运（制枭）、喜官杀运（化枭生身，视身强弱）；忌食神运（被夺）、忌枭旺运。

## 2.7 食神格

### 取格条件
- 月令本气为食神（日主所生、异阴阳）。
- 例：甲日巳月（丙食）、乙日午月（丁食）、丙日辰戌月（戊食）、丁日丑未月（己食）、戊日申月（庚食）、己日酉月（辛食）、庚日亥月（壬食）、辛日子月（癸食）、壬日寅月（甲食）、癸日卯月（乙食）。

### 原文总纲
- 《论食神》：「食神者，生我财神之谓也。……食神制杀，逢枭不贫则夭。」〔原文〕（「食神制杀，逢枭不贫则夭」为流传断语，见§6）
  - 白话：食神能生财，故为福星；食神制杀是贵格，但若逢枭神（夺食）则贫或夭。

### 成格条件（逐条可操作）
1. **食神当令**：月令本气为食神。
2. **食神生财**：财星透干，食神生财 → 富贵格（「食神生财，富贵自然来」）。
3. **食神制杀**：七杀透干，食神制之 → 贵格（「食神制杀，英雄独压万人」〔意〕）。
4. **食神要旺要纯**：一位食神最清；食神多则泄身太过（「食多身弱」）。
5. **忌枭神夺食**：偏印透干克食 → 破格大凶。
6. **身旺食神有力**：日主有根，食神泄秀 → 聪明才艺、口福、寿星。

### 忌神与破格
- 枭神夺食 → 破格（灾病、断财源）。
- 食神制杀而制之太过（杀弱食旺）→ 杀无力，格局庸常。
- 食神被合（合去食神则无生财之源）。

### 吉凶断语
- 吉：食神生财 → 富；食神制杀 → 贵；食神有气 → 长寿、口福、儿女孝顺（食神为女命之女、男命之福）。
- 凶：枭神夺食 → 灾；食多身弱 → 劳碌、健康差。
- 大运：喜财运（食生财）、比劫运（帮身任食）；忌枭印运（夺食）、忌食神过旺泄身。

## 2.8 伤官格

### 取格条件
- 月令本气为伤官（日主所生、同阴阳）。
- 例：甲日午月（丁伤）、乙日巳月（丙伤）、丙日未月（己伤）、丁日辰戌月（戊伤）、戊日酉月（辛伤）、己日申月（庚伤）、庚日子月（癸伤）、辛日亥月（壬伤）、壬日卯月（乙伤）、癸日寅月（甲伤）。

### 原文总纲
- 《论伤官》：「伤官者，其验如神。伤官务要伤尽；伤之不尽，官来乘旺，其祸不可胜言。伤官见官，为祸百端。倘月令在伤官之位，及四柱配合、作事皆在伤官之处；又行身旺乡，真贵人也。伤官主人多才艺、傲物气高。」〔原文〕
  - 白话：伤官应验如神；伤官格要把官星伤尽（不见官星）；若伤不尽，官星乘旺而来，灾祸不可说；「伤官见官，为祸百端」；若月令伤官，四柱又无官星，行身旺之运 → 真贵人；伤官之人多才艺、心高气傲。

### 成格条件（逐条可操作）
1. **伤官伤尽**：四柱天干地支（含藏干）不见官星（或官星被完全制合）→ 「伤官伤尽，贵不可言」。
2. **伤官生财**：财星透干，伤官生财 → 富格（「伤官生财，富贵自天来」）。
3. **伤官佩印**：印星透干制伤护身 → 贵格（「伤官佩印，贵不可言」）；身弱伤官旺必佩印。
4. **身旺伤官旺**：日主强旺，伤官泄秀 → 才华横溢、聪明绝顶（「伤官泄秀，聪明多能」）。
5. **忌见官星**：见官（无制）→ 官非口舌、丢职、伤病（伤官见官为祸百端）。
6. **忌伤官太旺身弱**：泄身太过 → 贫弱、克夫（女命伤官克官，夫缘差）。

### 各月伤官的特殊规则（伤官格分五种，〔意〕本于《渊海子平》体系）
| 月令 | 规则 |
|:----|:----|
| 火土伤官（夏月土伤官） | 忌见官星，喜财 |
| 土金伤官（秋月金伤官） | 忌见官星，喜财印 |
| 金水伤官（冬月水伤官） | 喜见官星（调候），金水伤官喜见官 |
| 水木伤官（春月木伤官） | 喜财官 |
| 木火伤官（夏月火伤官） | 喜印比，忌见官 |

### 吉凶断语
- 吉：伤官伤尽/生财/佩印 → 大才大富大贵，艺术家、科学家、创业者。
- 凶：伤官见官 → 官非牢狱、丢职、伤病；女命伤官重 → 克夫、婚姻不顺。
- 大运：喜财运、印运；忌官杀运（伤官见官）、忌身弱再行伤官运。

## 2.9 羊刃格（阳刃格）

### 取格条件
- 月令本气为日主之「阳刃」（帝旺之地，即劫财之极旺者）。
- 阳刃只论阳干：甲刃在卯、丙戊刃在午、庚刃在酉、壬刃在子（乙丁己辛癸阴干无刃，见刃以「劫财旺地」论）。
- 例：甲日卯月、丙日午月、戊日午月、庚日酉月、壬日子月。

### 原文总纲
- 《论阳刃》：「夫阳刃者，号天上之凶星，作人间之恶杀，以禄前一位是也；如甲禄在寅，卯为阳刃。喜偏官七杀，喜印绶；忌反吟伏吟，忌魁罡，忌三合。」〔原文〕
  - 白话：阳刃是凶星恶煞，是日主禄的前一位（甲禄寅，卯即刃）；喜七杀（刃驾杀）、喜印绶；忌反吟伏吟、忌魁罡、忌三合。
- 阳刃诗诀：「阳刃嫌冲合岁君，流年遇此主灾迍；三刑七杀如交遇，必定阎王出引徵。」〔原文〕
  - 白话：羊刃怕流年冲刃合刃，逢之主灾祸；若再遇三刑七杀，主大凶（有性命之忧）。

### 成格条件（逐条可操作）
1. **阳刃有制**：七杀透干制刃（「阳刃驾杀」）→ 大贵，武将、权威人物。
2. **阳刃有化**：印绶化刃生身 → 贵。
3. **身旺刃旺**：阳刃格本身身极旺，喜官杀制、食伤泄、财星耗。
4. **忌无制化**：刃旺无制 → 凶暴、破财、灾祸、克父克妻。
5. **忌财星见刃**：「时逢阳刃喜偏官，若见财星祸百端」（§6断语9）——刃见财则夺，祸多。
6. **忌冲刃合刃**：岁运冲刃（如甲日卯刃遇酉运）、合刃（如卯戌合）→ 灾祸。

### 吉凶断语
- 吉：阳刃驾杀 → 掌兵权、大贵；阳刃用印 → 武贵。
- 凶：刃旺无制 → 破财、凶灾、刑伤、克六亲；「阳刃之辰怕见官，刑冲破害祸千端；大嫌财旺居三合，断指伤残体不完」〔原文〕。
- 大运：喜七杀运、食伤运；忌财运（刃夺财）、忌冲刃合刃之运。

## 2.10 建禄格

### 取格条件
- 月令本气为日主之比肩（日主之禄地，临官）。
- 例：甲日寅月、乙日卯月、丙日巳月、丁日午月、戊日巳月、己日午月、庚日申月、辛日酉月、壬日亥月、癸日子月。

### 原文总纲
- 建禄格断语：「月令建禄，难招祖业；岁运临官，身旺无依？」〔意〕——流传断语：「月令建禄，多无祖屋；自挣自立，白手成家」。
  - 白话：建禄格多难继承祖业，靠白手起家。

### 成格条件（逐条可操作）
1. **建禄不取比肩为格**：月令为禄（比肩）不能立「比肩格」，须从月支余气/他柱另取格局（§1.2第五步）。
2. **建禄喜财官**：禄旺身强，喜财星（耗）、官杀（制）、食伤（泄）——「建禄格，喜财官食伤，忌比劫印」〔意〕。
3. **建禄逢官**：官星透干（如甲日寅月，天干辛官）→ 禄逢官，贵格（「建禄遇官，官职显达」〔意〕）。
4. **建禄逢财**：财星透干有根 → 富格（「建禄逢财，白手致富」〔意〕）。
5. **忌比劫再旺**：行比劫运、印运 → 身更旺无泄无制，主破财、孤、灾。
6. **忌禄被冲**：岁运冲禄（如甲日寅月，逢申运冲禄）→ 破禄，主变动、灾。

### 吉凶断语
- 吉：建禄逢财官 → 白手起家、独立自主、兄弟姐妹助力少靠自己。
- 凶：建禄无财官食伤 → 身旺无依，一生奔波劳碌、财来财去。
- 大运：喜财官食伤运；忌比劫印运。

## 2.11 杂气格（杂气财官格、杂气印绶格）

### 取格条件
- 月支为辰戌丑未（四墓库），以库中透干之财/官/印定格。
- 原文依据：《渊海子平》专设「杂气财官格」——辰戌丑未月，库藏财官印，须透干方显。

### 定格局规则（逐条可操作）
1. **先辨库中主气**：辰（水库：戊土本气、乙木、癸水）、戌（火库：戊土、辛金、丁火）、丑（金库：己土、癸水、辛金）、未（木库：己土、丁火、乙木）。
2. **透干取格**：库中财/官/印透出天干者，以透出者定格：
   - 透财 → 杂气财格；透官 → 杂气官格；透印 → 杂气印绶格。
   - 例：甲日辰月，辰中癸水（正印）透干 → 杂气印绶格；辰中戊土（偏财）透干 → 杂气财格。
3. **不透干则待冲**：库藏不透，须待岁运冲开墓库（如辰戌冲、丑未冲）方发用——「财官藏库，冲开则富」〔意〕。
4. **忌库被刑冲太过**：冲开得财，但冲刑太过则库破财散。

### 杂气格要点
- 原文：「财官印绶全备，藏蓄于月季之中。」〔原文〕（《喜忌篇》——财官印都藏在辰戌丑未库中，等待冲开/透出。）
- 操作：辰戌丑未月先查库中十神，再查透干，再查岁运冲库应期。

## 2.12 时上一位贵格（时上一位官/杀/财）

### 取格条件
- 时柱天干独透一位官星或七杀（「时上一位贵」），或时柱天干独透一位偏财（「时上偏财格」）。
- 原文依据：《渊海子平》「时上一位贵格」：**「时上偏官（七杀），只要一位，要行偏官运。」**〔原文〕

### 规则（逐条可操作）
1. 时干独透七杀一位（无官混杂、无比肩分夺）→ 贵格，子女宫好，晚年贵。
2. 时干独透偏财一位 → 大富格（「时上偏财格」），怕比肩分夺。
3. 时干独透正官一位（「时上正官」）→ 官星归时，晚年显达。
4. 忌重复：年月再有同字（双杀、双财）→ 降格。

## 2.13 从格（弃命从财、弃命从杀、从儿格、从旺格）

### 总原则
- 日主无根（地支无本气通根、天干无生扶），四柱某一行极旺，日主不得不「弃命相从」——顺旺势而行，不再扶身。
- 原文依据：《渊海子平》「弃命从财」「弃命从杀」两格专论。

### ① 弃命从财格
- 成格条件：
  1. 日主无根无印比（地支不见日主本气根，天干无印比透出帮扶）。
  2. 财星极旺（月令为财，地支财局成，或财星透干通根）。
  3. 旺财不可见劫夺，见比劫则「从之不真」。
- 吉凶：真从财 → 大富；行财运、食伤运 → 富上加富；行比劫运 → 破财灾祸（「从财忌比劫」）。
- 破格：原局见一比劫/印而无制 → 从格不真，反主贫贱多灾。

### ② 弃命从杀格
- 成格条件：
  1. 日主无根无印（有印则杀生印，不作从论）。
  2. 七杀极旺（月令为杀，杀透干通根，或杀局成）。
- 吉凶：真从杀 → 大贵（武贵、权贵）；行杀运、财运（财生杀）→ 贵；行印比运 → 从之不真，灾祸立至。
- 破格：见印透出（杀印相生则不从）、见食神制杀（制杀则不从）→ 均不作从杀论。

### ③ 从儿格
- 成格条件：
  1. 日主无根。
  2. 食神伤官极旺（月令为食伤，食伤局成），儿（食伤）旺生财。
  3. 喜财星（儿又生财），忌印星（枭夺食则儿绝）、忌官杀（逆儿势）。
- 吉凶：从儿 → 才华大成，艺术/技艺致富；「从儿不论身强弱，只要我儿又见儿（财）」〔意〕。

### ④ 从旺格（专旺/一行得气）
- 成格条件：日主极旺（得令、得地、得势，比劫印满盘），无财官食伤破局 → 从旺（顺其旺势）。
- 吉凶：从旺行比劫印运 → 大贵；行财官运 → 群比争财、旺极逆势，灾祸。
- 注：从旺与§2.14专旺格（曲直炎上等）是一体两面——从旺重「日主旺极」，专旺重「一行独秀」，操作上可合并判断。

### 从格判断清单（每次必查）
- [ ] 日主地支是否有根（本气通根）？无根才可从
- [ ] 天干是否有印比透出？无印比才可从
- [ ] 旺神是哪一行（财/杀/食伤/比劫）？
- [ ] 是否见「不从之神」（比劫/印/制神）而无制？
- [ ] 真从则顺旺势取用，假从（有根无助）则仍按扶抑

## 2.14 化气格（五合化气）

### 取格条件
- 日干与月干/时干/年干逢五合（甲己合、乙庚合、丙辛合、丁壬合、戊癸合），且合化成功 → 以化出之五行论格。

### 成化条件（逐条可操作，缺一不化）
1. **合神必须紧邻且无阻**：日干与月干或时干相合（紧贴方有力），中间无他干隔断。
2. **化神当令**：化出五行在月令当旺（如甲己合化土，生于辰戌丑未月）。
3. **化神透干**：化神在天干再透一位（如甲己化土，天干再透戊己）。
4. **日主无根**：日主地支无强根（有根则不化，或「合而不化」）。
5. **不被克破**：化神不被克（如化土忌木旺克）、不被争合（两甲争合一己为争合不化）。

### 五组化气表
| 合 | 化神 | 当令月 | 忌 |
|:--|:----|:------|:---|
| 甲己合 | 土 | 辰戌丑未月 | 木旺克土 |
| 乙庚合 | 金 | 申酉月 | 火旺克金 |
| 丙辛合 | 水 | 亥子月 | 土旺克水 |
| 丁壬合 | 木 | 寅卯月 | 金旺克木 |
| 戊癸合 | 火 | 巳午月 | 水旺克火 |

### 吉凶
- 化之真者：格局清奇，贵不可言（「化得真者只论化，化神还有几般话」〔意〕）。
- 化之不真（破化）：反主一生多变、身份错位、六亲缘薄。
- 大运：喜化神旺运、生化神之运；忌破化之运（克化神、引动日主本气）。

## 2.15 专旺格（一行得气：曲直、炎上、稼穑、从革、润下）

### 总原则
- 日主极旺，且全局五行归于一行（日主同党），无克泄耗破局 → 以该行名之。

| 格局 | 日主 | 成格条件 | 喜 | 忌 |
|:----|:----|:--------|:--|:---|
| 曲直格 | 甲乙木 | 生于寅卯月，地支亥卯未全或寅卯辰会木局，木旺成势 | 水（印）木（比劫）运 | 金（官杀逆势）、土重（财耗）、火泄过 |
| 炎上格 | 丙丁火 | 生于巳午月，地支寅午戌全或巳午未会火局 | 木火运 | 水旺（官杀逆势） |
| 稼穑格 | 戊己土 | 生于辰戌丑未月，地支土旺成势 | 火土运 | 木旺（官杀）、金水过 |
| 从革格 | 庚辛金 | 生于申酉月，地支巳酉丑全或申酉戌会金局 | 土金运 | 火旺（官杀逆势） |
| 润下格 | 壬癸水 | 生于亥子月，地支申子辰全或亥子丑会水局 | 金水运 | 土旺（官杀逆势）、火旺（财耗） |

### 规则（逐条可操作）
1. **得令**：生于本行当旺之月。
2. **成局**：三合局/三会局全（或本行地支三见以上）。
3. **无破**：不见克本行之官杀旺透、不见耗本行之财星成势。
4. **喜顺其势**：行印比运（生扶本行）→ 贵；行食伤运（泄秀）→ 富。
5. **忌逆其势**：行官杀运（克身）→ 灾祸；行财运 → 群比夺财。
6. 与从旺格区别：专旺格日主得令成局（顺势顺旺）；从旺格强调「弃命而从」。操作上可合并判断，喜忌一致。

# §3 论用神

## 3.1 《渊海子平》中的「用神」概念

- 古典子平法中，「用神」即「月令定格之神」（格神）——「用」者，取用之意；「用神」就是取月令最旺之气为用。
- 原文依据：《继善篇》「欲知贵贱，先观月令乃提纲」；《妖祥赋》「先要取其日干，次则详其月令」。〔原文〕
- 后世《子平真诠》把「格神」与「相神」（辅助格神之物）分开，本skill沿用：**格神=月令定格之神，用神=扶抑调候之实际取用**，两者多数时候同一，但须分别判断。

## 3.2 取用神五大原则（子平法）

### 原则一：月令优先（提纲为纲）
- 取用神第一看月令：月令本气即用神首选。
- 操作：月令本气若为日主所喜（能平衡命局）→ 直接用；若为忌（如身弱遇七杀当令）→ 取制化月令之物为用（食神制杀、印化杀）。

### 原则二：扶抑（身强身弱定喜忌）
- 身强（日主得令得地得势）→ 用克泄耗：官杀（克）、食伤（泄）、财（耗）。
- 身弱 → 用生扶：印（生）、比劫（帮）。
- 操作步骤：
  1. 数日主同党（比劫印）与异党（官杀财食伤）力量。
  2. 同党>异党 → 身强，取异党中最有力者为用。
  3. 异党>同党 → 身弱，取印（首选，能生身又能制食伤护身）或比劫为用。
  4. 身极强 → 从旺（顺其势，行印比）；身极弱 → 从弱（顺旺神之势）。

### 原则三：调候（寒暖燥湿）
- 冬生（亥子丑月）喜火（丙丁）暖局；夏生（巳午未月）喜水（壬癸）润局。
- 例：金水伤官（冬月金）喜见官（丙丁火调候）；夏月庚金喜壬水淘洗（「庚金用壬，夏金喜水」〔意〕）。
- 操作：调候用神与扶抑用神冲突时，先保调候（关乎生死层次），再论扶抑。

### 原则四：通关（两神相战取通关）
- 两行相战（如木土相战、金木相战、水火相战），取中间五行通关：
  - 木土战 → 火通关（木生火、火生土）。
  - 金木战 → 水通关（金生水、水生木）。
  - 水火战 → 木通关（水生木、木生火）。
- 操作：命局两大势力相克相战，用神取能化战为生的通关之神。

### 原则五：病药（有病方为贵）
- 原文依据：《继善篇》「有病方为贵，无伤不是奇；格中如去病，财禄喜相随。」〔原文〕
  - 白话：格局中带着「病」（忌神、破格之物），用「药」（制病之物）去之，反而成贵；没有病伤反显平庸。去病成功，财禄随之而来。
- 操作：先找格局之病（破格之神），再找去病之药（制病之神），药即用神：
  - 官格见伤官（病）→ 印星制伤护官（药）。
  - 杀格无制（病）→ 食神制杀（药）。
  - 财格见劫（病）→ 官星制劫护财（药）。
  - 印格见财（病）→ 比劫制财护印（药）。

## 3.3 用神成败与救应

### 成（用神有力）
- 用神得令、得地、得生、透干无伤 → 用神有力，格局成。
- 用神被生（食伤生财、官印相生）→ 用神有源头，格局高。

### 败（用神受伤）
- 用神被克（用财见劫、用官见伤、用印见财、用食见枭）→ 用神败。
- 用神被合（合去用神）→ 用神失。
- 用神无根（虚浮无地支根）→ 用神无力。

### 救应（败中求成）
- 败而有救 → 格局仍成，层次降一等：
  - 用财见劫 → 官杀透出制劫 → 救。
  - 用官见伤 → 印星透出制伤 → 救。
  - 用印见财 → 比劫透出制财 → 救。
  - 用食见枭 → 偏财透出制枭 → 救。

# §4 论大运起法与吉凶

## 4.1 起运规则（原文+算法）

### 原文依据
- 《渊海子平·论大运》：「凡起大运，俱从所生之日，阳男阴女，顺行数至未来节；阳女阴男，逆行数已过去节，俱折除三日为一岁。」〔原文〕
  - 白话：起大运都从出生那一天算起：阳年生的男命、阴年生的女命顺数到下一个「节」；阴年生的男命、阳年生的女命倒数到上一个「节」。用相隔的时间折算：三天折合一岁。

### 换算标准（逐条可操作）
1. **三天 = 一岁**（三天折合一年）
2. **一天 = 四个月**（一天折合四个月）
3. **一个时辰 = 十天**（一个时辰折合十天）

### 起运计算五步法
1. 定阴阳：年干为阳（甲丙戊庚壬）→ 阳年；年干为阴（乙丁己辛癸）→ 阴年。
2. 定顺逆：阳男阴女 → 顺行；阴男阳女 → 逆行。
3. 找节点：顺行 → 出生日到下一个「节」（立春/惊蛰/清明/立夏/芒种/小暑/立秋/白露/寒露/立冬/大雪/小寒，只算「节」不算「气」）；逆行 → 出生日到上一个「节」。
4. 算距离：出生时辰到节气的天数+时辰差。
5. 折算：3天=1岁，1天=4个月，1时辰=10天 → 得「X岁Y个月Z天起运」。

### 算例
- 例：甲子年（阳年）正月初二日生男，距惊蛰节尚有若干日……顺数至惊蛰；若距惊蛰 21 天 → 21÷3 = 7 → **7岁起运**（余数按天/时辰折算）。
- 例：乙丑年（阴年）生男，逆行数至上一个节（立春）；若距立春 1天12时辰 → 1天=4个月，12时辰=120天=4个月 → **8个月起运**（不足一岁即「周岁前起运」）。

### 大运排法
- 从月柱开始，顺行则月柱下一柱为第一步大运（干支各进一位）；逆行则月柱上一柱为第一步大运（干支各退一位）。
- 每步大运管十年；第一步大运自起运岁数开始，之后每十年换一步。

## 4.2 大运吉凶判断

### 原文依据
- 《五言独步》：「大运看支，流年看干？」〔意〕——传统：**运干管前五年，运支管后五年**（子平体系通行规则）。
- 《渊海子平》论行运喜忌散见各格：如《论印绶》「运入官乡福必清……后行财运百无成」〔原文〕——即大运吉凶按格局喜忌断。

### 判断规则（逐条可操作）
1. **大运十神定性**：每一步大运，以运干对日主之十神定性（运支同论，视力量主次）。
2. **喜用神运 = 吉运**：
   - 用神到位（如财格行食伤运生财）。
   - 调候到位（冬生行火运、夏生行水运）。
   - 通关到位（两行相战，运来通关之神）。
   - 去病到位（格局之病，运来药神）。
3. **忌神运 = 凶运**：
   - 忌神当令（如身弱行财杀运）。
   - 破格之神到位（官格行伤官运、财格行比劫运、印格行财运、食格行枭运）。
4. **大运与提纲（月令）的关系（最重）**：
   - 大运冲提纲（月支被运支冲）→ 一生大变动之年运（「运冲提纲，变动最大」〔意〕）：冲提纲往往主大起大落、搬家、换工作、甚至生死关口，须结合喜忌断吉凶方向。
   - 大运合提纲 → 安定、合作、婚恋应期。
   - 大运刑提纲 → 刑伤、官非、病灾应期。
5. **大运与日柱的关系**：
   - 运支与日支天克地冲 → 大变动（婚变、健康大关、职业剧变）。
   - 大运合日柱（运干合日干）→ 婚恋、合作、易被合走（女命尤验）。
6. **岁运并临与大运转换**：见§5。

### 大运吉凶分级
| 等级 | 定义 | 示例 |
|:----|:----|:----|
| 上吉运 | 用神得地得生，格局进级 | 官格行印运、财格行食伤运 |
| 中吉运 | 平顺无灾，小有进益 | 行比劫运（身弱）、行闲神运 |
| 平运 | 平淡过渡 | 闲神、无关喜忌之运 |
| 凶运 | 忌神得势 | 身弱行杀运、官格行伤官运 |
| 大凶运 | 忌神+破格+冲提纲叠加 | 忌神运又冲提纲又逢三刑 |

## 4.3 大运操作检查清单
- [ ] 此步大运干是什么十神？支是什么十神？
- [ ] 是喜是忌？（对照§3.4用神表）
- [ ] 运支是否冲/合/刑月支（提纲）？
- [ ] 运支是否冲/合日支（夫妻宫/自身）？
- [ ] 运干是否合日干？运支是否合日支？
- [ ] 是否填实外格虚拱（拱禄拱贵被填实则破）？
- [ ] 运中是否引动墓库（冲开则发、闭库则藏）？

# §5 论流年吉凶

## 5.1 流年基本规则

- 流年即「太岁」，一年一换；流年干管当年上半年（或全年之象），流年支管下半年（传统「干管上半年、支管下半年」〔意〕；与大运「干管五年支管五年」尺度不同）。
- 流年吉凶 = 流年十神 × 与大运互动 × 与命局互动，三者叠加。

## 5.2 流年与大运互动（核心规则）

### ① 岁运并临
- 定义：流年与大运干支完全相同（如大运甲子、流年甲子）。
- 断语：「岁运并临，不死自己也死他人」〔意〕（流传断语，须辨证）。
- 操作：岁运并临是吉凶大放大之年：喜用神 → 大吉大利（升迁发财）；忌神 → 大凶（灾祸、六亲损）。**必查喜忌再断，不可一见并临即断凶。**

### ② 天克地冲
- 定义：流年干支与大运干支天干相克、地支相冲（如大运庚申、流年丙寅——丙克庚、寅冲申）。
- 操作：天克地冲 = 大动荡应期：喜 → 大变革向好（转业、搬迁、婚嫁）；忌 → 大灾（破财、官非、伤病、婚变）。

### ③ 流年冲提纲（月令）
- 定义：流年支冲月支。
- 断语：「太岁冲提纲，祸福此年详」〔意〕；月令为纲，冲则动摇根基。
- 操作：冲提纲之年，人生大事应期（换工作、搬家、婚丧、健康关口）；吉凶方向看流年干之喜忌与所冲之十神：
  - 冲去忌神 → 吉（去病）。
  - 冲去用神/冲旺忌神 → 凶。

### ④ 流年与命局合会
- 流年支与命局地支成三合/六合/三会 → 引动该五行（合出喜用则吉，合出忌神则凶）。
- 流年干合日干 → 婚恋/合作/被合走之年。
- 流年支合日支 → 婚恋应期（男财星合入、女官星合入）。

### ⑤ 流年填实外格
- 拱禄拱贵/飞天禄马等虚拱外格，流年填实拱出之字 → 破格或应事（填实为用神则得，为忌神则祸）。

### ⑥ 流年引动墓库
- 流年冲开墓库（辰戌冲、丑未冲）→ 库中之物发用（财库冲开得财、官库冲开得官、印库冲开得名；反之闭库则藏而不发）。

## 5.3 流年吉凶判断十步清单
1. 流年干对日主是什么十神？喜还是忌？
2. 流年支对日主是什么十神？喜还是忌？
3. 流年与大运是否岁运并临？（吉凶放大）
4. 流年与大运是否天克地冲？（大动荡）
5. 流年是否冲提纲月支？（根基动摇）
6. 流年是否冲日支？（夫妻宫/自身）
7. 流年是否刑命局（三刑成局）？（官非病灾）
8. 流年是否合日干/日支？（婚恋合作）
9. 流年是否引动三合/三会局？（五行发力）
10. 综合喜忌+叠加项 → 定吉凶方向与应事类别（事业/财运/婚姻/健康/六亲）。

## 5.4 流年断事示例（操作示范）
- 例：身弱财旺之命（忌财），流年逢比劫（帮身任财）→ 吉，得财之年（群比帮身可担财）。
- 例：官格（用官），流年逢伤官 → 凶，「伤官见官为祸百端」，主官非、丢职、口舌（除非原局有印制伤救应）。
- 例：七杀格食神制杀（用食），流年逢枭神 → 凶，枭神夺食，杀无制攻身，主灾病。
- 例：日主弱、忌杀，流年杀旺又逢财生杀 → 大凶，防官非病灾。

# §6 《渊海子平》经典断语精选

> 每条格式：原文 → 出处 → 白话 → 应用规则（可直接套用）。

## 6.1 伤官类断语

### 断语1：伤官见官，为祸百端
- **原文：** 「伤官务要伤尽；伤之不尽，官来乘旺，其祸不可胜言。伤官见官，为祸百端。」〔原文〕
- **出处：** 《渊海子平·论伤官》（《喜忌篇》亦引此语）。
- **白话：** 伤官格必须把官星伤尽（命局完全不见官星）；若伤不尽，官星乘旺而来，灾祸无法言说。伤官遇上官星，百种祸端。
- **应用规则：**
  1. 伤官格四柱（含藏干）见正官 → 先断「祸」：官非口舌、丢职罢官、伤病、牢狱。
  2. 伤官格逢大运/流年见官星 → 该运/年应祸（丢职、官非、婚变）。
  3. 有救则减：印星透干制伤护官（伤官佩印）→ 祸解反贵；财星透干（伤官生财，财可通关——伤生财、财生官）→ 祸减。
  4. 操作顺序：见官 → 查有无印/财救应 → 无救断凶，有救断吉凶减半。

### 断语2：伤官务要伤尽；伤之不尽，官来乘旺，其祸不可胜言
- **出处：** 《渊海子平·论伤官》〔原文〕（见上）。
- **白话：** 伤官格要伤尽官星；伤不干净，官星一旺就要来报复，灾祸不可说。
- **应用规则：** 伤官格喜忌判断第一句：原局有无官星（含地支藏干）→ 有则查解救 → 无则「伤尽」，主清贵有才。

### 断语3：伤官主人多才艺，傲物气高
- **原文：** 「伤官主人多才艺，傲物气高，好胜，常以天下人不如己。」〔原文〕
- **出处：** 《渊海子平·论伤官》。
- **白话：** 伤官之人多才多艺、心高气傲、好胜心强，常觉得天下人不如自己。
- **应用规则：** 断性格：伤官旺/透干 → 才艺+傲气+不服管+口才佳；伤官为忌 → 恃才傲物、人际关系差、易得罪人。

### 断语4：年带伤官，父母不全；月带伤官，兄弟不完；日带伤官，妻妾不完；时带伤官，子息无传
- **原文：** 「年带伤官，父母不全；月带伤官，弟不完；日带伤官，妻妾不完；时带伤官，子息无传。」〔原文〕（《论伤官》）
- **白话：** 伤官在年柱伤父母（父母不全、早克）；在月柱伤兄弟；在日柱伤配偶；在时柱伤子女（子息无传）。
- **应用规则：** 伤官所在宫位 → 断对应六亲缘薄/受损；伤官无制尤验；有印救应则减。

## 6.2 官星类断语

### 断语5：官星怕刑冲破害（最怕刑冲破害、阳刃七杀，为贫命）
- **原文：** 「如甲用辛官，喜土生官；最怕刑冲破害、阳刃七杀，为贫命；如时干逢杀，乃官杀混杂。盖四柱有刑冲破害，皆未为贵命看。」〔原文〕
- **出处：** 《渊海子平·论正官》。
- **白话：** 甲日用辛金为官，喜土（财）生官；最怕官星被刑、冲、破、害，也怕羊刃和七杀，遇之则为贫命；时干见杀就是官杀混杂；四柱有刑冲破害的都不算贵命。
- **应用规则：**
  1. 正官格检查官星之支：被冲（如酉官遇卯）、被刑（三刑及官星被刑）、被破（害）→ 贵气大减。
  2. 官星见羊刃（劫财）→ 官被刃劫，主贫、丢职。
  3. 官杀混杂 → 降格，断「多职多扰、一生是非」。
  4. 操作：正官格四步查——①有无伤官克官 ②有无冲刑破害 ③有无官杀混杂 ④身旺否。

### 断语6：正官或多，反不为福；宜得中和之气
- **原文：** 「正官或多，反不为福。何以言之？盖人之命，宜得中和之气，太过与不及同。」〔原文〕
- **出处：** 《渊海子平·论官星太过》。
- **白话：** 正官太多反而不好——命贵在中和，太过和不及一样是病。
- **应用规则：** 官星透干2位以上（或官杀并见）→ 官多为杀，断压力大、官职多虚、小人多；须印化解（官印相生泄官气）。

## 6.3 七杀类断语

### 断语7：偏官妙喜食神遂，印绶身强福禄丰；若见正官并枭用，却见死绝祸重重
- **原文：** 「偏官妙喜食神遂，印绶身强福禄丰；若见正官并枭用，却见死绝祸重重。」〔原文〕
- **出处：** 《渊海子平》七杀/偏官诗诀。
- **白话：** 七杀最喜欢食神制伏，配印绶且身强则福禄丰厚；若见正官（混杂）又用偏印（夺食），再行死绝之地则灾祸重重。
- **应用规则：** 七杀格吉凶链：有食神制 → 吉；食神+身强+印 → 大吉；官杀混杂+枭神夺食 → 凶；再行死绝运 → 大凶。

### 断语8：七杀有制化为权，羊刃无制祸绵绵〔意〕
- **出处：** 渊海子平体系流传断语（《论七杀》《论阳刃》之义）。
- **白话：** 七杀有制伏就化为权柄（贵），羊刃没有制伏就灾祸不断。
- **应用规则：** 杀刃两凶星，断吉凶先问「有制无制」：有制（食制/印化/刃驾）→ 权贵；无制 → 灾祸。

### 断语9：时逢阳刃喜偏官，若见财星祸百端；岁运相冲并相合，勃然灾祸又临门
- **原文：** 「时逢阳刃喜偏官，若见财星祸百端；岁运相冲并相合，勃然灾祸又临门。」〔原文〕
- **出处：** 《渊海子平·论阳刃》诗诀。
- **白话：** 时柱逢阳刃喜见七杀（刃驾杀为贵）；若见财星则祸端百出（刃夺财）；岁运再冲刃合刃，灾祸立刻临门。
- **应用规则：** 阳刃格/时上阳刃：喜杀、忌财、忌岁运冲刃合刃。查流年大运是否冲/合刃之支 → 是则断灾。

## 6.4 羊刃类断语

### 断语10：阳刃者，号天上之凶星，作人间之恶杀，以禄前一位是也
- **原文：** 「夫阳刃者，号天上之凶星，作人间之恶杀，以禄前一位是也；如甲禄在寅，卯为阳刃。喜偏官七杀，喜印绶；忌反吟伏吟，忌魁罡，忌三合。」〔原文〕
- **出处：** 《渊海子平·论阳刃》。
- **白话：** 阳刃是天上的凶星、人间的恶煞，是日主禄的前一位（甲禄在寅，卯就是刃）；喜七杀和印绶；忌反吟伏吟（岁运与命局天克地冲/天地同字）、忌魁罡、忌三合（合刃）。
- **应用规则：**
  1. 阳刃定位：甲卯、丙午、戊午、庚酉、壬子（阳干禄前一位）。
  2. 阳刃格喜忌：喜杀（驾）、喜印（化）；忌岁运冲刃、合刃、见财。
  3. 反吟伏吟：大运/流年与命局某柱天克地冲为反吟、干支相同为伏吟 → 阳刃逢之断灾。

### 断语11：阳刃嫌冲合岁君，流年遇此主灾迍；三刑七杀如交遇，必定阎王出引徵
- **原文：** 「阳刃嫌冲合岁君，流年遇此主灾迍；三刑七杀如交遇，必定阎王出引徵。」〔原文〕
- **出处：** 《渊海子平·论阳刃》诗诀。
- **白话：** 阳刃怕流年冲刃合刃，逢之主灾祸困顿；若同时遇到三刑和七杀，则有性命之忧（阎王来引）。
- **应用规则：** 阳刃命查流年：流年冲刃/合刃 + 三刑成局 + 七杀旺 → 大凶叠加，断重灾，须提醒化解。

### 断语12：阳刃之辰怕见官，刑冲破害祸千端；大嫌财旺居三合，断指伤残体不完
- **原文：** 「阳刃之辰怕见官，刑冲破害祸千端；大嫌财旺居三合，断指伤残体不完。」〔原文〕
- **出处：** 《渊海子平·论阳刃》诗诀。
- **白话：** 阳刃之日怕见官星，刑冲破害灾祸千端；最怕财旺又成三合局（刃夺财），主伤残破体。
- **应用规则：** 阳刃格忌官（官刃相冲）、忌财旺三合 → 断伤残、手术、破财。

## 6.5 枭神/食神类断语

### 断语13：食神制杀，逢枭不贫则夭
- **原文：** 「食神制杀，逢枭不贫则夭。」〔原文〕（《论食神》）
- **白话：** 食神制杀的贵格，一旦遇到枭神（偏印夺食），不贫穷就短命。
- **应用规则：** 七杀格用食神制杀 → 若原局或岁运见偏印 → 断枭神夺食：破财、灾病、寿元受损；女命兼断子女灾。

### 断语14：枭神夺食，其祸甚烈〔意〕
- **出处：** 渊海子平体系流传断语（《论倒食》之义）。
- **白话：** 偏印夺食神，灾祸很猛烈。
- **应用规则：** 食神格/食神为用 → 岁运见枭（尤其流年干为偏印）→ 断：断财源、失业、病灾、子女灾（食神为子女星）。

## 6.6 财星类断语

### 断语15：财喜身旺，不要刑冲破害
- **原文：** 「财喜身旺，不要刑冲破害。」〔原文〕（《论正财》）
- **白话：** 财星喜欢身旺（身旺才能担财），财星不要被刑冲破害。
- **应用规则：** 财格检查：①身旺否（身弱则富屋贫人）②财之根是否被冲刑破害（被冲则财散）。

### 断语16：财多身弱，富屋贫人〔意〕
- **出处：** 渊海子平体系流传断语（《论正财》「财多身弱」之义，《继善篇》亦论）。
- **白话：** 财多而身弱，就像住在金屋里却挨饿的穷人——看得到财，拿不到。
- **应用规则：** 财星多旺而日主无根少帮 → 断：为财奔波却难聚财、因财致病、财来财去；行比劫运/印运帮身时得财。

### 断语17：财官印绶全备，藏蓄于月季之中
- **原文：** 「财官印绶全备，藏蓄于月季之中。」〔原文〕（《喜忌篇》）
- **白话：** 财、官、印都齐备，且藏在辰戌丑未（四季月/杂气）的库中。
- **应用规则：** 辰戌丑未月生人，查库中是否财官印俱全（如戌中戊财、丁官、辛印之类）→ 全则贵格，等冲库/透干之年发福（「财官藏库，冲开则富」）。

## 6.7 金神/魁罡类断语

### 断语18：金神入火乡，富贵天下响
- **原文：** 「金神入火乡，富贵天下响。」〔原文〕（《论金神》/金神格诗诀）
- **白话：** 金神（乙丑、己巳、癸酉时）喜入火地（火运、火旺之局），一入火乡就大富大贵，名震天下。
- **应用规则：** 金神格查火：原局火旺（寅午戌、巳午）或行南方火运 → 断大贵；忌水（水克火则金神无制）→ 断庸常。

### 断语19：魁罡四日最为先，叠叠相逢掌大权
- **原文：** 「魁罡四日最为先，叠叠相逢掌大权。」〔原文〕（魁罡诗诀）
- **白话：** 魁罡日（庚辰、庚戌、壬辰、戊戌）格局最尊，魁罡重叠出现的人掌大权。
- **应用规则：** 日柱为魁罡 + 年月时再逢魁罡（重叠）→ 断掌权；魁罡忌见财官（庚戌庚辰怕见官杀）→ 见之减贵；魁罡逢刑冲 → 断灾。

## 6.8 建禄/禄刃类断语

### 断语20：月令建禄，难招祖业〔意〕
- **出处：** 渊海子平体系建禄格流传断语。
- **白话：** 月令建禄的人，难以继承祖上产业。
- **应用规则：** 建禄格断「白手起家」：祖业难承、自立门户；配财官则成格致富，无财官则一生劳碌。

## 6.9 女命类断语（《渊海子平·女命》歌诀精选）

### 断语21：阳刃带伤官，驳杂事多端
- **原文：** 「阳刃带伤官，驳杂事多端。」〔原文〕（《女命》篇）
- **白话：** 女命阳刃带伤官，一生是非驳杂、婚姻多波折。
- **应用规则：** 女命查刃+伤官同现 → 断婚姻不顺、性格刚烈、克夫之象（须看官星有无救应）。

### 断语22：财官若藏库，冲破岂不富
- **原文：** 「财官若藏库，冲破岂不富。」〔原文〕（《女命》篇）
- **白话：** 财官藏在墓库里，一旦冲开，哪能不富？
- **应用规则：** 财库/官库逢冲（辰戌冲、丑未冲）→ 断得财得官之应期；男命财库冲开主富，女命官库冲开主夫荣。

### 断语23：官星若不合，夫主无所依
- **原文：** 「官星若不合，夫主无所依。」〔原文〕（《女命》篇）
- **白话：** 女命官星（夫星）若不合（不入命局/被合去），丈夫没有依靠（夫缘薄）。
- **应用规则：** 女命查官星：无官星或官星被合去 → 断夫缘薄、婚姻迟、或配偶无力。

## 6.10 其他通用断语

### 断语24：官禄贵马见合刑，一举便成名
- **原文：** 「官禄贵马见合刑，一举便成名。」〔原文〕（《心镜歌》）
- **白话：** 官星、禄神、天乙贵人、驿马遇到合或刑，一举成名。
- **应用规则：** 岁运合官星/合禄神/合贵人 → 断成名、升迁、考试高中之应期（与§5合日主断法呼应）。

### 断语25：有病方为贵，无伤不是奇；格中如去病，财禄喜相随
- **原文：** 「有病方为贵，无伤不是奇；格中如去病，财禄喜相随。」〔原文〕（《继善篇》）
- **白话：** 格局带病（有忌神）反而能成贵，没有病伤反不出奇；格局中的病被药去掉，财禄就跟着来了。
- **应用规则：** 断格局成色：先找病（破格之神），再找药（制病之神）；药在命局 → 成贵；药在岁运 → 行药运时发；无药 → 病格待运。

### 断语26：欲知贵贱，先观月令乃提纲；次断吉凶，专以日干为主本
- **原文：** 「欲知贵贱，先观月令乃提纲；次断吉凶，专以日干为主本。」〔原文〕（《继善篇》）
- **白话：** 想知道贵贱，先看月令（提纲）；再断吉凶，以日干为主。
- **应用规则：** 全篇总纲：任何分析先月令定格、再日干定旺衰，顺序不可颠倒。

### 断语27：月上偏官却怕冲，与阳刃同；时上偏官不怕冲
- **原文：** 「月上偏官却怕冲，与阳刃同；时上偏官不怕冲，与阳刃同。」〔原文〕（《月上偏官格》）
- **白话：** 月支七杀怕被冲（冲杀攻身），与时支七杀不一样——时支七杀不怕冲。
- **应用规则：** 七杀格看位置：杀在月支 → 忌岁运冲月支；杀在时支 → 冲亦无妨。

```
两行战 → 通关神

```

```
阳男阴女顺行，阴男阳女逆行
数至下一节（顺）/上一节（逆）
3天=1岁，1天=4月，1时辰=10天
干管前五年，支管后五年
运冲提纲=大变动；运合日柱=婚恋合作
```

## 流年
```
干管上半年，支管下半年
岁运并临=吉凶放大
天克地冲=大动荡
冲提纲=动摇根基
合日干/日支=婚恋合作应期
枭夺食、伤见官、刃冲合 → 三大凶年信号
```

## 三大凶年信号（优先报警）

3. **阳刃冲合**：阳刃格 → 流年大运冲刃/合刃 → 灾祸，叠加三刑七杀则大凶。
