## 一、十天干核心逻辑

### 1.1 土（戊己）的阴阳转化规则 ★杨清娟独有难点
土的阴阳是最难判定的，因为土本身"亦阴亦阳"：
- **单柱同柱判定**（死记硬背）：
  - 戊土见巳火=阳土得生（火生土）
  - 己土见巳火=阴土见阳火（火土混杂）
  - 关键看同柱组合：戊午=阳土坐阳刃，己巳=阴土坐印
- **命局整体判定**：
  - 土多火多=阳土（燥土，脆金）
  - 土多水多=阴土（湿土，生金）
  - 辰丑=湿土（阴），未戌=燥土（阳）

### 1.2 地支四土详解（断事精准度关键）
| 四土 | 阴阳 | 特性 | 断事要点 |
|:-----|:-----|:-----|:---------|
| 辰 | 湿土（阴） | 水库，蓄水生金 | 辰土晦火、生金，见火则晦 |
| 丑 | 湿土（阴） | 金库，寒湿 | 丑土生金，寒金需火暖 |
| 未 | 燥土（阳） | 木库，燥热 | 未土脆金不生金，见火更燥 |
| 戌 | 燥土（阳） | 火库，焦燥 | 戌土脆金，藏丁火 |

### 1.3 虚实断事法（决定成败的关键）
- **虚透**：天干透出但地支无根（如甲木透干但地支无寅卯亥）→ 虚浮无力，断事减半
- **实透**：天干透出且地支有根 → 有力，断事加倍
- 虚透十神的断法：主虚名虚利、口头应承、表面风光
- 实透十神的断法：主实际得到、落地兑现

### 1.4 合克得财定律（绝对真理）
- **相生力量法则**：生我者有力量来源（如金生水，金为水之源头）
- **合克得财定律**：合住忌神、克掉忌神，就是得财（如财被劫财合克，反而得财）
- 关键：不是"财多就好"，而是"财为我用"——合克得财 > 单纯有财

### 1.5 十天干实战速查表
- 方位：甲乙=东，丙丁=南，戊己=中，庚辛=西，壬癸=北
- 颜色：甲乙=青绿，丙丁=红紫，戊己=黄棕，庚辛=白金银，壬癸=黑蓝
- 五常：木=仁，火=礼，土=信，金=义，水=智
- 行业：木=文教农林，火=能源餐饮，土=房产建筑，金=金融金属，水=流通贸易

### 2.2 地支三合局
- 申子辰合水局、寅午戌合火局、巳酉丑合金局、亥卯未合木局
- **生地半合**（力量次于三合）：申子、寅午、巳酉、亥卯
- **墓地半合**（力量更弱）：子辰、午戌、酉丑、卯未

### 2.3 地支相冲及相克
- 丑未冲、寅申冲、巳亥冲、卯酉冲、辰戌冲、子午冲
- 相冲=动、变、散；力量大者冲散力量小者
- **相穿一定要看力量**：穿=暗中伤害，比冲更隐蔽持久

### 2.4 地支相穿
- 子未穿、丑午穿、卯辰穿、酉戌穿、申亥穿、寅巳穿
- 相穿=暗害、内耗、慢性问题，主暗中小人、隐疾

### 2.5 地支相破
- 卯子破、卯午破
- 相破=破损、离散，力量较轻

### 2.6 四墓库（辰戌丑未）
- 辰=水库，戌=火库，丑=金库，未=木库
- **墓库和土的生克关系**：库逢冲则开（开库），库逢合则闭
- 开库三要素：冲开（辰戌冲/丑未冲）、合开（卯戌合/子丑合）、透开（库中藏干透干）

### 2.7 四中神与四隅神
- 四中神：子午卯酉（正气之神，力量专一）
- 四隅神：寅申巳亥（驿马之神，主变动）

## 五、第一编·宾主与家里家外（杨清娟体系核心）

### 5.1 宾主定位：命局的"我"与"他"

**主位（日主掌控的核心底盘）**：
- 日干=我（核心主体）
- 日支=我的家（配偶宫、内心）
- 时柱=我的晚年、子女、归宿

**宾位（外界环境与他人势力）**：
- 年柱=祖上、远方、社会大环境
- 月柱=父母、单位、社会关系
- 天干=外（表面），地支=内（实质）

**宾主关系的六重境界**（从低到高）：
1. 宾来就主（宾主动来合我、找我）→ 贵人上门，坐享其成
2. 主去求宾（我去找宾）→ 辛苦奔波，求财在外
3. 宾主相合（互相合作）→ 合作共赢，但要看合的方向
4. 主控宾（我控制他）→ 掌权、领导
5. 宾控主（他控制我）→ 被压制、为他人做嫁衣
6. 宾主失和（刑冲穿害）→ 灾福之源，冲突不断

**宾主实战铁律**：
- 宾来就主=贵人上门·坐享其成（吉）
- 主去求宾=辛苦奔波·求财在外（劳）
- 宾夺主权=比劫夺财·小人作祟（凶）
- 宾主失和=刑冲穿害·灾福之源（凶）

### 5.2 家里家外：断事的空间法则

**四宫划分：年月为外，日时为内** ★
| 宫位 | 内外 | 含义 |
|:-----|:-----|:-----|
| 年柱 | 外 | 祖上、远方、社会大环境 |
| 月柱 | 外 | 父母、单位、社会关系 |
| 日支 | 内 | 配偶宫、内心、家庭 |
| 时柱 | 内 | 子女、晚年、归宿 |

**核心规则**：
- 财在"家里"（日时）才代表真欲望、真理想、真财富
- 财在"家外"（年月）= 为别人赚钱、为公家打工
- 官杀在"家里"= 自己掌权；官杀在"家外"= 为他人效力
- 工作在外取财（年月）→ 公家单位；工作在家取财（日时）→ 私营个体
- 家里有财库（日支坐财库）= 家里有财，富贵根本

**十神定位"家与外"**：
- 比劫克财 → 初断克父（结合父母宫位）
- 羊刃配杀 → 贵气十足（结合内外宫位）
- 化杀生印 → 关键看"印能否帮到我、外宫能否关联内宫"

### 5.3 应用示例
- 丑财库在日支（坐下）= 家里有财库 → 一生有积蓄
- 卯戌合化火，把闲星变用神 → 废物利用，格局提升
- 未冲丑，印库帮身开财库 → 开库得财
- 庚戌在时柱 = 财星在自家 → 财归己有

## 六、第二编·体用与做功系统

### 6.1 体用真谛：命局的本钱与目标
- **体的定义**：印、比、禄、食伤为体（本钱、资源）
- **用的定义**：财星、官杀为用（目标、所求）
- **体用失衡**：
  - 体强无用：本钱多但没目标（有资源无追求）
  - 用强无体：目标大但没本钱（追求高无资源）

### 6.2 做功九法：体作用于用的具体手段 ★杨清娟体系化核心

**第一功：合功（最省力的富贵之法）**
- 手段：干合、支合、半合
- 本质：通过合来取财官（合住忌神、合来用神）
- 取财官的优先顺序：合财>合官>合杀
- 例：日主合官=当官之象；伤官合杀=外财副业

**第二功：制功（强力夺取的手段）**
- 手段：冲、克、刑、穿
- 本质：强力制住忌神，夺取用神
- 制功层次（从高到低）：制官>制杀>制财>制伤
- 当官核心条件：官命三要素（官星有根+有制化+为我所用）
- 制功vs合功最核心区别：制=硬夺（激烈），合=巧取（温和）

**第三功：生化功（顺势而为的智慧）**
- 手段：食伤生财、杀印相生
- 本质：顺着五行相生的方向做功
- 老板三条件：有财源+有印护+有食伤输出
- 枭印夺食判断：枭神见食神，夺则凶；枭合财则不夺
- 开财库三要素：库在原局+库逢冲合透+库中财星为我所用

**第四功：墓库功（收藏与掌控的艺术）**
- 本质：用墓库来收藏、控制能量
- 财库在外面 → 合伙开库（看守所所长之象）
- 比劫帮我 vs 夺财条件：比劫在库中帮身=帮我；比劫在外夺财=夺财

**做功九法总口诀**：
```
合功最省力，制功最激烈
生化顺势为，墓库收藏控
做功要归主，不归主白做
归主入日支，入禄入印星
```

### 6.3 功必归主（核心铁律）★
- **做功必须归主**：做的功（能量结果）必须回到日主身上
- 归主路径三方向：
  1. 入日支（做功结果回到配偶宫/内心/家庭）
  2. 入禄（做功结果回到日主禄位=身体/根基）
  3. 入印（做功结果回到印星=保护/贵人）
- 做功不归主 = 白做功（为他人做嫁衣）
- 例：合官能不能当官？→ 必须看官是否归主（官入日支/禄/印才能当官）

### 6.4 假做功（看似忙碌，实则无获）★
- 特征：做功动作很多（合冲刑穿齐全），但结果不归主
- 表现：忙碌一生、白忙活、为他人打工
- 判断：做功的终点（合化/冲克的结果）不在日主身上

### 6.5 无功之命（体用无情，宾主隔离）★
- 特征：体用之间没有连接（体是体、用是用，互不相关）
- 表现：空有本钱无目标，或有目标无本钱
- 破财受骗的心理逻辑：财星在外+比劫在外+宾主隔离 → 身弱制不住财 → 被劫
- 例：为何给主播刷十万贷款？→ 财星在外、比劫在外、身弱制不住财、开库不成反被财星反制

### 6.6 五行平衡观（盲派专用铁律）
- 盲派也讲平衡：不是旺衰用神的平衡，而是"做功的平衡"
- 五行偏枯时：看配偶星（偏枯时的配偶星判断婚姻）
