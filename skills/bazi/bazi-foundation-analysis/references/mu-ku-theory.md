# 墓库理论：五行定库性，十神定库名，用神定库用

## 一、墓库的本质
辰戌丑未首先是**五行墓库**（五行属性决定本质）：
- 辰=水库(癸), 戌=火库(丁), 丑=金库(辛), 未=木库(乙)

## 二、十神库（以日主为锚）
当辰戌丑未对应到具体日主，藏干转化为十神，库名随十神而变：
- 未对辛金 = 偏印库(己) + 七杀库(丁) + 偏财库(乙) = **一库三名**

## 三、命名的关键
**论事以用神为主**：
- 虽未中己土本气最旺，但因是忌神，论事业财富时称"财杀库"
- 同一库在不同分析段落可以有不同名称（事业段称财杀库，健康段称印库）
- 命名必须与实证吻合（开库之年应什么事，决定称什么库）

## 四、应用铁律
1. 分析开库时先问"论什么"——论事业财富则看财杀，论学业则看印
2. "一库多名"不是混乱，是灵活——关键在于论事时锚定哪个十神
3. 不同日主·同一未库命名不同（辛金→财杀库，庚金→官财库，丙火→印库）
