## 一、断命四步顺序（标准流程）

```
① 断身强身弱（强/弱/中和/从格）——基础，定不了则取用模糊
② 看喜用神（身强喜克泄耗/身弱喜印比）
③ 看忌神（干扰喜用的=忌神/仇神）
④ 验喜用：有没有受冲？关键通关有没有断？有没有受迫害？
   → 定格局层次
```

---

## 二、原局格局层次三档判定（老板原话整理★核心）

### (a) 原局有用神且未被破坏 → 格局层次不低
```
条件：有喜用神 + 没有受大迫害（未受冲克/通关未断）
断语：格局层次不低，成就可期
```

### (b) 喜用神被破坏 → 层次打折扣
```
条件：有喜用神 + 被冲/被克/通关断
断语：层次打折扣，成就需等运催或大起大落
```

### (c) 原局没有喜用神 → 格局很低
```
条件：原局无喜用（喜用缺/无根无透）
断语：格局很低，一生较难有大成就
```

**关键判定项：**
1. **喜用是否受冲**：地支冲喜用根/天干冲喜用
2. **关键通关是否断**：食伤生财的食伤→财链路、杀印相生的杀→印链路是否被截断
3. **喜用是否受迫害**：被忌神克/合绊/三合忌神局

## 三、大运流年分工（老板原话整理★核心）

### 大运重地支，流年重天干
- **大运重地支**：看地支五行、地支刑冲合害（渊海子平"大运重地支，故有行东方南方西方北方之辨"）
- **流年重天干**：看天干十神、天干五合（流年天干透什么神=当年主题）

### 大运=十年主题定性（不是机械分类★老板校准）
```
大运决定这10年是干嘛的（定性/主题/趋势）：
  结合大运地支五行→十神（对日主）+ 喜忌 → 定十年主题
  财(喜用)运   = 求财收获的十年——主业发力、财富积累
  官杀(忌)运  = 压力打拼的十年——担责受制、防官非（需制化）
  印运         = 学习沉淀的十年——进修考证、积累名誉
  食伤运       = 输出变现的十年——才华展露、技术/表达换钱
  比劫运       = 竞争破财的十年（忌）或合伙开拓（喜）——防借贷担保
  注：收获/耕种/潜伏只是举例打比方，不是固定三分类！
      每个大运的主题按具体十神+喜忌生成
```

### 流年=应期（天气）
```
流年决定10年里的具体某一年：
  下雨/天晴/发财升官/破财
  大运定基调，流年定应期（哪年兑现）
```

**铁律：**
- 大运是趋势（10年基调），流年是应期（具体年份）
- 分析必先大运后流年：大运定"这是收获/耕种/潜伏的十年"，流年定"这年下雨还是天晴"
- 忌神大运+喜用流年=雨中有晴（该年尚可）
- 喜用大运+忌神流年=晴中有雨（该年波折）

## 四、AI应用规则（写入报告输出）

1. 报告必含**原局格局层次**：高（喜用未破）/中（喜用被破）/低（无喜用）+判定依据
2. 报告必含**喜用受冲/通关断检查**：喜用是否被冲、食伤生财/杀印相生通关是否断
3. 大运分析必含**季节定性**：收获（喜用运）/耕种（平运）/潜伏（忌神运）
4. 流年分析必含**应期定位**：在大运基调下的具体年份天气（应期）
5. 大运重地支、流年重天干——分析侧重点不同
