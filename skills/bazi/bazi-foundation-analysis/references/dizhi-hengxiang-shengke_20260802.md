# 地支横向生克作用规则（2026-08-02·老板辩证+原文考证）

> **来源**：老板辩证（亥水生卯木/未中乙木）+《子平真诠》《滴天髓》原文
> **核心**：地支主静，但**合局引动则气通**——水生木可横向

## 一、地支生克三层机制（按正统程度排序）

### 1. 同宫藏干相生（最正统·无争议）
```
亥藏壬甲 → 壬水生甲木（同宫共处，气自流通）
例：家主亥中壬水（伤官）生甲木（正财）——地支内伤官生财
```

### 2. 三合局本气横向相生（正统·三合局定义机制）
```
亥卯未三合木局 = 亥水生卯木 → 卯木墓于未
申子辰三合水局 = 申金生子水 → 子水墓于辰
寅午戌三合火局 = 寅木生午火 → 午火墓于戌
巳酉丑三合金局 = 巳火生酉金 → 酉金墓于丑
```
**原文依据**：
- 真诠/渊海："亥卯未会木局""亥卯未化木"
- 滴天髓："亥卯未木局"
- **水生木（亥生卯）是三合局的内在机制——地支横向相生的官方承认**

### 3. 半合局拱生（成立·机制精化）
```
亥未半合木局（拱卯）→ 水生未中乙木（木库得生）
寅戌半合火局（拱午）→ 木生戌中丁火（火库）
```
**注意**：
- 水克土——"亥水生未土"表述错误；正确是"亥水生未中乙木"（木库之木）
- 不是"藏干跨支直生"，是"半合局引动，水生木库之气"

## 二、辩证边界（哪些不算）

```
✗ 藏干跨支直生（亥中壬水"直接"生未中乙木）——非正统，不采
✗ 无合局关系的地支藏干互算生克——地支主静，不逐藏干算
✓ 有合局（三合/半合/六合）→ 气通 → 可论横向生克
✓ 本气五行横向相生（水生木：亥生卯）→ 三合局机制
```

## 三、滴天髓总纲

```
"地支顺而不悖也"——地支之气顺生（水→木→火→土→金→水）
"地支生之，天干辅之，皆为有情而顺则吉；地支抑之……无情而悖则凶"
→ 地支横向生克（顺生）是滴天髓认可的"有情顺则吉"
```

## 四、实战应用规则

1. 分析"水生木/木生火"等做功链时，**先查合局**：
   - 有亥卯未三合 → 亥水可生卯木、生未中乙木（气通全局）
   - 有亥未半合（拱卯）→ 亥水可生未中乙木
   - 无合局 → 只论同宫藏干相生（亥中壬生甲）
2. 表述规范："亥未半合拱卯→水生未中乙木"（不说"亥水生未土"）
3. 地支横向生克**必须通过合局机制**，禁止"藏干跨支直生"式自由发挥
