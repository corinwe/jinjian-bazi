## 一、调候法核心原理

### 1. 什么是调候用神
调候用神是"气候调节"层面的用神——按日主五行+出生月令，调节命局的寒暖燥湿：
- **寒局**（冬月生）：需要火暖局（丙/丁）
- **热局**（夏月生）：需要水润局（壬/癸）
- **燥局**（未/戌月）：需要水润、忌火再燥
- **湿局**（辰/丑月）：需要火暖、忌水再湿

### 2. 调候用神与格局用神、扶抑用神的关系
三者是不同层面的用神，判断次序：
1. 先看格局用神（子平真诠法：月令定格）
2. 再看扶抑用神（滴天髓法：身强弱）
3. 最后看调候用神（穷通宝鉴法：气候）
4. **冲突时的取舍**：
   - 从格成立 → 舍调候，从格优先（如坤造庚午，火旺成势，调候虽需壬水但不可逆局）
   - 正格 → 扶抑为先，调候为辅（如乾造辛亥，扶抑用水，调候亦用水，不冲突）
   - 调候用神同时是扶抑用神 → 最吉（用神兼调候，层次高）

### 3. 调候的实战意义
- 调候到位 → 命局"活"（有人气、有温度、能成事）
- 调候缺失 → 命局"死"（寒木不秀、燥金无光）
- 调候用神出现的大运流年 → 人生转折点（如寒命逢火运发）

## 三、调候实战应用规则

### 1. 调候判断四步
1. 查日主天干+月支 → 从 `tiaohou.py` 获取标准调候用神
2. 看原局是否已有该用神（透干/得地/有根）
3. 有 → 调候到位，命局层次加分
4. 无 → 调候缺失，看大运流年何时补上

### 2. 调候应期
- 调候用神出现之年 → 人生转机（寒命火年发、燥命水年润）
- 调候用神被克之年 → 状态低谷
- 大运走调候用神运 → 十年顺境

### 3. 特殊情形
- **从格**：舍调候（从格专旺，不可逆局）
- **专旺格**：本气即调候（曲直格木旺不需要再调候）
- **调候与扶抑冲突**：正格扶抑为先、调候为辅；调候兼扶抑最吉
