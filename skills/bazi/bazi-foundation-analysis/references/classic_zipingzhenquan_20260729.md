## 〇、格局法总纲（操作流程）

### 0.1 格局法七步判定流程

| 步骤 | 动作 | 判定要点 |
|:----|:----|:----|
| ① 定月令 | 锁定月支及其藏干（本气/中气/余气） | 月令为提纲，司令之神即用神候选 |
| ② 取用神 | 月令藏干透干者优先取用；无透则看会支成局；再无则取本气 | 透干 > 会支 > 本气（杂气月另见§六） |
| ③ 辨顺逆 | 财官印食=顺用（善神，喜生护）；煞伤劫刃=逆用（凶神，喜制化） | 「当顺而顺，当逆而逆，配合得宜，皆为贵格」 |
| ④ 定相神 | 找辅助用神成格之神 | 如官格之财（生官）、印（护官） |
| ⑤ 判成败 | 用神有生护、无刑冲破害 → 成；被克破合去 → 败 | 成格看「无破」，败格看「救应」 |
| ⑥ 评高低 | 清纯、有力、有情、位置配合 | 「有情而兼有力，则格局高」 |
| ⑦ 论行运 | 顺运成格变格、喜忌干支有别 | 运能助格局，亦能坏格局 |

## 一、论用神

### 1.1 用神专求月令（铁律）

**原文纲领：** 「八字用神，专求月令，以日干配月令地支，而生克不同，格局分焉。」

**操作规则：**
1. **用神必在月令取**：以日干配月支，看月支本气/中气/余气与日干的十神关系，决定格局。月令之外的天干地支只能做相神、喜神、忌神，不能做格局用神。
2. **月令司令之神为用神**：月支藏干中当令者优先（本气最重，中气次之，余气最轻；但透干者可越级取用）。
3. **透干取用**：月令藏干透出天干者，取所透者为用神。如甲生寅月，寅藏甲丙戊，透丙则取食神（食神格），透戊则取偏财（偏财格）。
4. **会支取用**：月令藏干不透，但地支三合/三会成局者，取会局所成之十神为用神。如亥月不透壬甲，地支亥卯未三合木，取食伤/财等按会局论。
5. **本气兜底**：不透不会，取月支本气为用神。
6. **例外情况**：月令为日主禄地（建禄格）或比劫（月劫格/阳刃格）时，月令无「财官印食杀伤」可取，另按建禄月劫法处理（见§5.7、§5.8）。

**禁忌（AI易错点）：**
- ❌ 拿月令之外的天干当格局用神（如申月透甲，甲不是月令用神，只是天干财星）。
- ❌ 把调候用神、扶抑用神与格局用神混为一谈。格局用神=月令所取；调候/扶抑用神是辅助判断喜忌的工具，两者可同可异。
- ❌ 月令被合化后仍照原样取格——须先看月令是否因合而化、因冲而变（见§1.4 用神变化）。

### 1.2 用神分类：扶抑 / 调候 / 通关 / 病药

格局用神（月令所取）之外，分析喜忌时还需四类辅助用神概念：

#### （1）扶抑用神
按日主旺衰定扶抑方向：
- **日主旺** → 宜克（官杀）、宜泄（食伤）、宜耗（财），此为「抑」。
- **日主弱** → 宜生（印）、宜助（比劫），此为「扶」。
- **身弱不胜财官** → 财官虽为善用神，亦须印比扶身方能任；身强方可任财官。
- **操作规则**：判身强弱（得令/得地/得势）后，扶抑方向必须与格局顺逆方向一致才论成格。如正官格身弱无印 → 官重身轻，格败。

#### （2）调候用神
- 寒暖燥湿失衡时，取调候之神：夏金冬水、冬木夏火之类。
- 例：金生冬月寒凝，喜丙丁火暖局；木生夏月火炎，喜壬癸水润局；土生冬月冻土，喜火解冻。
- **与格局的优先级**：《子平真诠》立场——格局为先，调候为辅。格局成而调候失，减贵不减格；调候成而格局败，仍论破格（详见§4.3 层次判定第5条）。

#### （3）通关用神
两神相战（相克）时，取中间能流通之神为通关：
| 相战组合 | 通关用神 | 说明 |
|:----|:----|:----|
| 木克土 | 火（木生火、火生土） | 食伤通关 |
| 土克水 | 金（土生金、金生水） | 印星通关 |
| 水克火 | 木（水生木、木生火） | 官杀通关 |
| 火克金 | 土（火生土、土生金） | 食伤通关 |
| 金克木 | 水（金生水、水生木） | 印星通关 |
- **操作规则**：官杀与食伤相战、财与印相碍、比劫与财相争时，先找通关之神。如财印相碍（财坏印），透官杀则财生官、官生印，通关而两全。

#### （4）病药用神
- 「有病方为贵，无伤不是奇。」八字有太过不及之病，取能治其病者为药。
- 例：印重身旺（病在印）→ 取财坏印或食伤泄秀为药；杀重身弱（病在杀）→ 取印化杀为药；财多身弱（病在财）→ 取比劫帮身为药。
- **操作规则**：病重药轻、病轻药重皆病；药与病力量相当，方为贵格。药神受伤（如药被合被冲）则病不可治，格降。

### 1.3 顺用与逆用（格局法核心分类）

**原文纲领：** 「财官印食，此用神之善而顺用之者也；煞伤劫刃，此用神之不善而逆用之者也。当顺而顺，当逆而逆，配合得宜，皆为贵格。」

#### 顺用（善神：财、官、印、食）——喜生助、喜护持

| 格局 | 顺用方式 | 相神（辅助） |
|:----|:----|:----|
| 财格 | 财喜食神以相生，生官以护财 | 食神生财；正官护财 |
| 正官格 | 官喜透财以相生，生印以护官 | 财星生官；印星护官 |
| 印格 | 印喜官杀以相生，比劫以护印 | 官杀生印；比劫护印 |
| 食神格 | 食喜身旺以相生，生财以护食 | 财星（食生财） |

#### 逆用（凶神：煞、伤、刃、禄劫）——喜制伏、喜化泄

| 格局 | 逆用方式 | 相神（制化之神） |
|:----|:----|:----|
| 七杀格 | 杀喜食神以制伏，忌财印以资扶 | 食神制杀；印星化杀 |
| 伤官格 | 伤喜佩印以制伏，生财以化伤 | 印星制伤；财星化伤 |
| 阳刃格 | 刃喜官杀以制伏，忌官杀之无制 | 官杀制刃 |
| 建禄月劫 | 禄喜财官以相生，忌比劫之争夺 | 财星、官星 |

**操作规则：**
- 顺用格（财官印食）**忌见克用神之物**：官忌伤官、财忌比劫、印忌财、食忌枭。
- 逆用格（杀伤刃劫）**忌见生扶用神之物**：杀忌财滋（财生杀）、伤忌官（伤官见官）、刃忌印比助刃。
- **「四吉神顺用而成，四凶神逆用而成」是判定成败的总开关**，任何格局分析先套此表。

### 1.4 论用神变化（合而变格）

月令藏干因透出不同、或因合而化，用神随之变化：

- **透干变格**：同一月令，透出哪个藏干即取哪个为用神。如丁生午月：午藏丁己，透己则取食神（食神格），透丁则取比肩（建禄类）。如甲生寅月：透丙=食神格、透戊=偏财格、透庚=七杀格（寅中庚为余气，透则取）。
- **合化变格**：月令藏干透出之干与邻干合而化他神，则用神随化气而变。如月令正官透干被日主合去，官星失用，格局按变化后论。
- **操作规则**：排盘后先检查月令藏干透干情况，再检查透干之干是否被合化、被克合。用神被合去=用神失位，是破格重要来源之一（见§2.2）。

### 1.5 论用神纯杂

**原文纲领：** 「用神既有变化，则变化之中，遂分纯杂。纯者吉，杂者凶。」

- **纯**：互用而两相得。如正官格配财印——财生官、印护官，财印两不相碍，官格纯。
- **杂**：互用而两不相谋。如正官格又透伤官（伤克官）、又透七杀（官杀混杂），互不相谋，格杂。
- **操作规则**：判定格局高低第一步看纯杂。杂格必须先「去留舒配」（合去其一、制去其一）方能论贵（详见§4.1）。

## 二、论用神成败救应

### 2.1 成格条件（总则）

**原文纲领（成格举例）：** 「何谓成？如官逢财印，又无刑冲破害，官格成也。财旺生官，或财逢食生而身强带比，或财格透印而位置妥贴两不相克，财格成也。……印轻逢煞，或官杀有根，印格成也。食神生财，或食逢煞而食重煞轻，食神格成也。七杀逢食制，或杀印相生，杀格成也。伤官生财，或伤官佩印而伤轻身旺，伤官格成也。阳刃透官杀，刃格成也。建禄月劫透财官，禄格成也。」

**成格判定五条件（可操作）：**
1. **用神清透有根**：用神透干得地（地支有禄旺库余气之根），不被合去。
2. **顺用者得生护**：财有食生、官有财生印护、印有官杀生、食有财接。
3. **逆用者得制化**：杀有食制或印化、伤有印制或财化、刃有官杀制、禄有财官用。
4. **无刑冲破害**：用神所在之支（尤其月支）不被刑、冲、破、害；用神之干不被克。
5. **身主能任**：身强能任财官，或身弱有印比扶助，不犯「身弱不胜」。

### 2.2 败格条件（总则）

**原文纲领（败格举例）：** 「何谓败？如官逢伤克刑冲，官格败也。财轻比重，财格败也。印轻逢财，或身强印重而透食伤，印格败也。食神逢枭，或生财而身弱，或制杀而杀重，食神格败也。七杀逢财无制，杀格败也。伤官非金水而见官，或生财而身弱，或佩印而伤轻身旺，伤官格败也。阳刃无官杀，刃格败也。建禄月劫无财官，透杀印，禄格败也。」

**败格判定六条件（可操作）：**

| 败格方式 | 说明 | 典型例子 |
|:----|:----|:----|
| ① 用神被克 | 克用神之干透出且有力 | 官逢伤官、印逢财、食逢枭、财逢劫 |
| ② 用神被刑冲破害 | 月支/用神之支遭刑冲 | 正官坐冲、官星入墓逢冲 |
| ③ 用神被合去 | 用神之干被邻干合住失用 | 官星被日主合去 |
| ④ 官杀混杂无去留 | 官与杀并透，无合去/制去其一 | 正官格又透七杀 |
| ⑤ 用神太过 | 用神过旺反成病 | 财多身弱、杀重身轻、印重身旺 |
| ⑥ 身主不任 | 日主太弱或太旺，不能与用神配合 | 身弱见官杀攻身、身旺无泄 |

### 2.3 救应机制（败格转成核心）

**原文纲领：** 「伤官见官，为祸百端；有财则伤官生财、财生官，转凶为吉。」「用神因成得败、因败得成，全在救应之有无。」

#### 救应三法总表

| 破格情形 | 救应方法 | 救应之神 | 示例 |
|:----|:----|:----|:----|
| 伤官见官 | ① 财星通关（伤生财、财生官） | 财 | 甲用酉官，透丁伤官，见戊己财，丁生戊、戊生辛，官格复成 |
| 伤官见官 | ② 印星制伤（伤官配印） | 印 | 伤官格透官，见印制伤存官 |
| 伤官见官 | ③ 合去伤官 | 合神 | 丁伤官被壬合去，官星无伤 |
| 官杀混杂 | ① 合杀留官 | 合神 | 七杀被合去，独留正官 |
| 官杀混杂 | ② 合官留杀（杀格用） | 合神 | 正官被合去，独留七杀，按杀格论 |
| 官杀混杂 | ③ 制杀存官（食制杀） | 食神 | 食神制去七杀，正官独清 |
| 刑冲破害 | ① 六合解冲 | 合神 | 子午冲，见丑合子，冲解 |
| 刑冲破害 | ② 三合解冲 | 会局 | 寅申冲，见午戌会寅局，冲解 |
| 刑冲破害 | ③ 冲处逢合 | 合神 | 用神逢冲，他支合住冲神 |
| 比劫夺财 | ① 官杀制劫护财 | 官杀 | 财格透比劫，见官星制劫 |
| 比劫夺财 | ② 食伤化劫生财 | 食伤 | 财格透劫，食神泄劫生财 |
| 枭神夺食 | ① 财星制枭 | 财 | 食神格逢枭，见财坏印护食 |
| 财星坏印 | ① 比劫制财护印 | 比劫 | 印格逢财，见比劫克财 |
| 财星坏印 | ② 官杀通关（财生官、官生印） | 官杀 | 财印相碍，透官则两全 |

#### 救应判定的关键规则

1. **先看破格之神有无制化**：破格之神被制（克）、被化（通关）、被合（去留），皆可救。
2. **救应之神必须有力**：救应之神透干有根方为真救；救应之神自身被克被合，救应失效。
3. **生克先后定吉凶**：「如甲用酉官，丁年壬运」——丁伤官先透，壬运合丁，伤官被合，官格得救，吉；若壬先合丁则丁失……**判定规则：先坏后救=有救；先救后坏=仍凶。** 流年大运顺序影响结果。
4. **用神因成得败**：原本成格，因大运流年破坏用神/相神而转败。
5. **用神因败得成**：原本败格，因大运流年救应（合去忌神、制去破格之神）而转成。
6. **救应之神即相神**：救应机制与相神理论（§三）同源——能救格局之神，正是此格的相神。

## 三、论相神

### 3.1 相神定义

**原文纲领（《论相神紧要》）：** 「用神者，月令所用之神也；相神者，辅助用神者也。」「伤用神甚于伤身，伤相甚于伤用。」

- **相神 = 辅助用神成格之神**（即常说的喜神/救应之神，但比「喜神」更精确——相神直接参与成格）。
- **地位**：伤用神比伤身更严重；伤相神比伤用神更严重。因为用神如根，相神如枝叶——「根伤则枝叶无所附，枝叶伤则根亦受伤」。
- **操作规则**：定格局后第一步找相神；相神受伤无救 = 格败，即使用神完好。

### 3.2 八格相神速查表（相神与用神配合）

| 格局 | 用神 | 相神（辅助） | 相神作用机制 |
|:----|:----|:----|:----|
| 正官格 | 正官 | 财（生官）/ 印（护官） | 财生官使官有源；印制伤护官使官无伤 |
| 七杀格 | 七杀 | 食神（制杀）/ 印（化杀） | 食制杀使杀受制；印化杀使杀生身 |
| 财格 | 财 | 食神（生财）/ 官（护财） | 食生财使财有源；官制劫使财无夺 |
| 印格 | 印 | 官杀（生印）/ 比劫（护印） | 官杀生印使印有源；比劫制财使印无坏 |
| 食神格 | 食神 | 财（食生财） | 食生财使秀气有归宿 |
| 伤官格 | 伤官 | 印（制伤）/ 财（化伤） | 印制伤使凶神受制；财化伤使凶气转生财 |
| 阳刃格 | 阳刃 | 官杀（制刃） | 官杀制刃使凶神受制 |
| 建禄格 | 禄（比劫） | 财（禄生财）/ 官（制比劫） | 财官为禄身之归宿、制比劫之争夺 |

**配合铁律：**
- 顺用格（财官印食）：相神必须「生」用神或「护」用神——生者如财生官、食生财；护者如印护官、比劫护印。
- 逆用格（杀伤刃劫）：相神必须「制」用神或「化」用神——制者如食制杀、印制伤、官制刃；化者如印化杀、财化伤。
- **相神不能反克用神**：如官格以印为相神护官，若印星同时泄官之气尚可；但若以伤官为「相」则反成破格之神。相神与忌神是同一十神在不同配置下的角色转换——伤官在官格是忌神，在伤官格配印制时印才是相神，须按格定位。

### 3.3 相神受损则格败（重点）

**原文纲领：** 「相神无救，则格败矣。」

**各格相神受损情形表：**

| 格局 | 相神 | 相神受损方式 | 结果 |
|:----|:----|:----|:----|
| 正官格（财为相） | 财 | 财被比劫夺 | 官无源，格败（除非另有印护） |
| 正官格（印为相） | 印 | 印被财坏 | 官无护，伤官可克官，格败 |
| 七杀格（食为相） | 食神 | 食被枭夺 | 杀无制，攻身，格败 |
| 七杀格（印为相） | 印 | 印被财坏 | 杀无化，格败 |
| 财格（食为相） | 食神 | 食被枭夺 | 财无源，格败 |
| 财格（官为相） | 正官 | 官被伤克 | 财无护，比劫夺财，格败 |
| 印格（官杀为相） | 官杀 | 官杀被合去/被伤 | 印无源，格败 |
| 印格（比劫为相） | 比劫 | 比劫被官杀克 | 财可坏印，格败 |
| 食神格（财为相） | 财 | 财被劫 | 食秀气无归，格败 |
| 伤官格（印为相） | 印 | 印被财坏 | 伤无制，见官则祸，格败 |
| 伤官格（财为相） | 财 | 财被劫 | 伤无化，格败 |
| 阳刃格（官杀为相） | 官杀 | 官杀被食伤制尽/被合 | 刃无制，格败 |

**判定规则：**
1. 相神受伤后，**若另有他神能制住伤相神之物（救应），格仍可成**——如官格印为相，印被财坏，透比劫克财护印，印得救，官格仍成。
2. 相神被合去、被克破且无救 → 格败无疑，纵用神清透亦不贵。
3. 大运流年伤相神 → 该运凶；伤相神之运逢救应之干 → 凶中有救。

## 四、论格局高低

### 4.1 清纯（用神纯杂决定贵气上限）

**原文纲领：** 「纯者吉，杂者凶。」

**清纯判定规则：**
1. **用神一位为纯**：正官格只透一位官星，无七杀混杂、无伤官暗克 → 清。
2. **官杀混杂为杂之最**：官杀并透，须去留舒配——
   - 合杀留官：七杀被合去，独留正官，仍论官格清。
   - 合官留杀：正官被合去，独留七杀，转论杀格。
   - 食制杀存官：食神制去七杀，官星独清。
   - **去留原则**：去留须「有情」——合神有力、制神有力，去得干净；合而不合、制而不尽，仍是混杂，格降。
3. **相神不杂**：相神之外不另见克用神之物。如官格有财有印为纯，若又见伤官（虽有印制，终属瑕疵）则略杂。
4. **清浊分数（操作参考）**：清（无杂）→ 贵；略杂有救（去留成功）→ 中上；混杂无去留 → 破格。

### 4.2 有力（用神力量决定成就上限）

**用神有力四要素：**

| 要素 | 判定 | 强弱 |
|:----|:----|:----|
| 得时 | 用神当令（月令司令） | 当令最强 |
| 得地 | 地支有根：禄 > 旺 > 库 > 余气/长生 | 根深者强 |
| 得透 | 天干透出 | 透干则力显 |
| 得助 | 有相神生助（财生官、官生印、食制杀等） | 有助者强 |

**操作规则：**
- 用神透干 + 得根 + 得相神生助 = 有力 → 格局高。
- 用神藏支不透、无根、相神无力 = 无力 → 格局低（纵成格亦仅小贵小富）。
- 「有情而兼有力，则格局高；无情而兼无力，则格局低」——**有情（配合得宜）× 有力（力量充足）双维度判定**：
  - 有情有力 → 上格（大贵）
  - 有情无力 → 中格（清贵而权轻）
  - 无情有力 → 中下格（有力而用不当，反成灾）
  - 无情无力 → 下格/破格

### 4.3 层次判定总表

| 层次 | 条件 | 断语参考 |
|:----|:----|:----|
| 上格（大贵） | 成格 + 清纯 + 用神有力 + 相神无损 + 位置妥贴 | 富贵双全，位高权重 |
| 中上格 | 成格 + 略杂有救（去留成功）+ 有力 | 贵而有疵，中高级别 |
| 中格 | 成格 + 用神有力但相神略弱/略受制有救 | 小贵小富，或富而不贵 |
| 中下格 | 成格但有明显瑕疵（用神无力/调候失/杂而勉强） | 平常命，有小成 |
| 败格有救 | 破格但有救应（逢运得救） | 待运而发，起伏大 |
| 破格无救 | 败而无救 | 贫贱夭折，一事无成 |

**附加规则：**
1. **位置配合（位置妥贴）**：相神与忌神的位置关系决定吉凶。如财印相碍，财在年干、印在时干（财先印后）与印先财后，结果不同——「生克先后分吉凶」。
2. **四吉神与四凶神贵气差异**：顺用格（财官印食）成格，贵在安稳持久；逆用格（杀伤刃劫）成格，贵在权变魄力（多武贵、白手起家）。同等成格条件下，官印格偏文贵，杀刃格偏武贵，财食格偏富。
3. **调候得失影响层次**：格局成而调候失 → 减贵（如冬金无火，官印虽成，寒而不秀）；格局成而调候得 → 增贵（「调候得宜，锦上添花」）。
4. **外格不轻取**：月令有可用之神，绝不取外格（从格、化格、遥合、倒冲等）。外格只在月令无用、日主无依时方论（见§七）。

## 五、正八格逐一详解

> 每格统一按「定义 → 取用 → 成格条件 → 败格条件 → 救应 → 喜忌速查 → 取运 → 案例」八项展开。

### 5.1 正官格

**① 定义：** 月令本气/中气/余气为正官，透干（或本气不透但支会官局）而成格。如甲生酉月透辛、乙生申月透庚、丙生子月透癸。

**② 取用：** 官星清透为用，身强能任，喜财生印护。「官星喜透喜生」——透出天干方显，有财生方有源。

**③ 成格条件：**
1. 官星清透有根（地支有官星之禄旺或余气根）。
2. 身旺能任官（身弱须有印）。
3. 有财生官（财为相神）或有印护官（印为相神）。
4. 无刑冲破害（官星之支不被冲、不被合去）。

**④ 败格条件：**
1. **伤官见官**——官格最忌（伤官克官，祸百端）。
2. **官杀混杂**——又透七杀，无去留。
3. **刑冲破害**——官星坐支逢冲（如酉官逢卯冲）、官星入墓。
4. **官重身轻**——日主太弱，官星攻身（身弱无印）。
5. **官星被合去**——官星与日主或邻干合，官失其用。

**⑤ 救应：**
- 伤官见官 → 见财通关（伤生财、财生官）或见印制伤，或伤官被合。
- 官杀混杂 → 合杀留官/制杀存官。
- 官星逢冲 → 六合/三合解冲。

**⑥ 喜忌速查：**

| 喜 | 忌 |
|:----|:----|
| 财（生官）、印（护官）、比劫（身弱扶身） | 伤官（克官）、七杀（混官）、刑冲（坏官）、食神合官（如丙合辛，官被合去） |

**⑦ 取运：** 喜财旺、官旺、印旺之地；忌伤官、七杀、刑冲之运。行伤官运而原局有财，伤生财、财生官，反吉；无财则凶。

**⑧ 案例（示例）：**
- 甲日酉月，透辛正官，年干己土正财生官，日主甲木坐寅有根 → 官星清透有源有护 → 正官格成，贵。
- 甲日酉月，透辛，又透丁伤官，无财无印 → 伤官见官 → 正官格败，主官非口舌、仕途多舛。

### 5.2 七杀格（偏官格）

**① 定义：** 月令本气/中气/余气为七杀。如甲生申月透庚、乙生酉月透辛、丙生亥月透壬。七杀为凶神，逆用，喜制伏化泄。

**② 取用：** 杀须有制有化方成格。制=食神（食神制杀），化=印（杀印相生）。「有制则为偏官，无制则为七杀」——制化得宜则贵，无制无化则凶。

**③ 成格条件：**
1. **食神制杀**：杀重食轻或食重杀轻皆偏，食杀相当方佳；食神须透干有力。
2. **杀印相生**：杀生印、印生身，杀化为权（最上乘——「杀印相生，功名显达」）。
3. **身杀两停**：日主与七杀力量相当，杀为我用（身强杀浅/身弱杀重皆不美）。
4. **伤官驾杀**：伤官制杀，须身强（伤官与杀皆凶，两凶相制，身强方任）。
5. 无财滋杀、无枭夺食（若以食制杀，忌枭）。

**④ 败格条件：**
1. **杀无制无化**——七杀无食制、无印化，直攻日主（杀重身轻）。
2. **财滋弱杀**——见财生杀，助纣为虐（「杀逢财无制，杀格败也」）。
3. **制杀太过**——食神太重把杀制尽，杀失其用（「制杀太过，杀无用，反不贵」；杀被制尽则如猫鼠同眠，无威可借）。
4. **身弱不胜**——日主无根，杀重攻身，纵有制亦制不住。

**⑤ 救应：**
- 杀无制 → 见印化杀（印为救应）。
- 财滋杀 → 见比劫制财或印化杀。
- 食被枭夺 → 见财制枭护食。

**⑥ 喜忌速查：**

| 喜 | 忌 |
|:----|:----|
| 食神（制杀）、印（化杀）、比劫（身弱帮身）、身强 | 财（滋杀）、枭（夺食）、制杀太过 |

**⑦ 取运：** 身强杀浅，喜财官食伤；身弱杀重，喜印比。忌再行杀旺无制之地、财地滋杀。

**⑧ 案例（示例）：**
- 甲日申月，透庚七杀，时透丙食神制杀，日主甲木坐寅禄 → 食神制杀，身强 → 七杀格成，武贵/权贵。
- 甲日申月，透庚，又透戊偏财生杀，无食无印，身弱 → 财滋弱杀攻身 → 七杀格败，凶祸之命。

### 5.3 财格

**① 定义：** 月令为财星（正财/偏财本气、中气、余气）。如甲生辰戌月（戊为偏财）、乙生辰戌月（戊为正财）、丙生酉月（辛为正财）。

**② 取用：** 财为善神，顺用——喜食神生财（财有源）、喜官星护财（制比劫）。「财喜食神以相生，生官以护财。」

**③ 成格条件：**
1. **财透有根**：财星透干，地支有根。
2. **身旺任财**：日主强方能担财（「财多身弱，富屋贫人」）。
3. **食神生财**：食伤生财，财源滚滚（财有源则大）。
4. **财生官**：财旺生官，官星护财（防比劫夺）——「财旺生官，富贵兼得」。
5. **财格配印**：财旺身弱时，配印帮身（须印有根、位置妥贴，防财印相碍）。

**④ 败格条件：**
1. **比劫夺财**——比劫林立，财被分夺（「财轻比重，财格败也」；无食伤官杀护财则败）。
2. **财多身弱**——财重日主不胜（富屋贫人，钱多反为累）。
3. **财坏印**——若以印为用（财格配印），财星克印，两不相谋。
4. **财星被合去**——财被合走（如甲日见己财，被庚合? 需查合而不合——甲己合，财被日主合，反为我所得，另论）。

**⑤ 救应：**
- 比劫夺财 → 见官杀制劫（官护财）、或食伤化劫生财。
- 财多身弱 → 见印比帮身。
- 财印相碍 → 见官杀通关（财生官、官生印）。

**⑥ 喜忌速查：**

| 喜 | 忌 |
|:----|:----|
| 食神伤官（生财）、官杀（护财）、身旺、印（身弱帮身） | 比劫（夺财）、身弱（不胜财）、枭（夺食断财源） |

**⑦ 取运：** 身旺喜食伤财官旺地；身弱喜印比之地。忌比劫夺财之运（群劫争财，财来财去）。

**⑧ 案例（示例）：**
- 甲日辰月，透戊偏财，年干丙食神生财，日主甲木坐寅有根 → 食神生财、身强 → 财格成，富格。
- 甲日辰月，透戊偏财，满盘比劫无食伤无官杀 → 比劫夺财 → 财格败，财来财去、为财起争。

### 5.4 印格（正印格 / 偏印格）

**① 定义：** 月令为印星（正印/偏印）。如甲生子月（癸正印）、甲生亥月（壬偏印）、乙生亥月（壬正印）。印为善神，顺用——喜官杀生印、喜比劫护印。

**② 取用：** 「印喜官杀以相生，劫财以护印。」官印相生、杀印相生皆为上格；印重身旺则喜食伤泄秀。

**③ 成格条件：**
1. **印透有根**：印星清透，地支有根。
2. **官杀生印**：官印相生（文贵）、杀印相生（权贵）——印有源则有力。
3. **比劫护印**：比劫制财护印，防财坏印。
4. **身旺有泄**：印重身旺时，有食伤泄秀（「身强印重而透食伤」，印格亦成——泄秀为用）。
5. 无财坏印、无枭食相碍（偏印格尤忌见食神——枭神夺食）。

**④ 败格条件：**
1. **财星坏印**——印格最忌（「印轻逢财，印格败也」）。
2. **印重身旺无泄**——土厚埋金、母旺子衰，印多为病（须食伤泄秀或财星坏印，然财星又坏印，须位置妥贴）。
3. **印星被合**——印被合去（如印星与邻干合化他神）。
4. **印星被刑冲**——印星坐支逢冲。

**⑤ 救应：**
- 财坏印 → 见比劫制财（护印）、或见官杀通关（财生官、官生印）。
- 印重身旺 → 见食伤泄秀（转成）。

**⑥ 喜忌速查：**

| 喜 | 忌 |
|:----|:----|
| 官杀（生印）、比劫（护印）、食伤（印重泄秀） | 财（坏印）、印重无泄（母旺子衰） |

**⑦ 取运：** 喜官杀印比之地；忌财地（财坏印）。印重身旺者反喜食伤财地泄秀。

**⑧ 案例（示例）：**
- 甲日子月，透癸正印，年干辛正官生印，日主甲木坐寅 → 官印相生 → 印格成，文贵。
- 甲日子月，透癸正印，又透己土正财克印，无比劫无官杀 → 财坏印 → 印格败，母病家累、学业中断之象。

### 5.5 食神格

**① 定义：** 月令为食神。如甲生巳月（丙食神）、乙生巳月（丁食神? 巳藏丙戊庚——乙见丙=伤官，须按藏干精确判定）、丙生辰月（戊食神）。食神为善神，顺用。

**② 取用：** 「食喜身旺以相生，生财以护食。」食神三用：①食神生财（秀气有归）；②食神制杀（制凶为权）；③食神泄秀（身旺吐秀，聪明文采）。

**③ 成格条件：**
1. **食神生财**：食神透干生财，财有源、食有归——最上。
2. **食神制杀**：食重杀轻、或食杀相当（「食逢煞而食重煞轻，食神格成也」）。
3. **食神泄秀**：身旺食透，秀气流露（忌再逢印）。
4. 身旺有根，食神不弱。

**④ 败格条件：**
1. **枭神夺食**——食神格最忌（偏印克食，秀气被夺；「食神逢枭，食神格败也」）。
2. **食神太过**——食多泄身太过，身弱（「生财而身弱」亦败）。
3. **制杀太过**——食神太重制杀太尽，杀失其用（反不为贵）。
4. **食神被合**——食神被合去（秀气被合）。

**⑤ 救应：**
- 枭夺食 → 见财制枭（财坏印护食）。
- 食多身弱 → 见印比帮身（然印又克食，须食印位置妥贴、印不直接克食或食印相隔）。

**⑥ 喜忌速查：**

| 喜 | 忌 |
|:----|:----|
| 身旺、财（食生财）、杀（食制杀，食重杀轻时） | 枭神（夺食）、食多身弱、制杀太过 |

**⑦ 取运：** 喜财旺地（食生财）、身旺喜食伤；忌枭印之地（夺食）、忌食多身弱之地。

**⑧ 案例（示例）：**
- 甲日巳月，透丙食神，年干戊偏财，日主甲木坐寅禄 → 食神生财、身旺 → 食神格成，富而有才。
- 甲日巳月，透丙食神，又透壬偏印（枭）夺食，无财制枭 → 枭神夺食 → 食神格败，才艺被夺、福禄减损。

### 5.6 伤官格

**① 定义：** 月令为伤官。如甲生午月（丁伤官）、乙生巳月（丙伤官? 巳藏丙——乙见丙=伤官）。伤官为凶神，逆用——喜印制、喜财化。

**② 取用：** 伤官三用：①**伤官佩印**（印制伤，身弱尤宜——「伤喜佩印以制伏」）；②**伤官生财**（伤生财，凶气转吉——「生财以化伤」）；③**伤官驾杀**（伤制杀，两凶相制，须身强）。

**③ 成格条件：**
1. **伤官生财**：伤官透干生财，财有归宿——最上。
2. **伤官佩印**：印星制伤，伤有制伏（「伤官佩印而伤轻身旺，伤官格成也」——注意伤轻身旺方宜佩印，伤重印轻则制不住）。
3. **伤官驾杀**：伤官制杀，须身强（伤杀两凶相制）。
4. **金水伤官喜见官**：金水伤官生于冬月，寒金喜火（官星）调候——此时见官不忌反喜（调候救应）。

**④ 败格条件：**
1. **伤官见官**——伤官格最忌（「伤官非金水而见官，伤官格败也」；非金水伤官、非调候需要，见正官即祸）。
2. **伤官无制无化**——无印无财，凶神肆虐（恃才傲物、刑伤官非）。
3. **生财而身弱**——伤生财泄身太过，身弱不胜。
4. **佩印而伤轻身旺**——伤官轻、印重、身旺，印反夺食伤之秀（制伤太过）。

**⑤ 救应：**
- 伤官见官 → 见财通关（伤生财、财生官）、或见印（印制伤护官）、或伤官被合。
- 伤重身弱 → 见印帮身制伤。

**⑥ 喜忌速查：**

| 喜 | 忌 |
|:----|:----|
| 印（佩印制伤）、财（生财化伤）、身强 | 正官（非金水伤官见官）、身弱、印重伤轻（制伤太过） |

**⑦ 取运：** 喜财印之地；忌官运（伤官见官，除非原局有财通关）。身弱喜印比。

**⑧ 案例（示例）：**
- 甲日午月，透丁伤官，时透己土正财，日主甲木坐寅有根 → 伤官生财 → 伤官格成，聪明致富。
- 甲日午月，透丁伤官，又透辛正官，无财无印 → 伤官见官 → 伤官格败，官非口舌、仕途倾覆。

### 5.7 阳刃格

**① 定义：** 月令为日主阳刃（阳干帝旺之地）：甲刃在卯、丙刃在午、戊刃在午、庚刃在酉、壬刃在子。如甲生卯月即阳刃格。（阴干不取阳刃，阴刃之说诸家分歧，《子平真诠》以阳刃为正。）

**② 取用：** 阳刃为凶神（劫财之极），逆用——「刃喜官杀以制伏，忌官杀之无制」。刃格三用：①官杀制刃（最正，尤喜七杀——「煞刃相济」）；②食伤泄秀（刃旺泄之）；③身强任财（刃旺用财）。

**③ 成格条件：**
1. **官杀制刃**：透官或透杀制刃，身杀/身官两停——「阳刃透官杀，刃格成也」。**杀刃相济最贵**：刃旺用杀、杀旺用刃，两相制衡。
2. **食伤泄秀**：刃旺身强，食伤透干泄秀（武人文才）。
3. **财星可用**：刃旺身强，财透有根，身强任财（须防比劫夺财，最好有官杀护财）。

**④ 败格条件：**
1. **刃旺无制**——无官杀无食伤（「阳刃无官杀，刃格败也」；群刃林立，争夺凶暴）。
2. **官杀被制**——制刃之神被伤（如刃格用官，官被伤官克；刃格用杀，杀被食制尽）。
3. **比劫夺财**——刃旺见财无比劫制化，群劫争财。
4. **刃逢刑冲**——刃支被冲（如卯刃逢酉冲，刃起波澜）。

**⑤ 救应：**
- 刃旺无制 → 见官杀制刃或食伤泄秀。
- 官杀被制 → 见财生官杀（财生官）或去制官杀之神。
- 比劫夺财 → 见官杀制比劫。

**⑥ 喜忌速查：**

| 喜 | 忌 |
|:----|:----|
| 七杀（制刃）、正官（制刃）、食伤（泄秀）、财（身强任财） | 比劫（助刃）、印（生刃）、刃旺无制、官杀被制 |

**⑦ 取运：** 喜官杀食伤财地；忌比劫印地（助刃增凶）。刃格行刃地或冲刃之地多凶。

**⑧ 案例（示例）：**
- 甲日卯月，透庚七杀制刃，日主甲木坐寅 → 杀刃相济 → 阳刃格成，武贵/掌权。
- 甲日卯月，满盘寅卯甲乙，无官杀无食伤无财 → 刃旺无制 → 阳刃格败，凶暴争夺、刑伤之命。

### 5.8 建禄格（含月劫格）

**① 定义：** 月令为日主临官（禄）之地：甲禄在寅、乙禄在卯、丙戊禄在巳、丁己禄在午、庚禄在申、辛禄在酉、壬禄在亥、癸禄在子。月令为日主之禄即建禄格；月令为日主之劫财（如甲生卯月之劫财）为月劫格。禄劫同论——日主当令身强，月令无财官印食可取，须借财官为用。

**② 取用：** 「建禄月劫喜财官以相生，忌比劫之争夺。」——禄劫身强，喜财官（身强任财官）、喜食伤（泄秀）。**取用看透干**：月令虽无财官，但四柱透财透官，即以透出之财官为用（格局名仍称建禄格/月劫格，用神是财官）。

**③ 成格条件：**
1. **禄用财官**：透财或透官（财官有根），身强任之——「建禄月劫透财官，禄格成也」。
2. **禄用食伤**：透食伤泄秀（身强吐秀）。
3. **禄用杀印**：透杀透印（杀印相生，化禄劫之旺为权）。
4. 财官有根、不被比劫争夺。

**④ 败格条件：**
1. **无财官可用**——「建禄月劫无财官，透杀印，禄格败也」（原文之意：禄劫无财官，若透杀印而身强杀浅印重，用非所用；更忌比劫林立无制）。
2. **比劫争夺**——比劫林立透干，财星被夺。
3. **官杀无根**——透官杀而无根，制不住比劫。
4. **财官被合被冲**——财官用神受损。

**⑤ 救应：**
- 比劫夺财 → 见官杀制劫护财。
- 无财官 → 见食伤泄秀（泄比劫之气生财）。
- 财官被冲 → 六合三合解冲。

**⑥ 喜忌速查：**

| 喜 | 忌 |
|:----|:----|
| 财（身强任财）、官杀（制比劫）、食伤（泄秀） | 比劫（争夺）、印（生比劫助旺）、身强无泄制 |

**⑦ 取运：** 喜财官食伤旺地；忌比劫印地（争夺更甚）。建禄格行比劫运，财来财去、破耗争竞。

**⑧ 案例（示例）：**
- 甲日寅月（建禄），透戊偏财、庚七杀，日主甲木坐寅 → 禄用财官杀，身强任之 → 建禄格成，富而有权。
- 甲日寅月，满盘寅卯比劫，不透财官食伤 → 无财官可用 → 建禄格败，孤身奋斗、财来财去。

## 六、论杂气如何取用

### 6.1 什么是杂气

辰戌丑未四墓库月，藏干多而杂，故称杂气：

| 月支 | 藏干（本气/中气/余气） |
|:----|:----|
| 辰 | 戊 / 乙 / 癸 |
| 戌 | 戊 / 辛 / 丁 |
| 丑 | 己 / 癸 / 辛 |
| 未 | 己 / 丁 / 乙 |

（注：本气为土，中气余气为木火金水。金鉴体系藏干标准以本skill《dizhi-canggan-biaozhun》为准。）

### 6.2 取用三法（操作规则）

**原文纲领：** 「杂气者，以其藏干多也。取用之法，先看透干，透者取之；次看会支，会者取之；皆无，则取本气为用。」

| 次序 | 方法 | 规则 | 示例 |
|:----|:----|:----|:----|
| ① 透干取用 | 月令藏干透出天干者，取所透者为用 | 透谁取谁（透本气取本气格，透中气取中气格） | 甲生辰月透戊 → 杂气偏财格；透乙 → 杂气劫财（月劫）；透癸 → 杂气正印格 |
| ② 会支取用 | 藏干不透，但地支三合/三会成局者，取会局之神 | 会支成局即取（如辰月寅卯辰会东方木） | 辰月地支寅卯辰会木局，透乙 → 取劫财/比肩局用 |
| ③ 本气取用 | 不透不会，取月令本气（土）为用 | 辰戌丑未本气皆土，按土与日主十神论 | 甲生辰月不透乙癸 → 取戊土偏财（杂气偏财格，弱） |

### 6.3 杂气各格要点

- **杂气正官**：辰月透乙（乙为甲之劫财? 例：乙日辰月透乙? 需按日主定十神）——杂气官星须透干方真，不透则藏而力微。
- **杂气财格**：辰戌丑未透财（如甲日辰月透戊偏财），财有库根，富格居多；「财库喜冲」之说须慎（见6.4）。
- **杂气印格**：未月透丁（偏印）、丑月透癸（偏印? 按日主定）——杂气印格，印在库中，须透干或冲开方有力。
- **杂气杀格**：未月透乙? 按日主定——杂气杀须制化同正格。
- **杂气食伤格**：辰月透癸（日主之食伤按十神定）——杂气食伤，秀气藏库，须透干方泄。

### 6.4 论墓库刑冲之说（重点辨析）

**传统俗说：** 「财官入库，不冲不发」「墓库逢冲则发」。

**《子平真诠》立场（徐注申明）：** 墓库逢冲未必皆吉，须视用神与配合：

| 情形 | 判定 | 理由 |
|:----|:----|:----|
| 财官藏库，透干有力 | 不必冲，亦发 | 透干已出库，冲反动根基 |
| 财官藏库，不透 | 逢冲或可开库（须冲神有力、不伤用神） | 冲开库门，藏者得用 |
| 库中藏忌神 | 逢冲反凶 | 冲开的是忌神之门 |
| 用神入库且逢冲 | 须细辨：冲库之支与用神关系 | 冲开库若同时刑冲用神之根，凶 |
| 会支成局 | 库已合开，忌再冲 | 合局已引化，冲则散局 |

**操作规则（AI判定）：**
1. 先判断墓库中藏的是用神还是忌神。
2. 用神藏库不透 → 冲开为吉（冲库之支须不被合住）。
3. 用神已透干 → 冲库无益，反防冲动根基。
4. 忌神藏库 → 忌冲；若能合住库门（如辰与酉合）反佳。
5. **「墓库逢冲」绝不无条件断吉**——这是《子平真诠》对俗说的核心校正。

## 七、论从格与化格

> 《子平真诠》立场：格局以正八格为主，从格化格属「外格」范畴，**月令有可用之神绝不取外格**；只有月令无用、日主无依、一方成势时，方论从化。取外格须条件苛刻，宁缺毋滥。

### 7.1 从格

#### （1）从格成立四条件（缺一不可）

1. **日主无依**：天干无比劫印（或比劫印被合化尽），地支无禄旺库余气之根（或根被冲合殆尽）。
2. **一方成势**：某一行（或数行）极旺成势——官杀成势（从杀）、财星成势（从财）、食伤成势（从儿）。
3. **不可逆**：所从之神旺不可犯，印比生扶日主即犯旺（逆局）。
4. **真从无杂**：无一点根气微根、无印比暗藏帮身。有微根者为假从（从得不真，运程起伏）。

#### （2）从格分类与用神喜忌

| 类型 | 成势之神 | 用神 | 喜神 | 大忌 |
|:----|:----|:----|:----|:----|
| 从财格 | 财星成势（食伤生财更真） | 财 | 食伤（生财）、官杀（护财） | 比劫印（帮身逆局） |
| 从杀格 | 官杀成势 | 杀（官） | 财（生杀） | 食伤（制杀逆局）、印比 |
| 从儿格 | 食伤成势 | 食伤 | 财（食伤生财） | 印（夺食逆局）、官杀（克食伤） |
| 从势格 | 财官食伤多行成势 | 所从之旺神 | 生助旺神者 | 印比 |

**喜忌总则（与正格完全颠倒）：** 顺所从之势者为喜（生助旺神），逆所从之势者为忌（生扶日主）。印比是最大忌神——帮身即逆局。

#### （3）从格行运

- 喜：所从五行旺地、生助所从五行之地。
- 忌：印比之地（破从）、冲克所从旺神之地。
- **假从格**：运逢印比帮身，反有「还原」之机，吉凶两判（帮身成身弱不胜，灾）。

#### （4）从格案例（示例）

- 甲日申酉戌月? 例：甲日生申月，天干庚辛戊己并透，地支申酉戌会金局，日主无根无依 → 从杀格，弃命从杀，杀旺有制化则贵。
- 甲日午月，天干丙丁戊己并透，地支巳午未会火局，日主无根 → 从儿格（食伤成势生财），秀气流行，聪明富贵。

### 7.2 化格

#### （1）五合化气表

| 天干五合 | 化气 | 化神旺令 |
|:----|:----|:----|
| 甲己合 | 化土 | 辰戌丑未月（土旺） |
| 乙庚合 | 化金 | 申酉月（金旺） |
| 丙辛合 | 化水 | 亥子月（水旺） |
| 丁壬合 | 化木 | 寅卯月（木旺） |
| 戊癸合 | 化火 | 巳午月（火旺） |

#### （2）化气成功四条件

1. **合而能化**：相合两干必须紧贴（年月、月日、日时），中间无间隔。
2. **月令得化神旺气**：化神当令（如甲己化土须生于辰戌丑未月）。
3. **地支有化神之根**：化神在地支有禄旺根气（如化土须地支有辰戌丑未）。
4. **化神不被克破**：天干不见克化神之干（如化土忌甲乙木透干克土；化金忌丙丁火透干克金）。

#### （3）化格成败与喜忌

- **成化**：四条件齐备 → 化格成，以化神为用（如甲己化土，以土为用，喜火土金，忌木水）。
- **破化**：化神失令/无根/被克 → 合而不化（只论合绊不论化）——两干互绊，反失其用，按原十神论格局，且多一层牵绊。
- **妒合/争合**：两干争合一干（如两甲争合一己）、或间隔不合——不化。
- **化格行运**：喜化神旺地及生助化神之地；忌克破化神之地（如化土忌木运、化金忌火运）。

#### （4）化格案例（示例）

- 甲日己月? 例：甲日生于戌月，月干己土，甲己紧贴相合，地支辰戌丑未齐全，天干无木克土 → 甲己化土成，以土为用，大富之格（「化气格成，富贵非常」）。
- 甲日己月，天干又透乙木（比劫）克土，或地支无土根 → 合而不化，甲己仍论正财合身，按财格/正格论。

### 7.3 外格用舍总则

**原文纲领（《论外格用舍》）：** 「八字用神，专求月令……若月令无可取，则舍月令而取外格。然外格多不可靠，不可轻取。」

**操作规则：**
1. 月令有财官印食杀伤可取 → 一律先论正八格，不取外格。
2. 月令为禄劫（建禄月劫）→ 按建禄格处理，不视为「月令无用」。
3. 只有月令完全无可用之神、日主无依、一方成势 → 方依次尝试：从格 → 化格 →（遥合、倒冲、井栏叉等杂格——条件苛刻，金鉴体系不轻断，须验案例）。
4. **从化格断语须谨慎**：从格从得不真、化格合而不化，皆按正格论而减贵，切忌错断从化导致喜忌全反。

## 八、操作速查（金鉴AI实战指引）

### 8.1 三步定格局（排盘后强制流程）

1. **定月令** → 取月支藏干，确认本气/中气/余气（以排盘引擎藏干表为准）。
2. **取用神** → 透干优先 > 会支次之 > 本气兜底（杂气月按§六三法）。同时检查：月令藏干透出之干是否被合化/被合绊（用神变化）。
3. **判格局** → 按§0.2速查表定格局名 → 套§五对应格的成格/败格/救应表 → 定相神 → 评层次（§四）。

### 8.3 破格速查（先查这七条）

1. 官格见伤官 / 官杀混杂？
2. 财格见比劫夺（无官杀食伤护）？
3. 印格见财坏印（无比劫官杀救）？
4. 食神格见枭夺食（无财制枭）？
5. 杀格无制化、或财滋杀？
6. 伤官见官（无财通关、无印护）？
7. 刃格/禄格无财官制泄？

——任一命中且无救应 → 破格；有救应 → 按§2.3救应表转成论，评层次时降一档。

### 8.4 用神变化与行运提醒

- 用神随大运透干而变化（如原局用神藏支，大运透出 → 用神得用，发）。
- 行运能成格变格（如败格逢救应之运转成、成格逢破格之运转败）——断流年大运须先判「此运对用神/相神是生是克、是救是破」。
- 喜忌干支有别：天干主表象（名声、事端），地支主实质（根基、福祸）——干喜支忌、干忌支喜，吉凶分论。
