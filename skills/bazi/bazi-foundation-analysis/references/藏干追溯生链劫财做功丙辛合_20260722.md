## 一、藏干追溯铁律（子源案例触发）

**致命教训：** 子源八字分析中，我因未查藏干庚金，错误判断"水源不足"。
结果月支巳藏庚金(30%)+时支巳藏庚金(30%)+日支戌藏辛金(60%)——四金生双癸水，水源充足。

**规则：**
```yaml
分析生克链条（尤其是生水链条）时：
  第1步：查天干 → 有哪些金？
  第2步：查所有地支藏干 → 有哪些庚辛金？
    年支、月支、日支、时支的本气/中气/余气全查
  第3步：汇总所有金（天干+地支藏干）→ 才能判断水源是否充足
  第4步：分析水源的质量
    庚金（阳金）= 生水之力强
    辛金（阴金）= 生水之力弱
    但数量可以弥补质量（如双庚+双辛=强水源）
```

**口诀：** 生水链条查藏干，天干地支皆要算；庚金阳刚生水力强，辛金阴柔双倍来补。

## 二、生链分析（子源八字）

丙火日主的做功链条是纯「生」，不是"化"也不是"制"：

```yaml
丙火(日主) → 生 → 戊土食神(泄才华) → 生 → 辛金正财(变现) → 生 → 癸水正官(换地位)
```

每个环节都是「生」，干净利落、没有制也没有克。

### 各环节力量来源检查
| 环节 | 力量来源 | 强度 |
|:----|:--------|:----:|
| 丙生戊 | 双巳助丙+戌中戊主气 | 强 ✅ |
| 戊生辛 | 戌中戊(100%)+巳中戊×2(60%)生辛金(年干+戌中60%) | 中上 ✅ |
| 辛生癸 | 辛金(年干100%+戌中60%)生癸水(月时双透) | 中 ⚠️ 最薄弱环节 |

## 三、劫财做功 vs 劫财判断标准（魏启令案例）

劫财（庚金）在八字中有两种可能的路：
1. 庚→生→癸（食神）= **做功** ✅
2. 庚→克→乙/甲（财星）= **劫财** ❌

### 判断标准：两个条件同时满足则劫财去做功

```yaml
# 条件一：天干有没有财星给它劫？
天干无明财 → 劫财没有直接目标 → 只能往下走
天干有明财 → 劫财有目标 → 可能去劫财

# 条件二：前面有没有明确的食伤输出路径？
食伤在前顺生 → 能量自然往食伤流
无食伤泄路 → 劫财憋着 → 去找财劫

# 两个条件同时满足 → 劫财在"做功"，不在"作恶"
```

### 实战应用
```yaml
劫财不可怕，可怕的是：
  劫财 + 财星透干 + 无食伤泄路 → 三条俱足，劫财才会真去劫

安全情况：
  劫财 + 财不透干 + 食神在前顺生 → 劫财去做功了
```

## 四、丙辛合化水（子源八字·关键发现）

子源八字年干辛（正财）+ 日主丙（自身）= **丙辛合化水**。

### 意义
一般人需要两步（赚钱→用钱换地位），他一步到位——
**丙（自身）和辛（财）直接合在一起，一步化成了水（正官/地位）。**

他的财富和追求是一体两面：
- 不是先赚钱再求地位
- 赚钱本身就等于积累地位
- 丙辛合化的是他的自身，不是外部的东西——地位是自己挣来的

### 双重保障机制
- 路径一（核心）：丙辛直接合化水 → 一步到位
- 路径二（后备）：辛金生癸水（月时干）→ 间接路线

### 实战检查清单
```yaml
□ 日主天干是否与年干/月干辛金相邻？
  → 是 → 丙辛合化水
□ 合化出的水是否为命主喜用？
  → 丙火日主喜水调候 → 合化有利 ✅
□ 有无阻碍合化的因素（如戊土透干克水）？
  → 无戊己土透干 → 合化顺畅
```
