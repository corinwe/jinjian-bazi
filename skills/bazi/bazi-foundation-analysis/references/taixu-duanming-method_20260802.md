## 一、三步断运法（核心方法论★）

### 第一步：断身强弱
```
方法：日元在地支受生（尤其受月令生）+ 地支根多 → 大概率身强
案例：己土生午火月（印当令）+ 天干透正印丙 + 地支四根（午中己/巳中戊/寅中戊/申中戊）
      → 断身强
铁律：强弱定不下来 → 取用神就模糊
```
- 身强 → 喜克泄耗（官杀/食伤/财）
- 案例喜用：金水（伤官生财）

### 第二步：断喜用在原局的力量
```
喜用有力 → 成就格局不低，大起大落程度轻
喜用缺/弱/被扰 → 成就等运催，容易大起大落（运来上去，运走下来）
案例：伤官庚金+财星壬水原局有（庚申柱+壬坐申有根）
      → 喜用有力但被火克（申被午巳寅夹克）→ 能成但大起大落
```

### 第三步：找干扰（忌神/仇神）
```
干扰喜用的 = 忌神/仇神
忌神得力（地支生它/天干坐实）→ 该年份不好
案例：火（印）是忌神 → 印重再生印 → 人轴不听劝 → 损失财源
```

**三步完成 = 运势起伏分析七七八八**

## 二、性格论（配合十神本意）★

| 组合 | 性格断语 | 案例验证 |
|:-----|:---------|:---------|
| 正偏印混杂 | 思虑多、多思伤脾（印重脾胃差）、多思少动 | 印重→想法多执行少 |
| 财星破印 | 有执行力（无财破印=思想巨人行动矮子） | 财星壬水破丙印→有执行力 |
| 财星被冲（寅申冲） | 行动力不持续、干一段停一段 | 财根受冲→执行断断续续 |
| 伤官生财 | 发现商机能力、临场应变能力 | 伤官庚生财壬→赚钱通道 |
| 伤官被冲合（寅申冲+巳申合） | 财源不稳定→适合干项目（一阵一阵）不适合单品生意 | 网络安全+电脑硬件+项目多 |
| 印重+正官 | 贵人运好、易与体制打交道、业务偏工程类 | 寅中甲木正官→体制工程业务 |
| 印重 | 很轴不听劝（忌神再生印）、能吹（叙事感）、重情重义、扛压 | 轴→损失财源；能吹→爱复盘讲经历 |

**财源属性判定（细节决定职业属性）：**
- 财源稳定 → 适合长期经营单品（卖服装一直卖）
- 财源不稳定（伤官被冲合）→ 适合经营项目（干完一个拿一笔，再干下一个）
- 冲合多 → 项目方向多（既干网络安全又卖硬件）

## 三、学历论 ★

| 规则 | 断语 | 案例 |
|:-----|:-----|:-----|
| 财星破印（财克正印） | 学历降一档 | 壬水克丙火印→降档 |
| 喜伤官生财，伤官旺 | 读书聪明灵动、学东西快 | 伤官庚金→聪明 |
| 伤官根被火干扰（午火当令克金） | 伤官不旺 → 学历不高 | 金被火克→学历不高 |
| 喜用被伤（伤官被克） | 出身一般 | 壬水伤→出身普通 |

**结论：财破印+伤官受克=学历不高、出身一般**（该老板早年学历不高）

## 四、大运流年实战（完整案例·教材级）★

### 大运序列（男·阳年？己土年干庚申——庚阳年男顺排）
癸未(少年) → 甲申(15-24) → 乙巳(25-34) → 丙戌(35-44) → 丁亥(45-54)

### 逐运断语
| 大运 | 干支作用 | 断语 | 实际 |
|:-----|:---------|:-----|:-----|
| **癸未** | 癸水财透+未土印；巳午未三合火局克申金+寅申冲 | 过得很惨（少年） | 早年困苦 |
| **甲申** | 甲木正官透→事业心起；申金当令→伤官生财通+财破印利 | 能挣钱但事业不稳定（甲庚冲伤官） | 15岁出门闯荡搞钱 |
| **乙巳** | 乙木七杀透+乙庚合（合杀）；巳申合加强申金 | 比甲申运好（七杀制衡身旺印旺） | 2004后创立公司、成家立业 |
| **丙戌** | 丙火印透+戌土印；寅午戌三合火局切走戌土力量（帮倒忙）；丙冲壬水财 | 为面子投资、为大而大 | 历经风浪 |
| **丁亥** | 丁火克财+亥水泄午火 | 比丙戌稳定 | 干品牌、海外销售 |

### 流年实战（丙戌运内·教材级）
| 流年 | 作用 | 断语 |
|:-----|:-----|:-----|
| 2016丙申 | 丙冲壬水财+申金续接水 | 赚钱问题不大（多赚少赚） |
| **2018戊戌** | 印旺+戊土克壬水（忌神坐实） | **踩大坑** |
| 2019己亥 | 亥水来（水有气） | 稍微好点 |
| 2020庚子/2021辛丑 | 金水喜用 | 好得多、缓过劲 |
| **2022壬寅** | 壬水透准备大干+寅午戌三合火局引动+寅申冲（申金被克掐财源）+壬水被火反克 | **破大财+官司牢狱** |

**流年铁律：**
1. 忌神坐实（戊土克壬水）=踩坑年
2. 喜用透出（亥水/庚子/辛丑）=缓过劲年
3. **忌神三合局引动+冲用神=大坑年**（寅午戌合火+寅申冲=破财官非）

## 六、AI应用规则（沉淀）

1. 分析报告必含：**喜用在原局的力量评估**（有力/弱/被扰→大起大落程度）

4. 性格分析加**组合断语**：印重→轴/多思/脾胃差/贵人运/能吹；财破印→执行力；财被冲→行动不持续；伤官被冲合→财源不稳定（项目型）
5. 职业分析加**财源属性**：财源稳定→单品生意；财源不稳→项目经营
