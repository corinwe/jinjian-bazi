# 配偶宫（日支）十神正确理解
来源：20260722老板精读校正
铁律等级：永久

## 核心原则

**配偶宫十神 = 配偶本人的性格、能力、特征。**
**不是日主对配偶的态度，也不是配偶对日主的态度。**

## 错误理解（已被纠正）

❌ 日支亥中壬水伤官 → "我对太太挑剔"
❌ 配偶宫的十神描述的是"日主眼中的配偶什么样"

## 正确理解

✅ **日支亥中壬水伤官 + 甲木正财 → 太太的特质：**
   壬水伤官：太太聪明、有才华、有自己的标准、比较挑剔
   甲木正财：太太务实、会理财、持家有道
   伤官生财：太太虽然挑剔，但她的挑剔能转化成实际好处

✅ **日支午中丁火正官 + 己土正印 → 你（日主）在太太眼中的特质：**
   丁火正官：她觉得你正直可靠、有担当
   己土正印：她觉得你包容照顾人
   官印相生：她眼中你是个"靠谱又宠她"的人

## 验证方法

拿到一个八字，先看配偶宫的藏干十神。
问自己：**这个配偶（真实的人）有这样的性格特征吗？**
如果是，说明理解对了；如果想的是"日主如何对待配偶"，就是错的。

## 快速口诀

> 配偶宫不是"日主管配偶"，
> 配偶宫是"配偶本人"。
