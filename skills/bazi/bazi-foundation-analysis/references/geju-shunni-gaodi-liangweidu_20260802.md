# 格局两维度并存：高低（真诠）vs 顺逆（滴天髓）· 2026-08-02辩证沉淀

> **来源**：荀太虚《滴天髓》讲解 vs 《子平真诠》体系辩证（老板辩证思维铁律首应用）
> **辩证结论**：荀太虚说"格局没有高低之分，只有轻重/顺逆之分"，与《子平真诠》"格局高低"论表面冲突——经辩证，**两者不冲突，是两个独立维度**，分析时必须同时看，不可互相替代。

## 一、两个维度

```yaml
维度① — 格局高低（《子平真诠》·格局本身质量）
  判定依据：用神成格/败格、相神有无、清纯、有情有力、位置配合
  （详见 classic_zipingzhenquan_20260729.md §四 论格局高低）
  结论：格局质量（先天层次）

维度② — 格局顺逆（《滴天髓》·运行配合）
  判定依据：五行能量是否平衡流通（理气心法）、是否顺势而为（大运流年配合）
  （滴天髓原文：五行干支，阴阳二气，贵在流通，中和为贵）
  结论：运行顺畅度（后天发挥）
```

## 二、四象限关系

| 格局质量（真诠） | 顺势程度（滴天髓） | 人生结果 |
|:----------------|:------------------|:---------|
| 高 | 顺势 | 上佳——既成格又走得顺 |
| 高 | 逆势 | 空有好格局也过不好（荀太虚原话：大富大贵格局却痛苦） |
| 平 | 顺势 | 普通格局也能安稳幸福（荀太虚原话） |
| 低 | 逆势 | 雪上加霜 |

## 三、铁律（写报告时强制）

1. 分析报告必须**两维度都覆盖**："格局质量（真诠）+ 顺势程度（滴天髓）"
2. 不能只讲一个维度——只讲高低漏了"走不走得顺"，只讲顺逆漏了"格局本身质量"
3. 引擎落点：格局质量→ge_ju.py+determine_ge_ju_level；顺势程度→da_yun_theme.py（大运十年主题）+yong_shen_power.py（喜用力量/忌神坐实/大运流年）
4. 从弱/从格等特殊格局例外：无喜用也能成格（格局质量维度需加"从格例外"备注）

## 四、辩证背景

- 荀太虚原话："格局没有高低之分，只有轻重之分、顺逆之分"——这是滴天髓视角（重运行配合）
- 真诠明讲"有情而兼有力，则格局高"——这是子平视角（重格局质量）
- 两派都正确，维度不同：真诠看"这台机器的配置"，滴天髓看"这台机器跑在什么路上"
- 与 `shishen-benyi-rensheng-shijian_20260802.md`（十神本意→人生实践）呼应：顺势=做与格局精髓相通的事
