# 实证反推方法论 · 全流程标准化

## 一、触发事件分类
| 事件类型 | 应查机制 | 关键取象 |
|:---------|:---------|:---------|
| 工作变动 | 大运换运/流年冲合日支/财根/官杀透干 | 填实/冲动/透干 |
| 破财 | 比劫与透财组合/通关是否断裂 | 透财年结盟→劫透年兑现 |
| 车祸/官非 | 驿马冲/开杀库/金木交战 | 外杀入宫/印化杀 |
| 健康手术 | 土困水脏/日支受冲/日主受克 | 年→运→月→十神四层追溯 |
| 婚恋/得子 | 婚姻宫合动/官杀透干/财合身 | 应期在换运前一年 |

## 二、反推步骤

### Step 1：列出事件时间轴
记录：年份/月份/事件类型/结果/金额(如适用)

### Step 2：反查大运流年干支
- 当前大运是什么？管前五年还是后五年？
- 流年干支是什么？天干透出什么十神？地支是什么？

### Step 3：找触发机制
检核清单：
- □ 流年地支与原局某字相冲？（巳亥/卯酉/寅申/子午/辰戌/丑未）
- □ 流年地支与原局某字相合？（午未/亥卯未/巳酉丑等）
- □ 流年天干透出官杀/财星/比劫？
- □ 流年填实/伏吟原局某字？
- □ 大运换运当年？

### Step 4：分线断法
同一流年拆成五条线分开判断：
- 财线 → 【吉/凶/平】。依据：财星透干/得地/被劫？
- 官杀线 → 【吉/凶/平】。依据：官杀透干/开库/被冲？
- 身线 → 【吉/凶/平】。依据：日主受克/受泄/得助？
- 夫妻线 → 【吉/凶/平】。依据：日支被冲/被合？
- 比劫线 → 【吉/凶/平】。依据：比劫透干/夺财？

### Step 5：归纳触发字
从已验证的事件中归纳共同点：
- 哪些地支重复出现？（如"亥卯酉午"四字铁律）
- 哪些天干重复出现？（如丁年升职、甲年透财）

### Step 6：反推未来
用归纳出的规律反推未来流年：
- 未来触发字之年 → 预计事件类型
- 分线判断吉凶 → 不是整体吉凶

## 三、从实证到通用规则的方法

### 通用化步骤
1. 识别个人八字中的特殊结构（如杀藏财库、通关链条）
2. 抽象为通用机制（如"凡财与官杀同库→财名捆绑"）
3. 去掉具体干支（不写"丁+亥"，写"七杀坐下地支决定吉凶"）
4. 加上条件（"在X条件下格成/在Y条件下格败"）

### 常见错误
- ❌ 把个人实证直接当通用规则（"您八字午合开库" → 应写为"凡墓库逢合则开"）
- ❌ 结论式表述而不给条件（"某年吉" → 应写为"财线吉+身线凶"）
- ❌ 只看天干不透就下结论（"无官杀" → 应查藏干中气余气）
