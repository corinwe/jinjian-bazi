## 二、引擎升级内容（ge_ju.py v3.1）

### 2.1 会支取用（规则①）
```
触发：月令本中余气均不透干（原判杂气格时）
逻辑：月支参与的完整三合（能量≥7）/三会局 → 取局五行对日主的十神成格
排除：半合（能量5）不作取格依据——月令本气兜底优先（避免酉月伤官被半合误判）
```

### 2.2 本气兜底（规则②）
```
触发：仍为杂气格且月令有藏干
逻辑：取月支本气对日主的十神成格（比肩劫财不入格→维持杂气格）
效果：酉月辛不透→伤官格；子月癸不透→伤官格；午月丁不透→正财格
```

### 2.3 用神变化（规则③）
```
触发：透干取用后
逻辑：取用天干与四柱其他天干成天干五合 → 标记"用神X被Y干合绊"
示例：家主母亲壬辰戊申癸卯壬子——正官戊被日主癸合绊（癸戊合）
```

### 2.4 顺逆用标记（规则④）
```
顺用：正官格/正印格/偏印格/正财格/偏财格/食神格
逆用：七杀格/伤官格
```

## 四、AI应用规则（沉淀）

1. **判格必走五步**：定月令 → 透干取用 → 会支取用 → 本气兜底 → 顺逆用标记（引擎已实现）
2. **会用神变化**：取用天干被合→在报告中提示"用神被合"（官被合身吉/合绊失用凶，按合化五行论）
3. **杂气格是兜底不是默认**：辰戌丑未月才真正可能"杂气"；单藏干月（子午卯酉）必能定格
4. **半合不取格**：半合只影响能量分析（刑冲合害层），不影响格局命名
5. **从弱/从旺优先级最高**：先判从格，再从正八格（引擎v3.0既有逻辑）
