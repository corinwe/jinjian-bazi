# 全盘通根分析法（2026-08-02·老板辩证沉淀）

> **来源**：老板辩证（子源辛金案例）——《子平真诠》正统通根规则
> **铁律**：看天干之根，**不能只看坐支，要全盘统观四支**（真诠第27章"统观四支，有一字，皆甲木之根也"）

## 一、通根判定规则（真诠原文依据）

### 规则1：全局四支都算根（不限于同柱）
```
真诠第6章："十干不论月令休囚，只要四柱有根"
真诠第27章："统观四支，有寅亥卯未等字否，有一字，皆甲木之根也"
真诠第6章徐注："月令休囚，而年日时支中，得生禄旺余气墓，皆为通根也"
```
**判断步骤**：
1. 取天干（如辛金）
2. 统观四支（年月日时），找：
   - 本气通根：四支藏干中有该干本气（戌中藏辛→辛根）
   - 长生禄旺位：四支为该干的长生/禄/帝旺之地（庚金长生巳→庚根；丙禄巳）
   - 墓库余气位：四支为该干的墓库/余气（辛墓辰/辛冠带戌）
   - 比劫帮扶：四支藏干为同五行（巳中庚→帮扶辛金）
3. 有一个即算有根——不要求同柱！

### 规则2：根的力量有轻重（真诠第6章）
```
长生/禄/旺 = 重根（根之重者也）
墓库/余气   = 轻根（根之轻者也）
通根之中，尤以月令之支为最重也
比劫帮扶（地支藏同五行）= 朋友之扶（轻于通根，但算帮扶）
比劫如朋友之相扶，通根如室家之可住；干多不如根重
```

### 规则3：生源（源不断）
```
看用神/财官星时，除了自身根，还要看"谁生它"：
  财生官：金生水——财星生官星 → 官星有源不孤（孤官不贵，有财生则贵）
  杀印相生：木生火——印星有源
  食神生财：水生木——财有源
判断"源源不断" = 全局多个根/多个生源
```

## 二、实战案例（子源·辛卯 癸巳 丙戌 癸巳）

### ❌ 错误判断（只坐支）
```
年干辛金坐卯（绝地）→ "辛财无力" → 官星无源 → 格局中
```
### ✅ 正确判断（全盘通根）
```
辛金全局通根：
  戌中藏辛（冠带·中气60%）→ 本气根 ✅
  巳巳中藏庚（庚金长生在巳）→ 比劫帮扶+重根 ✅
  三财根（巳巳庚+戌辛）→ 金生水 → 源源生官星癸水
→ 财旺生官！官星有源不孤 → 格局中上（成格）
```

## 三、比劫做功完整链条（家主案例·老板2026-08-02补全）

> **案例**：家主 庚申 癸未 辛亥 辛卯——比劫（金）如何做功生财

### ❌ 粗糙版（漏年柱）
```
辛金（日主）→ 癸水（食神）→ 亥卯未财局
```
### ✅ 完整版（补年柱源头）
```
【年柱·比劫源头】申金（庚禄·强根）→ 生庚金（劫财）← 支生干·通根
【天干·比劫生食神】庚金（劫财）+辛金（日主）→ 双金生癸水（食神）← 干生干
【接驳】癸水通根亥（亥中壬水·同气）← 干入支
【地支内】亥中壬水（伤官）→ 生甲木（正财）← 地支内伤官生财
【三合】亥水生卯 → 卯未半合 → 亥卯未三合木局（财局成）
```
**要点**：
1. 比劫的力量来自**年支申金**（庚禄在申·支生干）——没有申根，庚金是浮干
2. 比劫做功=**双金生食神**（庚+辛都生癸水）——食神双源受生
3. 食神通根引气入支→地支内藏干自生（壬生甲）→三合扩大成财局
4. **干支作用铁律**：天干不能直生地支——靠通根接驳（"支为干之生地，干为支之发用"）

## 四、AI应用规则（写入所有分析）

1. **分析天干力量必看全局四支**——禁止只看坐支
2. 输出格式：`X干通根：某支藏本气(重/轻)+某支比劫帮扶+生源某五行`
3. 判断"有力/无力"要看：本气根数+长生禄旺位+比劫帮扶+生源——四要素综合
4. 财生官/食神生财等链条：先验"源头是否有根"，再断"链条是否通"
5. 引用原文："有一字，皆甲木之根也"——任何位置有根即算
