## 二、判定规则（结合全盘通根）

### 2.1 妻星/夫星有力无力（必须全局通根，不只看坐支）
```
妻星（财）有力条件（四要素，全盘四支统观）：
  ① 本气通根：四支藏干有财星本气（戌中辛=正财根）
  ② 长生禄旺：四支为财星长生/禄/旺之地（庚长生巳）
  ③ 比劫帮扶：四支藏干同五行帮扶（巳中庚扶辛金）
  ④ 生源：谁生财星（食伤生财=财有源）
妻宫坐财（日支藏财）= 妻贤助财（真诠"坐下财官，妻当贤贵"）
日主合财（丙辛合）= 妻来就我，情专向主（真诠"本身之合不为合去，合更为亲切"）
```

### 2.2 子女星判定
```
男命：官杀=子女星——官杀透干/有根=子女有；官杀坐时柱子女宫=子女有出息
女命：食伤=子女星——食伤透干=有子女；被克=子女星弱（多磨）
子女宫（时柱）：坐喜用=子女好；坐忌神=子女拖累
```

### 2.3 婚姻组合断语
```
妻宫坐财 + 妻星有情 → 妻贤旺夫（家主/子源）
夫宫坐官 + 官星旺 → 夫有地位（主母）
正偏财混杂 → 多妻星之象（防多情/感情复杂）
官星过旺（女命） → 夫缘重/丈夫强势/防感情复杂（主母4官）
比劫重 + 财星 → 比劫争财=防感情竞争/婚姻外缘（家主）
```

## 四、AI应用规则
1. 六亲分析先取星（按上表）→ 再全局通根验力（四要素）→ 再断组合
2. 禁止只看坐支断妻星/夫星有力无力
3. 婚姻断语必须"妻/夫宫+妻/夫星+全局配合"三合一看
