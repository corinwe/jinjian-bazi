## 一、杨清娟食伤做功应用检查表（老板必问"你用上了吗"）

分析任何八字时，逐条跑这张表，每条给"✅用了/❌不适用+原因"：

### 1.1 断官三要素（4.7条）
```
① 食伤旺不旺？（有根？被克？被合泄？）
② 有没有对应要制的神（官）？（官杀透干？藏而不透？）
③ 制的官大不大？（官旺=大官，官弱=小官，藏=不显）
结论：三要素全过→当官；食伤中旺但官藏→管理者/白领（4.6条主位食伤）
      食伤力量<官杀→100%求财（5.1条）
```

### 1.2 闲神逻辑（老板原话版）
老板问："比劫生食伤，如果食伤不去生官杀，也不去克印，那么它就是个闲神，就会比较有福"
```
判定时必须区分【直接】与【间接】：
  直接生官杀：食伤五行直接生火（水生木→木生火 算间接！）
  直接克印：食伤直接克土（水生木→木克土 算间接！）
  间接生官杀/克印（通过财星中转）→ 仍算"去了"→ 不是闲神
关键结论：
  - 食伤生财（直接做功）→ 不是闲神，是"做工型"→ 劳而有获
  - 食伤不直接制官杀、不直接克印（走生化路）→ "合比制长久"（5.2条铁律）→ 做工但顺利，越老越顺
  - 纯闲神（什么都不做）= 清福命但平庸（4.5条"食神不做事=有福之人"）
  - 争斗型食伤（直接制官杀：食神制杀+伤官见官）→ 劳碌硬碰硬
```

### 1.3 比劫归属（哪些是朋友）
```
逐比劫寻根基（盲派寻根基R11）：
  根在哪：禄>刃>本气库>余气库；家里（日时）vs 家外（年月）
  杨清娟劫财归属（食伤做功解读6.4）：
    - 劫财坐年/月柱 = 外面的，无情
    - 劫财和我同宫 + 家中有财 = 贵人/合作伙伴，喜走比劫运
    - 比劫在年财在月 + 走比劫运 = 朋友变夺财（防）
  做功型 vs 夺财型（关键判定）：
    - 比劫生食伤（链条上游帮忙）→ 贵人型朋友，帮生财
    - 比劫直接克财/坐财克财（下游抢钱）→ 防分财（如时干比肩坐偏财同柱克财）
    - 比劫不见财（见的是食伤）→ 不破财
```

### 1.4 食神制杀 vs 伤官见官辨析
```
食神制杀（庚克甲等）：身旺+食神有力 = 官命大官；身弱 = 制不住反噬
伤官见官（辛克乙等）：为祸百端，官星受伤应官灾；印（火克金）是解药
两者并存 = 一吉一凶，吉凶各自应期
制杀需身旺——身弱制杀必须找印（杀印相生）当救应通道
```

### 1.5 官来合身应期
```
大运流年官星透出与日主相合（如辛日主逢丙午年丙辛合）：
  "原命日主合官=当官的""官来了一定大于财"（杨清娟）
  官杀并见年：看去官留杀/去杀留官（透干合身=留，藏支不扰=去）
  原局食神透+杀藏 = 食神制杀但制而不显 → 官杀透出之年是应期
  防：食伤旺年（水旺）食神直接克透干之官 = "食神制官多管闲事"
```

## 二、段建业做功分析要点

```
① 做功类型：生功（体生用·生化）/ 制功（制官杀·争斗）
   - 生功=化敌为友，最长久；制功=劳碌所得（克制得来的都是劳碌所得）
② 宾主：年柱=宾·家外，日时=主·家里；三合/六合把宾方财合进主位 = "宾来就主"
③ 体用：体（印比食伤·本钱）→用（财官·追求）；体生用=正向做功
④ 贼神捕神：有明确制局才走"制贼"路线；无制局走"生化"路线
⑤ 应期：合冲应期（合局逢冲填实）/ 墓库应期（冲库开库）/ 做功完成（局成）
```

## 三、子平格局层次要点

```
定格：月令本气；杂气取用看透干
成败：身旺有通关 + 食伤泄秀 + 财星有局
清浊：清（链条干净）vs 雄（官杀透干有杠杆）
调候验格：调候得用（原局有）→ 层次上台阶
富而不贵：财旺局成但官杀不透 → 主富不主贵
```
