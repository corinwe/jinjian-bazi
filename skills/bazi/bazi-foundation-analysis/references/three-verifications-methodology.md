# 三决断分析方法 · 产品化流程（2026-07-27）
来源：heluwenxian.nat100.top 三决断模式 + 老板校准

## 核心原则
先验过去，再看当下选择。任何八字分析的第一步不是全面报告，而是先给出3条可验证的过去判断。

## 三决断选取规则
- 覆盖三个不同人生阶段（早年/青年/中年）
- 或覆盖三个不同领域（家庭/事业/健康）
- 每条必须是有明确时间点/时间段的事件
- 不可涉及未来预测

## 多流派模式（可选）
同时输出子平/盲派/九龙三条三决断，用户反馈哪个流派准，再以该流派为主体做深度分析。

## 与常规报告的关系
三决断 = 免费层（先验过去）
完整报告 = 付费层（再看选择）
