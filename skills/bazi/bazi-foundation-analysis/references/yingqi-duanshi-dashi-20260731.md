# 刑冲合害应期 · 断大事件模型（2026-07-31 实战验证版）

> **来源**：对乾造辛亥（庚申 癸未 辛亥 辛卯）实战断验——断出5件老板未提及的大事件，供老板验证。
> **用途**：从原局刑冲合害反推人生大事件年份，属于"先验过去"（三决断/断验）的核心方法。

## 一、应期事件映射表

| 应期类型 | 触发条件 | 事件定性 | 周期规律 |
|:---------|:---------|:---------|:---------|
| **冲月令** | 流年地支冲原局月支（如丑未冲） | 事业/家庭/人生路线变动 | 约12年一次 |
| **冲年柱** | 流年地支冲原局年支（如寅申冲） | 长辈/祖上/根基/破财 | 驿马冲=变动奔波 |
| **冲时柱** | 流年地支冲原局时支（如酉冲卯） | 子女/财务事件 | — |
| **官合身** | 流年正官透干与日主相合（如丙辛合） | 名分/身份/婚姻/事业确立 | 约10年一次 |
| **夺食应期** | 流年印星合食伤（如戊癸合） | 思虑停滞/健康/输出受阻 | 逢印之年 |
| **日支伏吟/自刑** | 流年与日支同字（如亥亥自刑） | 内心/婚姻/健康内在事件 | — |
| **墓库刑开** | 流年刑冲墓库（如戌未刑） | 房产/文书/家宅/开库 | — |

## 二、实战案例（乾造辛亥 庚申 癸未 辛亥 辛卯）

### 原局刑冲合害底图
```
原局: 申亥害  亥卯未三合(财局)  午未合(藏)  申中戊土(印)
应期键: 丑未冲  戌未刑  寅申冲  酉卯冲  丙辛合  戊癸合  亥亥自刑
```

### 断出的5件大事件（供验证）
1. **1997丁丑（17岁·乙酉运）**：丑未冲月令+丁杀透 → 学业/人生路线大转折（辍学/转学/离家），伴随与长辈观念冲突
2. **2006丙戌（26岁·丙戌运）**：丙辛合（官合身）+戌未刑+大运伏吟 → 成家/立业/买房（名分确立，至少其一）
3. **2010庚寅（30岁·丙戌运）**：寅申冲（冲年柱）+庚劫透 → 长辈（尤其父亲）大事件 或 重大破财/事业清零
4. **2017丁酉（37岁·丁亥运）**：酉冲卯（冲时柱财星）+丁杀透（伏吟运干） → 财务大变动/投资失利，或子女事件
5. **2021辛丑（41岁·丁亥运末）**：丑未冲月令+辛比透，紧接2022壬寅再冲年柱（连续双冲） → 工作/事业/家庭大变动（换赛道/搬迁）

### 规律总结
- **冲月令年份（1997/2009/2021）**：事业/家庭/路线变动——约12年一次，间隔均匀
- **冲年柱年份（2010/2022）**：长辈/根基/祖业事件
- **冲时柱年份（2017）**：子女/财务事件
- **官合身年份（1996/2006/2016）**：名分/身份/事业确立——约10年一次
- **夺食年份（2008/2018）**：思虑/健康/输出受阻——逢戊土（印）之年

## 三、断验方法流程（先验过去）

1. **列全应期键**：写出原局全部刑冲合害（冲/刑/合/害/自刑/伏吟）
2. **逐年扫描**：把每步大运的流年与应期键比对，标记触发年份
3. **排除已知**：剔除老板已确认过的事件年份（三决断/旧报告已验证的）
4. **选信号最强的**：冲月令>冲年柱>冲时柱>官合身>夺食（按强度排序）
5. **三段式输出**：每件事件 = 规则（引动类型+十神）→ 数据（大运流年）→ 结论（事件性质+验证点）
6. **交叉验证**：子平应期 + 盲派合冲应期 + 枭神夺食 + 劫财夺财 + 官合身 多体系同断

## 四、注意
- 断验报告标注"供验证"——对得上的越多说明应期模型越准；对不上的年份据此校准规则
- 男命女命官星含义不同（男命官=事业/子女，女命官=丈夫），应用时先定性别视角
- 三合局（亥卯未）成立时，合局内字的冲（如冲亥）会引动整个财局——冲合俱动
