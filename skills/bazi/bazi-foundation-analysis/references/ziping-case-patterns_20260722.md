# 三造实证案例模式提炼

本文件提炼三个完整实证案例（乾造辛亥、坤造庚午、乾造丙戌）中的可复用模式，作为新案分析的对照模板。

## 案例一：乾造辛亥（偏财格、通关结构、杀藏财库）

### 命盘
庚申年 癸未月 辛亥日 辛卯时。身旺，杂气偏财格，劫生食食生财通关，杀藏未库。

### 模式1：事业变动"触发字"归纳
八次变动全部落在亥（2007、2019）、卯（2011）、午（2014）、酉（2017）四字：
- 亥＝伤官本位填实/伏吟 → 直线升级，一次到位
- 卯＝财局填实 → 先创业试错、后到位（双动）
- 午＝合开杀库 → 先创业试错、后到位（双动）＋官非并发
- 酉＝冲卯动财 → 先创业试错、后到位（双动）
- 巳（2013）虽冲日支却全年无事——巳字落空，不入触发字序列

**复用**：从实证变动记录归纳"触发字"，用触发字反推未来应期。

### 模式2：双动年机制——先试错、后到位
- 第一动奔向创业：偏财被引动则心动，心动则生自立门户之念
- 创业不成：杀藏财库，财与名分同库捆绑，无名之财不立
- 第二动到位：回归名→利通道，杀财同时跃升，一到位即翻倍

**复用**：杀藏财库之命，凡偏财被引动之年，第一动必奔创业、必不成，第二动回归平台必成。

### 模式3：破财"两步走"模型
- 第一步·透财年结盟（2014甲午、2015乙未）：财星透干暴露于劫财射程，且地支为燥土火地（通关断电）——关系形成，钱未出
- 第二步·劫透年兑现（2020庚子）：庚劫透干，钱出手还债——透财年签约，劫透年买单
- 反例：2024甲辰同为透财，但辰为湿土水库（通关加粗）——收入十年最佳

**复用**：透财年看地支——坐湿土水地吉（财被食神护住），坐燥土火地凶（通关断电、财暴露于劫）。破财兑现在劫透年。

### 模式4：官非"开库放杀"机制
2014甲午年9月底（癸酉月）车祸官非：
- 年柱：午未合开杀库，丁火杀气出库
- 月令：酉金冲卯，将出库杀气撞入现实
- 应象：驿马逢冲、外杀入宫（对方主动碰撞）
- 拖延：库开须待官星合化方收尾（缠讼两年至2016丙申丙辛合官）
- 无损：冲起的是官杀（是非责任）不是财——印化杀，保险公司全赔

**复用**：官杀入库之命，开库之年官杀线激活，官非、责任、规则纠纷随之而来；通关完好时事业线不动，两线分明。

### 模式5：健康"土困水脏"机制
2024甲辰年11月（乙亥月）肾结石手术：
- 亥为日支，主肾与泌尿
- 戊子运戊土盖头＋甲辰年辰土再来——土重困水，水液代谢之脏受郁
- 乙亥月亥字伏吟自刑引动日支——手术应期落地
- 同年收入十年最佳——财吉与身疾并行不悖（分线断法）

**复用**：日支为身体之本，受土困、受冲、伏吟之年应健康事件；财吉与身疾可分线并行。

### 模式6：大器晚成结构
- 第一重压制：丙戌运（22–31岁）官印盖头，食神被埋——会做不会说
- 第二重压制：丁亥运前期（32–38岁）伤官来了但杀也来了——动而折腾
- 解封点：2019己亥（39岁）亥水伏吟日支，伤官本位全面激活——从此连续丰收

**复用**：财官藏库、比劫成群、食神被埋之命，必大器晚成；解封点在用神填实/伏吟之年。

### 模式7：置业"印性窗口"规律
三次置业全在土月或印年：2006丙戌（印库）、2013甲辰月（湿土水库）、2024戊辰月（财透坐库）——印能锁财化杀，是比劫夺不走的资产形态。化财为产，是通关结构下的最优解。

**复用**：比劫旺之命，置业必择土月或印年——印性资产是绝对安全区。

## 案例二：坤造庚午（从杀格、六亲缘薄、苦尽甘来）

### 命盘
丁卯年 丁未月 庚午日 壬午时。日主无依，官杀成势，真从杀格。

### 模式8：从格实证锁定法
- 正格断"土金运吉"（戊申、己酉、庚戌三步印比运），实则受尽极苦——从格铁证
- 六岁母离（1993癸酉伤官见官）、后妈虐待（印比为忌）、辍学打工（2007丁亥食神合官）、父亡（2022壬寅父星化火）
- 2009己丑遇正缘（丑未冲，官星之根被冲动）

**复用**：正格断吉凶与实证完全相反时，果断修正为从格，全面重断喜忌（吉凶颠倒）。

### 模式9：从格六亲缘薄机制
- 母缘：未土印星被午合化火——印星化去，母缘化尽
- 父缘：卯木财星被未合泄、被午相破——父缘本浅；壬寅年父星化火归天
- 后妈：偏印己土被两午一卯围困——偏印受虐则虐人

**复用**：从杀格印比皆忌，六亲星皆为忌神——亲缘自然疏离，非命硬克亲，是结构使然。

### 模式10：从格转运节奏
- 逆运期（土金）：苦厄连连——前三十七年
- 转运元年（火透干）：2026丙午、2027丁未——运势逆转
- 高危期（土金再来）：2028戊申、2029己酉——一生中仅次于童年的高危期
- 晚运（木财生杀）：甲寅乙卯运——晚景反吉

**复用**：从格之人的大运节奏是"逆局苦→顺势昌→逆局危→晚运安"，与常命完全相反。

### 模式11：从格婚恋"夫星动"应期
- 丑未冲（2009己丑）：月令官星之根被冲动——遇正缘
- 官杀混杂（两丁争合一壬）：防二婚或多角
- 从杀格女命宜夫强：被管反而安心

**复用**：从杀格女命，官杀旺地或冲动官杀之年为婚恋应期；官杀混杂主夫缘多。

## 案例三：乾造丙戌（建禄格、财官俱真、运抬格局）

### 命盘
辛卯年 癸巳月 丙戌日 癸巳时。身旺建禄格，财透通根（两巳庚金长生＋戌库辛金余气），官透有源（巳中庚金生水）。

### 模式12：学业"官杀线晴雨表"
- 三年级前优秀：小运壬辰，杀食相济
- 三年级至八年级上滑至中上：壬辰大运杀星盖头压身
- 2024下半年觉醒：甲辰年辰土水库再临、甲印生身
- 2025年跳级入顶尖平台且轻松：身旺任杀，压力是磨刀石

**复用**：身旺任杀之命，学业节奏＝官杀线节奏——杀透压制则滑、金生水足则升、平台升级则强。

### 模式13：财星"明绝暗生"判定
- 表面：辛坐卯为绝地，虚浮
- 实际：两巳各藏庚金长生＋戌库藏辛金余气——有根而弱，合而有情
- 丙辛合：日主合财而财有根——合身之财牢牢在握，守财能力强

**复用**：判定财星根气必须细查地支藏干，不能只看天干表象；"明绝暗生"是常见的误判点。

### 模式14："运抬格局"结构
- 原局：身旺、财官有气而弱（水囚金死）——半成品
- 大运：壬辰起六十年金水连环——及时雨
- 结论：命的高度七分靠运抬、三分靠库开

**复用**：原局调候不足但大运连环补足之命，层次一半在局一半在运——先苦后甜、越老越值钱。

### 模式15：升学应期"食神吐秀＋官星得源"
2028戊申年高考：
- 戊土食神透干——发挥通道打开
- 申金财星得禄——金生水，官星得源
- 申巳合（合中带刑）——利远方之校，防考前小恙

**复用**：身旺之命考试看两点——食神透干（发挥）、官星得源（名分）；合中带刑防身体小状况。

### 模式16：两造对比框架
- 命1（辛亥）：通关结构、财藏不透、杀藏库中——下限稳、上限受杠杆限制
- 命2（丙戌）：财透通根、官透有源、运抬格局——上限高半档至一档
- 对比维度：财星状态、官星状态、守财能力、大运配合、兑现节奏

**复用**：两造对比看五个结构差异——财透vs财藏、官透vs官藏、守财机制、大运配合、峰值时间。

## 家庭合参模式（三造）

### 模式17：家庭五行互补系统
- 乾1（父，辛金）：金旺水相，缺火透干——提供规则与约束
- 坤3（母，庚金）：火旺水囚，需水调候——承受压力与转化
- 乾2（子，丙火）：火旺建禄，需水调候——释放能量与成长
- 互补：乾1之水润坤3之燥、乾1之水为乾2官星之源；同喜水木，财路同向

**复用**：家庭合参看五行互补与十神对应——互为调候、同喜同行、十神镜像。

### 模式18：大运同步共振点
- 2009：母遇正缘＋父起运
- 2011：父得子（官杀出库）＋母处低谷（生育耗气）
- 2024–2025：父子同步上升（父收入最佳＋子成绩觉醒）
- 2026：三造同见火——家庭整体转折

**复用**：家庭成员大运的共振点（婚配、生育、同步觉醒）是家庭运势的转折坐标。

### 模式19：合作创业命理可行性框架
- 行业属性与双方命局契合度（火＋水，双双得地）
- 分工模式适配（从杀格宜台前法人、杀藏财库宜幕后技术）
- 生死线（财权独揽、凶年守成、健康优先）
- 规模预判（分阶段：起步期、危机期、爆发期）
- 终极规模天花板（双方皆无平台化之命，宜小而美）

**复用**：合作创业分析看四点——行业五行契合、分工十神适配、风险日历、规模天花板。
