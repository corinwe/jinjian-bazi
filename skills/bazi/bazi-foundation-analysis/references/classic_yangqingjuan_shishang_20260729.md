# 杨清娟盲派·食伤生财升官做功解读（2026-07-29 全量提取）

> 来源：《杨清娟盲派食伤做功解读.pdf》（6页扫描件·页码44-48续篇·OCR提取）
> 主题：食伤生财/升官断法/十神做功关系/四凶神转吉
> 定位：盲派做功在"财官"层面的具体断法——什么人当官、什么人发财、什么人当多大官

## 〇、总纲：官是人生发展的动力

- **官来了一定大于财**：看到命主官来，就知道命主要做事情了——要干事业、要投资、要工作变动、要提升了
- 官是权贵、是敬畏；再懒情的人，只要官来了，他就要做事情了
- 正官=事业、法律、上进心、权力、保护神，为日主的衣食父母
- 正官有护身卫财之能，保护日主人身及财产安全，象征官与权力

## 一、十神基础与做功关系（本解读核心）

### 1.1 十神相生（看好事）
```
比劫生食伤 → 食伤生财 → 财生官 → 官生印 → 印生比劫 → 比劫帮身
```
十神相生非常重要：**这件事能不能成，中间要发生什么事情，都要看八字之间的整体组合**

### 1.2 十神相克
```
比劫克财 → 财克印枭 → 印枭克食伤 → 食伤克官杀 → 官杀克比劫
```

### 1.3 克制vs化解（做功效率铁律）
- **凡是克制得来的任何东西，都是因为劳碌所得**（比劫克财、食神制杀）
- 克制得到的东西没有化得到的东西容易、舒心
- **化敌为友为上策**：最好的策略就是化，减少双方的伤害

### 1.4 每个神都有它对应要做的事
- 有神无对应事 = 命没有平台或舞台
- 命中有这个神 = 有这方面的思想想法；没有 = 空有理想
- 比劫生食伤，食伤不生财不制官杀 = 无所事事
- 每个神如果没有对应的事做，它就是无聊
- 只要家里有体，就能去干事；能做多大事，看本体旺和弱

## 二、财生官（升官核心断法）★

### 2.1 日主合官 → 当官
- **原命日主合官，官完整且不被破坏 = 命主是当官的**
- 这个官一定要完整且不被破坏
- 如果原命有财来生官，让官的量加大，让官又上了一个台阶 → **当的这个官大**
- 财升官，我来合官，我就是当官的
- 没有财来升官，当的官相对比有财生官所当的官小
- 大到什么程度和级别，还需要看组合

### 2.2 财生官+日主合财 → 发财
- **财生官，日主合的是财 = 发财的，不是当官**
- 具体发哪方面的财，要看官与自己家里有没有联系
- 有联系 = 吃皇粮的
- 没有联系 = 私企或外企

### 2.3 财生官+透比劫 → 劳动者
- **财生官，日主合官，命中透比劫 = 劳动者**
- 合官是他的事业、理想和追求，**不能代表是当官的**
- 因为比劫是制财的，这个财生官没有力量

### 2.4 区分吃皇粮/私企/外企/管理/白领
- **吃皇粮 vs 私企外企**：看我合的是官还是合的是财
- **管理人员 vs 白领**：看合官还是合财，看食伤有没有对应要制的神

## 三、官生印（官杀生印格）★

### 3.1 官杀生印 → 好转应期
- 命中带官杀克身的，**大运印来或流年印来的时候，要么发财了，要么提职了**
- 杀不是好的，但杀被制住或化解，就往好的方面断

### 3.2 财坏印的两种解救法
- 身弱承受能力差，命中有印生身又有财来坏印：
  - **第一解：用官解救**——让财去生官，官再去生印（路线稳）
  - **第二解：用比劫克财**——比劫克财可以解救，但**没有财去生官稳**
  - 克财容易破财，破财后化解危机；克必然自身也有损失

### 3.3 官生印+印生身有力 → 大官
- **只要命中有官生印，印生身有力（贴身）= 当官的，这个官更大**
- 比财生官、合官的级别大
- 不但权力大，印还代表名气，做的这个官就是**名气在外**
- **什么性质的印生身有力？一定是同性的生身有力**

## 四、比劫生食伤（当官判断核心）★

### 4.1 比劫生食伤不见财官 → 当官的
- **原命有比劫生食伤，而且不见财和官 = 一定是当官的**
- 因食伤旺暗制官

### 4.2 比劫虚+食伤弱 → 老师/白领/中层
- 比劫虚、食伤弱 = 往老师上断（老师是孩子王，也是管理者）
- 也可能是企业的中层领导，也叫白领

### 4.3 比劫有根+食伤有根+食伤旺 → 当官的
- **比劫有根、食伤有根、食伤旺，不见财官 = 当官的**
- 食伤旺见到官又能制住官，官也旺 = **大官**
- 食伤旺、官弱 = 小官

### 4.4 食伤生财+家里有比劫 → 劳动者
- **原命有食伤生财，自己家里有比劫 = "劳动者"或企业工人**
- 因为食伤生了财，财是用比劫制的，层次低了
- **比劫生食伤，食伤不生财 = 管理者**（关键区别！）

### 4.5 食神不做事 → 有福之人
- **比劫生食神，食神不做事 = 有福之人**，一辈子吃不穷喝不穷
- 但容易成为一个平庸的人
- 看食神有没有对应的神出现，若无，此神就是闲神

### 4.6 主位有食伤 → 管理者（白领）
- **只要主位有食伤，且食伤不被破坏或破坏程度小，每一个都是管理者（白领），但不是当官的**

### 4.7 是不是当官的判断三要素
1. **看自己的这个食伤旺不旺**
2. **看有没有对应要制的神（官）出现**
3. **留意这个官的大小**——制住的官大，做的事就大（官大）；制的官弱，做的事就小（官小）
- 若没有对应的神，那这个人一生就要靠运气
- 否则就是"晚上想想千条路，白天依然走原路"

## 五、十神相克断法（制功应用）

### 5.1 食神制杀/伤官制官
- **食神制杀、伤官制官，食伤的力量大于官杀 = 当官的**
- 大运流年走出制伤官的星（印地）→ 这个命要有灾了，当官的有官灾
- 如果原命制不住这个官杀 = 求财的命，求财的要破财
- **如果食伤的力量小于官杀，100%是求财的**

### 5.2 食神制官 = 多管闲事
- 食神是制杀的，你去合官可以，去制官你就制不住
- **食神制官就是多管闲事、爱出风头**——制不了又要做
- 这类人一定是一个自不量力的人、摆不正自己位置的人
- 做事往往会半途而废——做的是不适合自己做的事
- **铁律：食神（禄）就是制杀的，伤官就是制官的，制反了就会半途而废；合是可以的，也能长久**

### 5.3 官杀克比劫无制化 → 有灾
- 看原命官杀是否有制化；无制化时，克比劫要有灾
- 看官杀的五行：
  - 金 → 身上会有伤灾
  - 火 → 容易被烧伤
  - 木 → 容易有伤灾
  - 水 → 容易有水灾

## 六、四凶神转吉（格局用法）★

> 四凶神：枭神、伤官、七杀、劫财（简称：枭、伤、杀、劫）
> 一切事物的好与坏都是相对而言的，如果条件变了，人、物自然也会跟着变

### 6.0 什么是格局（杨清娟定义）
- **十神相生叫格局**：比如七杀生枭印=化杀生印，不见食神的情况下是大格局
- 如果命中有七杀、有枭印又有食神，不叫有格局
- **十神相克也叫格局**：比如七杀克比劫=七杀制比劫，以暴制暴也是格局
- 官喜化不喜制：官好比法律、法规、领导、官员，约束是保护

### 6.1 七杀（凶神）
- 杀无制又无化叫七杀；有制或有化叫偏官
- 七杀无制又无化 = 没用格局的人：说了不算、算的不说、光说不做、思想简单、浑浑噩噩
- **杀一定要制或化，无制又无化会遭灾**
- **杀生印，化杀级别相当大，比化官的级别要大**
- **食神制杀，身旺，食神有力制住七杀，没有穿破杀信息者 = 官命**，当的官一般都是大官
  - 当的不是一把手而是二把手，他也说的算，一把手也要听他的
  - 因为食神制住七杀的人：说话有道理、办事有决策、还霸气
- **杀印相生，适合武职、公检法部门的官**
- **官杀混杂**：看去官留杀还是去杀留官，取其能用的为吉
  - 合官留杀 / 合杀留官 / 官杀无制
  - 只要能制服其中一个就是贵命
  - 命中有印、食伤、官杀，当食伤力量没有官杀力量大时，看印能不能用；印能用，这个命也有贵的地方
  - 官杀无制无化时为凶，杀到（杀攻身）时，应官灾或病灾
- **制杀反制**：命中有制杀格局，七杀力量增大了，当制杀力量制不住杀时，容易遭到反制，一旦反制应灾
  - 杀当财看（制不住）→ **破财**，再具体点就是**投资破财**
  - 杀当权力看（食神制不住杀）→ **犯小人**：①自己的工作失误 ②多年的隐患暴露 ③被别人排斥、诬告或诬陷

### 6.2 枭印（凶神）
- 枭印遇到食神且枭无制或受生时，即成灾星，**遇食即夺**
- 枭透出又遇食神，枭无制或受生时：心狠手辣、做事不择手段
- 枭有制时，心性有所变好；过了枭受制的年头，枭的心性又死灰复燃
- 善良是天生的，狠毒也是天生的；真正的改变在于修行
- **枭神夺食，喜配比劫，有财来破，可以变成喜神**
- 不管怎么化，枭遇食的心性只是有所改善，其本性存在，不能完全消失

### 6.3 伤官（凶神）
- 伤官之人：思想想法不正确、没有正知正见、说话做事偏激、爱冲动、不顾别人感受、口无遮拦、嘴黑、易伤人、胆大、法律意识淡薄
- **伤官克官"伤官见官，为祸百端"**：官是吉神，是给我们俸禄的，去制了官是错误的
- 伤官之人没有正知正见，见到官星就制，无普世思想、法律意识，做事无规矩，往往违背法律
- **命带伤官见官，大运或流年给双方加力时，就会应灾**，或是身体遭灾

### 6.4 劫财（凶神）
- **劫财见财即为动，引动劫财即破财**；劫财是和我异性的，劫财取财是不择手段的
- 大运来的神是外面的，动起财来不留情
- **命中的劫财坐在年柱或月柱，也是外面的，无情**（劫财位置决定有情无情）
- **寻根基看这个劫财出自哪里**：
  - 劫财和我出自同宫 → 命家中有财，这个劫财就是我的贵人、帮助我的人、合伙人 → **喜走比劫运，走了比劫运就发财**
  - 原命我和比劫同宫，比劫在年财在月 → **怕走比劫运**，走了比劫运，过去的朋友、合作伙伴就变成夺财的人，反目成仇
  - **预测指导**：看到此种情况，告诉命主——不管对方给你多么好的项目，不管你算好事成之后能赚多少钱，这个时候你只要去干就会赔
- **劫财见财如何化解？**
  - **化敌为友为上策，配食伤化凶为吉**
  - 指导做法：让对方去做一下投资；女命可以给予女方面做一些投资或财产支持，花钱买东西
- **劫财合杀**：有劫财时配七杀者，层次提高，命中有之适合武职
- **劫财坐主位，合财为有事情做，不动财**

## 七、应用规则（融入金鉴体系）

### 7.1 断职业层级决策树
```
日主合官 + 官完整不被破坏 → 当官的（有财生官=官大）
日主合财 + 财生官 → 发财的（官与家有联系=吃皇粮，无联系=私企外企）
合官 + 透比劫 → 劳动者（财生官无力量）
比劫生食伤不见财官 → 当官的（食伤旺制官）
比劫虚食伤弱 → 老师/白领/中层
食伤旺制住官且官旺 → 大官；官弱 → 小官
食伤生财 + 家里有比劫 → 劳动者/工人
比劫生食伤食伤不生财 → 管理者
主位有食伤不被破坏 → 管理者（白领）
食伤力量 > 官杀 → 当官的；食伤力量 < 官杀 → 100%求财
食神制杀身旺食神有力 → 官命（大官·有决策霸气）
杀印相生 → 武职/公检法
```

### 7.2 断灾应期
- 官杀生印格：大运印来/流年印来 → 发财或提职
- 食伤制官：大运流年走印地 → 当官的有官灾
- 制杀力量制不住杀 → 反制应灾（投资破财/犯小人）
- 伤官见官：大运流年给双方加力时 → 应灾
- 劫财见财：走比劫运（劫财在年月） → 破财
