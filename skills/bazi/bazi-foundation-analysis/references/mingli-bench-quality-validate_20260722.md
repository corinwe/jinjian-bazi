# 命理分析质量验证体系（MingLi-Bench）
来源：2026-07-22 整合入库

## 质量验证流程
每次完成八字报告后：

1. 从160题题库中抽取与命主同类别（婚姻/事业/财运等）的3-5题
2. 自行作答并记录答案
3. 与题库中的标准答案对比
4. 准确率≥80% → 报告质量合格
5. 准确率<80% → 需要重新审视分析逻辑
