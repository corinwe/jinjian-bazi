# 深度分析方法论 · 四份文档精读（二读）
日期：20260722
来源：四份专业命理分析报告的结构、逻辑、表述方式精读

## 核心差距：结论式 vs 机制式

**我的分析**是结论式的：「身旺→喜水→忌土→某年吉/某年凶」
**文档的分析**是机制式的：「在X条件下该五行为喜、在Y条件下为忌；吉凶取决于通关链条是否断裂」

## 方法论一：条件喜忌的表述方式

**通用模板**（所有八字通用）：

```
◆ 水（食伤）——真用神 → 无条件第一用神。功能：泄金、生财、通关、化枭
◆ 木（财）——喜神 → 透干时看地支：
   - 坐辰亥子丑寅卯（湿润水地）→ 通关顺畅 → 得财
   - 坐午未戌巳（燥热火地） → 通关被烤断 → 破财/埋雷
◆ 金（比劫）——半喜半忌 → 可帮身、可共事；忌与透财同见（透财年不动大钱）
◆ 火（官杀）——条件之喜 → 原局无官杀透干时，从流年借：
   - 虚透无根（丁亥/丁酉）→ 杀为我用，升职加薪
   - 有根通根（丁巳/丁午）→ 真杀攻身，凶
   - 坐燥土（丁未/丁戌）→ 名分打折，压力滞塞
◆ 燥土（未戌/戊己透）——真忌 → 埋金克水，断通关之源
◆ 湿土（辰丑）——平中带喜 → 培木蓄水，反帮通关
```

**每一条喜忌都有三个要素**：①五行/十神 ②什么条件下 ③什么结果

## 方法论二：流年分析的"四步推演法"

**通用模板**（分析任何流年都用四步）：

**第一步：年柱定性** — 该流年的干支组合激活了什么机制？
- 合开库？冲日支？填实财局？透出官杀？
- 例如：甲午年 → 午未合开月令杀库

**第二步：流月引爆** — 具体在哪个月份应事？
- 冲力最强的月份（酉月金旺、子月水旺等）
- 三合/六合发力的月份
- 例如：癸酉月金旺极生水冲火 → 冲力到顶点应事

**第三步：多线并发** — 同一流年可能同时触发几条线？
- 财线（收入变动）
- 官杀线（职位/名分/官非）
- 比劫线（同辈/合伙/担保）
- 身线（健康/自身）
- 例如：2014甲午年三线并发——创业(财线)+担保(比劫线)+官非(官杀线)

**第四步：持续年限** — 该事件会持续几年？
- 战冲（巳亥/寅申）→ 至少看往后3年
- 断冲（卯酉/子午）→ 当年结
- 开库 → 看库中物何时被合化/冲散

## 方法论三：从格判定的"三步锁"

**通用模板**（分析任何八字都先检查）：
```
第一步：日主有依还是无依？
  - 天干有无比劫？地支藏干有无同类？
  - 无 → 继续检查。有 → 通常不从

第二步：某五行是否成势不可逆？
  - 是否透干+禄旺+合会？
  - 官杀势？财势？食伤势？
  - 势不可逆 → 继续检查

第三步：行扶身大运时实证如何？
  - 行印比运时人生苦还是顺？
  - 苦 → 从格锁定
  - 顺 → 非从格
```

## 方法论四：事业变动的"先试错后到位"模型

**通用规则**：
```
判断任一事业变动流年：

① 流年触发的是日支本位（填实/伏吟/合动）？
  → 单动年 → 一步到位，直线升级

② 流年触发的是偏财/合局/财根？
  → 双动年 → 先试错（奔向创业）→ 不成 → 回归主线
  → 为什么不成？因为命里的财不认无名的路
  → 为什么第二动必成？冲动余波未平+回归名分渠道
```

## 方法论五：健康事件分层追溯法

**通用规则**：
```
追溯任何健康事件（如手术/疾病）：

① 流年 → 五行生克起点（甲辰年土重困水）
② 大运 → 叠加影响（戊子大运戊土盖头+流年辰土=双重土压）
③ 流月 → 引动机制（乙亥月亥水伏吟自刑引动肾水之脏）
④ 十神 → 应象（辛金日主应金刃之事=手术动刀）
```

四层缺一不可，不能只说"某年健康不好"。

## 方法论六：家庭合参的三同步法

**通用规则**：
```
分析家庭八字时，按三维度同步检查：

维度一：五行互补
  父喜水+子喜水=父子一致？
  母从杀+父杀藏=夫妻互补？

维度二：大运同步
  列出三人大运时间轴
  找重合的关键年份
  逐行分析家庭大事原因

维度三：角色定位
  根（物质精神支柱）→ 通常给财杀同库/通关结构的人
  炉（压力炼就）→ 通常给从杀格/官杀混杂的人
  果（延续超越）→ 通常给财官俱真/格局更高的人
```

## 方法论七：报告结构——从"结论式"改为"机制式"

**旧结构（我的）**：
```
§1 八字总览 → 结论
§2 格局分析 → 结论  
§3 身强弱 → 结论
§4 喜用神 → 静态列表
...
```

**新结构（文档的）**：
```
§1 命盘总览与核心架构 → 先给数据，再给一句话总结
  - 四柱排布
  - 命局关键数据（旺衰/五行/十神/关系）
  - 核心架构（格局本质）

§2 喜用忌神判定 → 不是静态列表，是条件表
  - 每个十神有：①五行/十神 ②什么条件下 ③什么结果
  - 总纲一句话（如"此命水断则百病生，水通则万事顺"）

§3-§7 各领域分析 → 每个领域先用机制解释，再给结论
  - 事业：先解释为什么是这样的机制，再给结论
  - 财富：先解释通关链条，再给量级判断
  - 健康：先追溯历史事件，再预测未来

§8 大运流年总表 → 逐流年分析，每行标注★吉凶+影响度
  - 规律提炼（几句话概括）
  - 重点年份标注
```
