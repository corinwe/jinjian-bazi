# 子平法三经典定格局要点（2026-08-02·全家判定实战沉淀）

> **来源**：老板要求用《渊海子平》《子平真诠》《滴天髓》定家主/少爷/太太格局——实战中修复2个引擎bug
> **方法**：渊海（十干喜忌·月令）→ 真诠（取用·成败·相神）→ 滴天髓（顺逆·平衡·真从假从）三层推敲
> **完整案例**：知识库 `02-人物档案/全家格局三经典判定_20260802.md`

## 一、三经典判定流程（类级方法）

```
① 渊海子平：日主十干喜忌 + 月令旺衰定性（如辛金喜壬水淘洗、丙火喜壬水、庚金喜丁火锻炼）
② 子平真诠：定月令 → 透干取用 → 会支取用 → 本气兜底 → 建禄/阳刃另论 → 判成败 → 定相神
③ 滴天髓：五行平衡流通检查 + 顺逆（大运流年配合）+ 真从/假从 + 火炎土燥等特殊形态
```
三者是**不同维度**，不是互相替代——真诠讲格局本身质量（有情有力则高），滴天髓讲顺势程度（顺之者昌），两维度并存（见 geju-shunni-gaodi-liangweidu_20260802.md）。

## 二、引擎2个bug修复（2026-08-02·防回退）

### 1. 从弱格细分映射错误（已修）
- **旧bug**：写死 `{"土":"从杀格","火":"从财格","木":"从儿格"}` ——方向全错（假设所有日主土=官杀/火=财，只对特定日主成立）
- **修复**：按日主五行动态映射——克我=官杀(从官杀格)、我克=财(从财格)、我生=食伤(从儿格)
- **验证**：主母庚金火68极旺 → 火克金=官杀 → 从官杀格（旧判"从财格"错误）

### 2. 建禄格/阳刃格缺失（已修）
- **旧bug**：月令本气=比劫时一律判"杂气格"
- **修复**：查建禄（甲禄寅乙禄卯丙禄巳丁禄午戊禄巳己禄午庚禄申辛禄酉壬禄亥癸禄子）+阳刃（甲刃卯丙刃午戊刃午庚刃酉壬刃子）
- **验证**：子源巳月丙火=建禄格（旧判"杂气格"错误）
- 真诠："建禄与月劫，可同一格，皆以透干支别取财官煞食为用"——建禄格另取财官煞食，不透则按月令本气兜底前先识别

## 三、从格判定要点（辩证重点）

- **真从条件**（真诠）：日主无根 + 四柱皆财官 + 无印比帮身
- **印星失用才可从**：月令印星当令≠一定有生扶——**火炎土燥时燥土不生金反脆金**（滴天髓），印分计0（引擎燥土规则：火炎土燥当火看）
- **假从**：从格中有克泄耗之神透干（如从官格见食神透）→ 破从之意 → 假从，层次打折、起伏大
- **从官格喜忌（关键修正）**：喜财（生官）官（从得更真）；**忌食伤（制官破从）**——食伤在从弱一般论喜，但从官格是例外！引擎喜用对从官格需人工检查（主母案例：引擎喜用水有误，水=食伤=忌）

## 四、会支取用细节

- 三合局以**中神**为代表定财偏财：亥卯未木局中神卯=乙木，辛金见乙=**偏财**（引擎取正神简化输出"正财格"，严格按子平应作偏财格）
- 财格细辨：正财（异性）vs 偏财（同性）——按局中神藏干阴阳定
