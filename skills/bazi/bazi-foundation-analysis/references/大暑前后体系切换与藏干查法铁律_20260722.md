# 同月令大暑前后体系切换 + 藏干查法铁律
来源：20260722老板精读校正·丙火巳月/庚金未月/辛金未月
铁律等级：永久

## 一、大暑前后的体系切换

### 庚金生于未月
- **大暑前**（约7月22日前）→ 按五月庚金论
  - 丁火猛烈，庚金被过度煅制
  - 用神：**壬水（第一）**，癸水次之
  - 忌：火（过度煅制）、木（生火助焰）
- **大暑后** → 按六月庚金论
  - 土旺埋金，庚金坚顽
  - 用神：**丁火（煅金成器）** + 甲木（疏土显金）
  - 忌：癸水/壬水伤丁火

### 同一八字用神可能完全相反
主母成（太太）：丁卯 丁未 庚午 壬午
- 大暑前生 → 壬水为用 ✅，双丁为忌
- 我之前按六月庚金分析 → 全反了（说双丁好、壬水不好 ❌）

### 启动流程

分析未月庚金前，先问：**出生日期是否在大暑前？**
- 是 → 加载五月庚金体系
- 否 → 加载六月庚金体系

## 二、藏干查法铁律

分析生克链条（尤其是水源/财源）时：

### 必须查藏干，不能只看天干 ❌错法
「子源没有庚金，水源不足」→ ❌ 错！查藏干后发现：
- 月支巳：庚金 × 30%
- 日支戌：辛金 × 60%
- 时支巳：庚金 × 30%
→ 四金生双癸水，水源非常充足

### 正确做法
分析步骤如下：
1. 先看天干透出的相关十神
2. 再查四个地支的所有藏干
3. 统计目标五行的总力量（透干100% + 主气100% + 中气60% + 余气30%）
4. 不能仅凭"看起来没有"就下结论

## 三、比劫做功 vs 作恶的判断

劫财/比劫不是天然要去"劫"财的。
判断标准（三个条件）：

| 条件 | 做功 | 作恶 |
|:----|:----|:----|
| 天干有财星可劫？ | 财不透干 ❌ | 财透干 ✅ |
| 前有食伤可生？ | 食神透干顺生 ✅ | 无食伤通路 ❌ |
| 比劫和财的位置 | 隔层（财在地支） | 同柱或近身 |

### 三个条件全部满足 → 做功
老板的庚申年干 + 癸水月干：财不透干 + 食神在前顺生 → 庚金去做功了

### 口诀
> 劫财不可怕，怕的是：
> 劫财 + 财星透干 + 无食伤泄路
> 三条俱足，劫财才会真去劫
