# 文件归档规则（2026-07-27 老板校准）
来源：家主三造多流派报告归档踩坑

## 核心原则
报告文件必须按"人物档案→编号-姓名"归档，禁止放入"00-原始素材"或其他目录。

## 归档路径
```
知识库根目录: /root/weiwuji-knowledge-base/07-国学哲学/八字命格/
人物档案目录: 02-人物档案/
├── 01-家主-魏启令/       ← 编号-姓名
├── 02-主母-成/
├── 03-少爷-子源/
└── NN-{姓名}/            ← 新人编号 = 现有最高编号+1
原始素材目录: 00-原始素材/  ← 仅存外部导入的原始资料（Kimi文档、公众号文章等）
❌ 禁止把人物报告放这里
```

## 人物报告放入规则
1. **一家三口（家主/主母/子源）** → 固定编号：01/02/03
2. **新人** → 查现有最高编号 +1
3. **报告文件命名**：`{日主阴阳造}_{报告类型}_{日期}.md`
   - 例：`乾造辛亥_完整多流派报告_20260727.md`
   - 例：`坤造庚午_盲派体用v2_20260716.md`

## 检查清单（每次归档前）
```yaml
□ 文件路径包含 02-人物档案/ → ✅
□ 文件路径不包含 00-原始素材/ → ✅
□ 文件路径包含正确的编号-姓名子目录 → ✅
□ 新人编号 = max现有编号 + 1 → ✅
```
