## 一、层次格局（子平法·正统视角）
══════════════════════════════════════════

### 1.1 定格
月令未土，本气己土偏印当令。未中藏：己（偏印·本气）、丁（七杀·中气）、乙（偏财·余气）。
**取格：杂气格。** 但实际做功重心不在印，而在天干通关结构——庚（劫）→癸（食）→亥卯未（财）。

### 1.2 格局成败
**格成。** 三要素齐全：
- **身旺有印**：64分身强，未土偏印生身，金有根（申禄+辛比）
- **食伤泄秀**：癸水食神透干，辛金生癸水，泄身有力
- **财星有局**：亥卯未三合木财局，财有强根成局

**通关链条**：庚（劫财）→癸（食神）→甲木（财）——比劫不夺财，反为生财之源。
这是**"食伤生财格"的通关结构**，属于"以技艺立身、以名取利"的格局。

### 1.3 清浊评定
**清而不雄。**
- **清**：通关链条干净无断裂，劫生食、食生财一路顺畅
- **不雄**：官杀不透（丁火七杀藏而未透）、财不透干（财全藏地支）——无杠杆放大效应，属"守成之格，非开疆拓土"

### 1.4 调候验格（重要）
辛金未月调候用神**壬、甲**——原局亥中藏**壬**（伤官）、**甲**（正财），调候齐备！
这大幅提升格局层次：未月燥土生金，金被土埋，得壬水淘洗、甲木疏土，金显其用。
**调候得用是此命层次不低的关键证据。**

### 1.5 层次定位
- 中上层次（身旺+食伤生财+财局+调候得用）
- 富而不贵（财旺局成但官杀不透，主富不主贵，无公权力象征）
- 财的形态：**局财**（三合木局）非单财——财富规模大、来源广，但需要"局成"的应期才能兑现

### 1.6 格局隐患
**枭神夺食**：未土偏印当令，克癸水食神。食神是用神，被枭神压制——
- 表现：才华有但输出受阻，"话到嘴边咽回去"；想法多但行动滞后
- 解救：大运见**水**（食伤旺克枭）或**火**（财生官制枭）→ 2026丙午年官星透出制枭，是输出窗口

## 二、盲派段式（段建业·做功体系）
══════════════════════════════════════════

### 2.1 做功方式判定
**做功类型：生功（非制功）。**
- 用我的体（辛金）去生食伤（癸水），食伤再生财（甲木）——**正向做功**
- 不是"制"的做功（无制官杀），是"生"的做功——靠本事赚、不靠争斗

**做功链条**：庚（劫·生源）→ 癸（食·功神）→ 甲木（财·功果）
- 主要功神：**癸水食神**（生财做功）
- 辅助功神：亥中壬水（伤官·同助生财）
- 废神：未土偏印（不参与做功，反克功神——效率损耗点）

### 2.2 宾主分析
```
年 庚申 = 宾（家外·别人的）
月 癸未 = 宾/门户（枭神坐在食神上）
日 辛亥 = 主（自己）★
时 辛卯 = 主（自己家）
```
- **宾来就主**：月令未（宾）与日支亥（主）、时支卯（主）**三合木局**——宾方的财被合进主位！
- 未中乙木偏财，通过亥卯未三合，合到家里——**外面的财主动送进来**
- 家里最旺的：**亥卯未财局**——家里有个财库等着被填满

### 2.3 体用分析
- **体**：辛金日主（体旺，有庚申+辛帮身）
- **用**：木（财·甲木）、水（食伤·癸水）
- **体用关系**：体生用（金生水、水生木）——用我的体去追求财
- 评价：**体旺用足，可成事**。瑕疵在体旺过用（想多做少），且用神癸水被未土枭神压着（输出打折）

### 2.4 贼神捕神
- 捕神（有用之神）：癸水食神、甲木正财
- 贼神（被制之神）：此命无明确制局，不走"制贼"路线，走"生化"路线
- 结论：**不做"以暴制暴"的功，做"化敌为友"的功**——这是段建业体系中最高级的做功方式之一（用化不用克）

### 2.5 应期法则
- **合冲应期**：亥卯未三合局，逢**子年**（2020庚子、2032壬子）冲午填实；逢**申年**（2028戊申）冲寅——合局引动的关键点
- **墓库应期**：未为财库（乙木入未库），逢**戌年**（2030庚戌）冲未开库——财库打开
- **做功完成**：三合局成（亥卯未齐），大运流年添木（甲乙寅卯）→ 财局发力

## 三、盲派特点（杨清娟·食伤做功视角）★ 本次重点
══════════════════════════════════════════

> 应用新学到的杨清娟《食伤做功解读》断法——"比劫生食伤怎么断官"、"食伤做不做工、享不享福"

### 3.1 结构定性：比劫生食伤 + 食伤生财
```
庚（劫财）→ 癸（食神）→ 甲/乙（财）
辛（比肩）→ 壬（伤官）→ 甲（财）
```
**这是标准的"比劫生食伤"结构**——比劫不夺财，反而生食伤、食伤生财。
按杨清娟：比劫生食伤是**"看好事"**的相生链，代表这个人有技术、有输出能力，且身边的人（比劫=兄弟朋友）能帮他出力。

### 3.2 核心判定①：是不是当官的？（4.7条三要素）

| 杨清娟三要素 | 此命验证 | 结论 |
|:-------------|:---------|:-----|
| ① 食伤旺不旺？ | 癸水食神坐未受枭克，但有亥中壬水为根；亥卯未合局后水被泄向木 | 🟡 **食伤中旺**——有根有力但被合泄、被枭压 |
| ② 有没有对应要制的神（官）？ | 未中丁火七杀藏而不透 | 🟡 **官杀藏库**——有"要制的神"但没透出来 |
| ③ 制的官大不大？ | 丁火七杀藏未库，力量弱且不透 | 🔴 **制的官小** |

**判定结论：不是"当官"的命（制官无实），是"管理/技术骨干"的命。**
- 不符合"比劫生食伤不见财官→当官"（此命**有财局**，财透成局）
- 不符合"食伤旺制住官且官旺→大官"（官杀藏而不透，制不住）

### 3.3 核心判定②：食伤做不做工、享不享福？（4.5条）

杨清娟原话：**"若命中有比劫生食神，食神不做事，此人就是有福之人，这一辈子吃不穷喝不穷。"**

此命：**食神做事了**——癸水食神生了财（亥卯未财局），不是闲神。
- 食神做工 → **不是清福命，是"劳而有获"的命**
- "看食神有没有对应的神出现，若无，此神就是闲神"——癸水对应甲木财，**有对应神，不是闲神**
- 但注意：食神做的功（生财）被枭神（未土）盯着——**做得辛苦，不是轻松钱**

### 3.4 核心判定③：主位食伤 → 管理者（4.6条）

杨清娟原话：**"只要主位有食伤的，且食伤不被破坏，或破坏的程度小，每一个都是管理者，也就是白领，但不是当官的。"**

此命：**日支亥（主位）藏壬水伤官**——主位有食伤 ✅
- 亥卯未三合，伤官参与做功（伤官生财）——不是闲神
- 破坏程度：未土克亥水（枭克伤官），但亥未半合引化——**破坏程度小**
- **判定：管理者/白领/技术骨干 ✅**（不是当官的，不是普通工人）

### 3.5 核心判定④：劳动者 vs 管理者（4.4条）关键辨析

杨清娟原话：**"若原命有食伤生财，自己家里有比劫就是'劳动者'，或者是企业的工人，因为食伤生了财，财是用比劫制的，所以层次低了。如果比劫生了食伤，食伤不生财，就是管理者。"**

**此命属于哪个？需要仔细辨析：**
- 时柱辛卯：比肩坐偏财——**家里有比劫**（时干辛金）✅
- 食伤生财了（亥卯未财局）✅
- **但关键区别**：杨清娟说的低层次场景是"**财是用比劫制的**"——比劫把食伤生出来的财抢走/制掉
- 此命**比劫不制财**！比劫（庚辛）生食伤（癸壬），食伤再生财——**比劫在链条上游帮忙，不在下游抢钱**
- 且财局（亥卯未）**合进家里**（亥在主位），不是被比劫劫走

**结论：不适用"劳动者"判定。** 此命的"家里有比劫"是**帮工**不是**夺财**——时干辛比肩坐卯（财），比肩与日主同气相帮，是把财守住/帮生，不是抢。

### 3.6 核心判定⑤：食伤生财的财归谁？（合克得财）

- 亥卯未三合财局，**合在主位**（亥在日支）
- 财与日主：日主辛金坐亥（财星长生），**日主直接坐在财局上**
- 杨清娟："财生官，日主合的是财=发财的"——此命日主坐财、财合进家——**典型的发财结构**
- "官与家里有没有联系"：未（官库）与亥卯三合，官库合进家里——**财官都与家有关**，主吃"体制内技术饭"或"平台红利"

### 3.7 杨清娟视角综合断语

```
比劫生食伤 → 有技术、有帮手（兄弟朋友助力）
食伤生财 → 技术变现、凭本事赚钱
财局归家 → 钱能攒住，财库在家里
主位食伤 → 管理者/白领/技术骨干（非当官、非工人）
食伤做工（非闲神） → 劳而有获，不是清福
枭神压食伤 → 做得辛苦，思虑多，输出打折
```

**一句话（杨清娟式）**：这是个**"比劫生食伤、食伤做工生财、财局归家"**的命——有本事、有帮手、钱能留住；但不是"食神不做事"的清福命，是劳心劳力的管理者命。当不了大官（制不住官），但做得了管理（主位食伤）。财富靠"做工"赚，不靠运气。

## 四、三派合参 · 统一结论
══════════════════════════════════════════

### 4.1 层次定位（三派共识）
| 流派 | 层次判断 | 依据 |
|:-----|:---------|:-----|
| 子平 | 中上·富而不贵 | 食伤生财+财局+调候得用；官杀不透 |
| 段建业 | 生化做功·上等做功 | 用化不用克，宾来就主，财合进家 |
| 杨清娟 | 管理者/白领·劳而有获 | 主位食伤做功，食神做工非清福 |

**三派共识：中上层次，技术/管理立身，财富可观（财局），非官贵。**

### 4.2 职业画像
- **子平**：技术获得信任→信任兑换名分→名分兑换财富（三段式）
- **段建业**：吃技术饭、赚主动送上门的钱；兄弟朋友能帮上忙但需先付出
- **杨清娟**：管理者/白领/技术骨干；有对应事做（食伤做工），有平台（功神有处发力）

### 4.3 财富特征
- 财成局（亥卯未）→ 财富规模可观
- 财合进家（宾来就主）→ 钱能攒住
- 食伤做工 → 每一分钱都是做出来的，不是捡来的
- 忌：比劫夺财大运（庚申、辛酉年）防合伙/借贷破财

### 4.4 应期提示（2026-2032）
- **2026丙午**：丙火正官透干合辛（官来合身）+午未合——**官来要做事了**（杨清娟："官来了一定大于财"），事业动作年
- **2027丁未**：丁火七杀透出+未土枭神伏吟月柱——杀枭并见，压力年，注意健康（土克水·肾）
- **2028戊申**：戊土正印合癸水食神（枭神夺食应期！）+申金劫财——**防夺食破财**，合作谨慎
- **2030庚戌**：戌冲未开财库（墓库应期）——**财库打开之年**，重大财务变动
- **2032壬子**：子水冲午+食伤大旺——食伤发用年，技术输出变现

### 4.5 核心提醒（三派交叉验证）
1. **枭神夺食是最大隐患**（子平/杨清娟共识）：未土压癸水——思虑过多、输出受阻、健康上防土克水（肾结石2024已验证，2028戊申注意）
2. **富而不贵**（三派共识）：不要强求官场权力，走技术/管理/专业路线
3. **财局兑现靠应期**：合局逢冲逢合之年（2028申、2030戌、2032子）是财务大年，提前布局
