## 二、起名核心原理

```yaml
① 名字=最短的符咒：写出来是符，念出来是咒。经常叫唤的名字持续影响能量场
② 名字可补五行能量50分（≈5个能量盘/250元价值的能量）
③ 一命二运三风水，四积阴德五读书，六名七相八敬神——名字排第六，重要过面相
④ 不怕生坏命，就怕起错名
⑤ 微信名/网名/英文名同具能量（避讳：私人号=死人号谐音；Bruce=不路死）
```

## 三、八字定字规则（第一优先）

```yaml
① 五行缺失必须优先补：缺什么五行先用名字补上（哪怕忌神也要补——缺了造成性格缺陷/五脏气不足）
② 五行齐全 → 补喜用神即可
③ 身弱 → 补印星、比劫（提升自身能量）
④ 身强财旺 → 补财星、食伤（让财富担得起，否则发财出问题）
⑤ 每个字有五行属性（部首/字义判定，可用「汉字五行查询」）
⑥ 尽量五行顺生：金→水→木→火→土→金，一顺百顺；避免中间五行断掉
⑦ 避生僻字/避长辈同音同字/避不吉谐音/避十字交叉结构（十、乂代表对应部位伤病）
```

## 四、名字五行评估四步法（2026-08-18 实战沉淀）

### Step A — 五行顺生链检查（最重要）

```
把名字的字按顺序连成五行链，检查是否顺生：
✅ 水→木→火（水生木、木生火）→ 一顺到底，最佳结构
⚠️ 火→木（木生火，倒生）→ 次优
⚠️ 水→火（水火相见无通关）→ 需加木字通关
❌ 金→土→水（土克水断链）→ 尽量避免

例：炜枫智能 = 火→木→火（木生火）✅ 顺生
    深润智能鼎 = 水水→火火（水火交战、缺木通关）→ 改「深润枫鼎」= 水木火顺生即完美
```

### Step B — 通关检查（水火交战必查）

名字同时含强水+强火（如 深/润/澜 + 鼎/智/能）→ 中间必须加木字通关：水生木、木生火 → 全局流通。缺木就改一字为木。

### Step C — 数字五行（河图数）

```
数字本身有五行：一六水、二七火、三八木、四九金、五十土
「六六」= 水水 → 天然补调候水 + 物流行业水 → 好底子
```

### Step D — 谐音/辨识度检查

```
□ 读起来顺口、不拗口
□ 无不良谐音
□ 首字+核心字辨识度（不与他人重名）
□ 项目名可复用公司名核心字呼应（如枫/鼎）
```

## 六、刑冲合害解冲命名法（2026-06-24课程核心技法）

八字有冲 → 名字中加入能合住一方/双方的字 → 合化后不再相冲（相当于给自己加第九个字）：

| 冲的组合 | 化解字（六合） | 原理 |
|:--------|:-------------|:-----|
| 子午冲 | 丑（合子）或未（合午） | 子丑合/午未合 |
| 卯酉冲 | 戌（合卯）或辰（合酉） | 卯戌合/辰酉合 |
| 寅申冲 | 亥（合寅）或巳（合申） | 寅亥合/巳申合 |
| 巳亥冲 | 寅（合亥）或申（合巳） | 寅亥合/巳申合 |
| 辰戌冲 | 酉/卯/申/午 | 辰酉合/卯戌合/三合 |
| 丑未冲 | 午/巳/子/卯 | 午未合/三合/子丑合 |

**解冲原则**：①确定是哪种冲 ②找可合化一方的字（六合/三合/三会均可）③合化字必须同时是八字喜用神 ④既解冲又补用神，一举两得。

## 十二、单字/候选字五行评估要点（2026-09-07「子焘」案例沉淀）

> 案例：「焘」字适不适合少爷(子源·丙火建禄·引擎喜金土水忌木火) → ❌ 属火犯忌。全流程证据见 `references/name-case-zitao-20260907.md`

### 12.1 🚨 通关陷阱：通关字必须先过忌神关
- 名字水火交战 → 教科书解法「中间加木通关」，但⚠️命主若忌木（子源忌木火），加木=饮鸩止渴
- **忌神永远不能当通关字**。此路不通时的正确出路：不用火字 / 把火字换成水或金

### 12.2 双字名必须按书写顺序判生克（首字→次字）
- 五行链按名字先后连：子(水)→焘(火)=水克火直克断链（不是可接受的倒生）
- 记法：X→Y 为 X生Y 顺生最佳；Y生X 为倒生=次优可接受；X克Y=断链❌
- 丙火建禄忌木火命（子源类）次字优先级：**水(同气顺补) > 金(倒生回注·金是第一喜用)**；火/木一律红牌；土慎用（克首字水易断链）
- 现名「子源」=水+水顶配 → 单字寓意再好也不能随意替换，寓意让位于五行喜忌

### 12.3 忌火命遇「火部首/火义」字先红牌
- 焘/煜/烨/晟/炜/灿… 对忌火命=比劫过旺：争强内耗、泄官星（丙火之癸水官星被耗）、不利学业期立规矩
- 焘字档案：五行火（康熙·火部 从火寿声，姓名学字库一致）；多音 dào/tāo 易读错；简体11画 vs 繁体燾18画 → 「多音+简繁笔画差」双减分

## 十三、笔名/网名/署名评估三维法（2026-09-07 家主笔名实战）

> 实战：家主(辛金身强64·引擎喜木水<火>忌土金)候选「无记/无咎/忘机/无为」+少爷「子焘」。逐字验证细节见 `references/penname-eval-20260907.md`

### 13.1 触发条件

```
□ 用户问某笔名/署名/网名/微信名适不适合自己或客户（公众号署名尤其常见）
□ 老板给一批候选名要求「都验一遍」
□ 用户问自己的**智能体/助手/工具名**要不要按八字改（如「我这几个 AI 助手名字需要改名吗」）
  → 同用三维法，**逐个给「留/改」结论**（不是笼统排序），不合格的给出「只换一字」级最小改动候选
```

### 13.2 三维评估法（五行层 → 传播层 → 意涵层）

```
维度1 — 五行层（硬指标·引擎优先）
  ① 引擎实跑喜用神（pipeline_v5.py，禁凭记忆）
  ② 逐字五行 → 康熙字典取名库同口径（URL技巧见13.4）
  ③ 五行链检查（同§四StepA）：顺生✅ / 倒生⚠️次优 / 直克断链❌
     双字名水火直克无位加木 = 不合格（与「子焘」「无咎」同判）

维度2 — 传播层（笔名/署名必查·否决项，比意涵更重）
  □ 口语歧义：读出来第一联想是否负面（无记=没记性 ❌）
  □ 谐音撞名：撞历史/公众名人（魏+无记≈魏无忌信陵君=双刃剑：有光环但像蹭名）
  □ 品牌对冲：与主品牌语义打架（金鉴真人=明察铭记 vs 无记=无所记 ❌）

维度3 — 意涵层
  □ 出处/典故是否正面契合行业（易经吉辞/道家/佛家/诗文）
  □ 铁则：世俗读音的负面联想权重 > 高深出处——名字是给人叫给人看的

结论格式：五行层 ✅/⚠️/❌ + 否决项表格 + 每候选一句话总评（落点候选→结论，不笼统）
```

### 13.6 🚨 口径分歧处理：双口径稳健性检验（定案规则）

```
字有五行争议（部首派 vs 字义派判不同，如 宝=火/土、墨=水/土、九=木/金）时，
不要停在「两库不一致、没法判」，按下面二选一收口：

① 稳健结论（可直接定案）：两种口径下结论一致 → 照判，文档注明「两口径同判」
   例：知墨 = 知(火)→墨(水)=水火直克断链❌；若墨=土 → 火生土顺生但土是忌神收尾❌
       → 两种口径都不合格 = 结论稳健，不因分歧阻塞
② 口径敏感（只能给倾向，须双库复核才能定案）：结论随口径翻转
   例：元宝 = 宝(火)→木生火顺生✅；若宝=土 → 木克土直克+忌神收尾❌ → 口径敏感
   标注形式：「本结论押在『宝=火』口径上」+ 列入待复核项

铁律：
□ 交付文档必须写明「采用了哪个口径 / 出处 / 哪几项结论受口径影响」——禁止静默择一
□ 稳健结论可直接给「留/改」；口径敏感项只给「倾向+待复核」，不假装确定
□ 只剩单库可达时，做稳健性检验即可支撑定案（文档注明「单库」）
```

### 13.7 含数字名/字符数字的双口径（六、九…）

```
数字有两套读法，判名前两套都要过一遍：
  字符五行（康熙取名库）：六=火、九=木 …
  河图数五行：           1/6=水、2/7=火、3/8=木、4/9=金、5/0=土
本体系既有口径（沿用，不擅自翻转）：名称里的数字按【河图数】当五行用
  （「六六」=水水 —— 呼应物流=水 + 调候水；2026-08-18 六六枫鼎批次定案）
但仍要两口径各判一次：
  六六智达：河图口径=水水→火火（水火交战缺通关❌）；字义口径=火火火火（比劫/官杀气过旺❌）
  → 两口径都不优 = 稳健判定；若某口径下翻转成吉，则标注口径并复核
价值点：数字常是名称里唯一能直接补「调候五行」的位置（六=水），别只看字义。
```
