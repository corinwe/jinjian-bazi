## 用途

**仅供对照与规则移植，不参与运行时。**

本项目是 TypeScript / Next.js 16 应用，依赖 `iztro`、`lunar-javascript`；
我们的排盘引擎是自研 Python（`engine/ziwei_engine.py`），技术栈不同，
因此这里只保留**可移植的规则与算法参考**。

## 可借鉴点

1. **格局三层结构**：`required`（必须）／`bonus`（加分）／`breaking`（破格）——
   本项目的 `ziwei_rules.py` 目前缺"破格层"。
2. **每格标古籍出处**：《紫微斗数全集》《全书》《骨髓赋》。
3. **对 0 次触发的条目标 `disputed`**，不硬凑规则。
4. **明确排除飞星派工具**（宫干自化、来因宫），与倪师立场一致。
